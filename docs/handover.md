## 環境・前提

- **`python3` は無い。`python`（3.12.7）**
- **`npm run build --strict` は効かない。`npm run build -- --strict`**（`--` が要る）
- **`npm run prices:refresh` はツールの実行許可で拒否される**（I-014）
- **`git reset --hard` / `git clean -f` / `git restore` / `git checkout --` / `git push --force` は拒否される**
- **Python スクリプトは Write ツールでファイルへ書いてから `python <path>` で実行する。**
  bash の heredoc も `python -c "..."` も、日本語やバックティックを含むと壊れる
- **ターミナルの出力が cp932 で日本語が化ける。** 読む必要があるものは
  UTF-8 でファイルへ書き出してから Read で開く
- **`Agent` ツールに `name` パラメータが無い**（I-006）。`CLAUDE.md` が定める
  エージェント間の直接通信は**この実行環境では構造的に使えない。**
  全タスクを `連絡してよい相手: 無し` で回す。**代わりに、終了したエージェントへ
  `SendMessage` で追加指示を送ると文脈を保ったまま再開できる**（新しく起こすより安い）
- **ブラウザでの目視確認**（→ I-003。**T-071 でスキル化する**。それまでは毎回この注意が要る）:
  - `--window-size` だけでは **meta viewport が無視され、誤った観測になる。**
    Chrome を `--remote-debugging-port` で起動し、Node 22 標準の `WebSocket` から
    `Emulation.setDeviceMetricsOverride`（`mobile:true`）を叩く
  - **`dist/` を `file://` で開かない。** CSS が絶対パスのため当たらず、
    **エラーにならないままレイアウトの観測が誤る**。ローカル HTTP で配信する
  - **`document.fonts.ready` を待つ。** 待たないと文字幅が約16%細く出る。
    **T-057 で実際に誤った設計を1件生んだ**
  - Chrome が終了コード 21 で落ちる環境がある。`--headless`（旧）と絶対パスの
    `--user-data-dir` に変えると動く
  - ホバーは `CSS.forcePseudoState`
- **`main` への push は本番デプロイである**（Cloudflare Workers Builds。`docs/ops/deploy.md` §4）
