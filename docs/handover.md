### 実行環境の注意（毎回ここで詰まる）

- **`python3` は無い。`python` で入っている**（3.12.7）。組織のスクリプトはこれで動かす
- **`npm run build --strict` は効かない。`npm run build -- --strict`**（`--` が要る）
- **`npm run prices:refresh` はツールの実行許可で拒否される。** 組織からは実行できない
- **モバイル幅の目視確認に `--window-size` は使えない。** ヘッドレス Chrome は
  端末エミュレーション無しでは meta viewport を無視し、デスクトップ幅が切れて写るだけになる。
  実装担当2体がここで続けて詰まった。正しくは Chrome を `--remote-debugging-port` で起動し、
  **Node 22 標準の `WebSocket`** で DevTools Protocol へ接続して
  `Emulation.setDeviceMetricsOverride`（`width:375, height:812, deviceScaleFactor:2, mobile:true`）
  を送ってから `Page.captureScreenshot` を撮る。依存パッケージは要らない
- **`Agent` ツールに `name` パラメータが無い。** `CLAUDE.md` が定めている
  「エージェントに名前を付けて宛先にする」仕組みが、この実行環境では使えない。
  いまは全タスクが `連絡してよい相手: 無し` なので支障が出ていないが、
  **レビュー↔実装の往復を直接通信でやらせようとすると成立しない**
