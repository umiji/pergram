## 調査が出した、設計に直接効く結論

| # | 結論 | 出典 |
| --- | --- | --- |
| 1 | 🔴 **個々の変更に人が都度クラスを判定する設計を、どの実務も採っていない。** 判定は**種類に対して一度だけ前もって**行われ、個々は照合に還元される。**この組織には「タスクの種類」の一覧が無い。実務との差はクラスの切り方ではなく、ここである** | ITIL 4 |
| 2 | **軽い工程とは、審査の省略ではなく、審査対象を一段上げること。** 手続きが作られた／変わったときに一度だけ完全なリスク評価を通す | ITIL 4 |
| 3 | **「手続きが既に整備されているか」という軸が増える。** 変更の性質ではなく**組織の履歴**で決まる。同じ変更が1回目は normal、5回目は standard | ITIL 4 |
| 4 | **「1タスク＝1つの重さ」で全工程を決めている実務が一つも無い。** 設計＝曖昧さ / テスト＝リスク / 決定の記録＝不可逆性 / レビュー＝全件やって観点を変える | Ubl, ISO 29119, Nygard, Google |
| 5 | **クラス数は2〜3が最多。4超は皆無。** クラス分けを使っていない実務が3つ（SRE＝連続量、DORA＝承認の所在、WHO＝全件一律19項目） | 横断 |
| 6 | 🔴 **Fowler は「不可逆性＝工程を重くする軸」の根拠に引けない。** 原文は "things people **perceive as** hard to change"、発想は Ralph Johnson、**論文の結論は "eliminate irreversibility"（不可逆性を取り除け）** | Fowler 2003 |
| 7 | **不可逆性と「変更の種類」は独立の軸ではない。** 「構造の変更は安く戻せる。振る舞いの変更は戻せない」 | Beck |
| 8 | **「リスク＝影響×発生可能性」は ISO 29119 の定義ではない**（`such as` 付きの例示）。**算定方法は規格の要求ではないので独自に決めてよい。** 低エクスポージャを費用制約で落とすことは規格上の正規の手順 | ISO 29119 |
| 9 | **レビューは省かない。** DORA 2019: 外部の変更承認委員会を持つ組織は低パフォーマー **2.6倍**、変更失敗率を下げる証拠なし。⚠️ **否定されているのは外部機関の承認で、ピアレビューは推奨側** | DORA, Google |
| 10 | **規模は「決める軸」ではなく「操作する対象」。** 「小さいから省く」ではなく「リスクを閾値以下に収めるため小さく切れ」 | ITIL, Google |

## PO 指摘「Maturity と遂行能力」への答え — 3段ではなく5段

| 段 | 判定の証拠 | この組織の現状 |
| --- | --- | --- |
| 定義 | 手順・entry/exit 条件が書かれているか | おおむね足りている |
| **配備** | 役割が割り当てられ**伝達され**、**力量と資源があるか** | 🔴 **I-013 がここで落ちている** |
| 遂行 | 実際に行われているか | 証拠・入口は実際に書かれていた |
| **管理** | **逸脱したとき是正措置が取られるか** | 🔴 **CMMI の Performed / Managed の境目はこの1点。検知だけでは届かない** |
| **保証** | **遂行者以外**が評価し、不適合が **クローズまで追跡**されているか | 🔴 **閉じる経路が無い。警告は翌セッションも印字される** |

**I-013 が「②遂行できる組織か」の教科書的な実例である** ——
`org-review` の定義に `Write` も `Edit` も無く、**規約が全担当へ求める
「組織への指摘を自分のタスクファイルへ書く」を物理的に実行できない。**
指摘が上がらないことが「指摘が無い」と読める。同種が5件ある。

### 「止める」か「測る」かの答え

**どちらを採っても、不適合を閉じる経路が無ければ段3に到達しない。それが分かれ目。**

順序は **精度を上げる → 件数を減らす → 閉じる経路を作る → 止める。**
本セッションで1段目と2段目を行った（50件 → 2件）。

🔴 **成立条件がある。Google は「偽陽性が10%を超えると開発者は警告を無視する」とし、
繰り返しそれを観測した結果、警告を出し続けるという選択肢を最初から捨てている。**
**この組織の警告は偽陽性94%だった。この状態で割り当てを止めれば組織はほぼ全面停止する。**
