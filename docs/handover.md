### 実行環境の注意（毎回ここで詰まる）

- **`python3` は無い。`python`（3.12.7）**
- **`npm run build --strict` は効かない。`npm run build -- --strict`**（`--` が要る）
- **`npm run prices:refresh` はツールの実行許可で拒否される**
- **`git reset --hard` / `git clean -f` / `git restore` / `git checkout --` / `git push --force` は拒否される**
- **Python スクリプトは Write ツールでファイルへ書いてから `python <path>` で実行する。**
  bash の heredoc も `python -c "..."` も、日本語やバックティックを含むと壊れる
- **`Agent` ツールに `name` パラメータが無い。** `CLAUDE.md` が定めるエージェント間の
  直接通信（役割名＋タスク番号を宛先にする）は**この実行環境では構造的に使えない。**
  全タスクを `連絡してよい相手: 無し` で回した。**代わりに、終了したエージェントへ
  `SendMessage` で追加指示を送ると、文脈を保ったまま再開できる**（T-016 / T-017 / T-011 で使った。
  新しいエージェントを起こすより安い）
- **ブラウザでの目視確認**（→ 組織改善 I-003。スキル化の候補）:
  - `--window-size` だけでは **meta viewport が無視され、誤った観測になる。**
    Chrome を `--remote-debugging-port` で起動し、Node 22 標準の `WebSocket` から
    `Emulation.setDeviceMetricsOverride`（`mobile:true`）を叩く
  - **`dist/` を `file://` で開かない。** CSS が絶対パスのため当たらず、
    **エラーにならないままレイアウトの観測が誤る**。ローカル HTTP で配信する
  - ホバーは `CSS.forcePseudoState`
