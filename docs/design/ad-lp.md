## 0. v0.3 から何を変えたか

v0.3 の仕様通りに実装したところ、**正しいが退屈な**ページになった。原因は3つあり、いずれも構造の問題だった。

| # | v0.3 の問題 | v0.4 の対処 |
|---|---|---|
| 1 | ヒーローの5行が `¥3.3 / ¥3.5 / ¥3.5 / ¥4.4 / ¥5.2` と似た数字の羅列で、**差の大きさが体感できない** | 差を**年額**に直して1つだけ巨大に出す |
| 2 | 最大の武器である「**ソートキーを変えると順位が入れ替わる**」がページのどこにも無い | それをヒーローそのものにする |
| 3 | シグネチャ要素「コストの物差し」が細い線に点が数個で、何も語っていない | 分布の**形**を見せる。最安・中央・最高に金額を打つ |

加えて、競合調査で前提が1つ変わった（§1）。

## 1. 競合状況 — 「1gあたりで計算する」はもう訴求にならない 🔒

英語圏には同じ計算をするサービスが既に複数存在する。

| サービス | 規模・特徴 |
|---|---|
| CompareProteinPrices | プロテイン700製品超を1gあたり単価で比較 |
| ProteinMath | 50製品超、Amazon 価格で毎日更新、$0.02〜0.08/g |
| SupplementMath | ラベルを解析し有効成分100gあたり価格を算出。「30回分 vs 2lb」の表記差を剥がすことを売りにしている |
| SuppsRadar | 30成分。g / mg / IU に正規化。ブランド提携なしを明示 |

日本語圏でも「タンパク質1gあたり価格」で比較する記事は既にある（男前研究所、個人 note 等）。

**したがって「単価を計算します」は差別化にならない。** LP がコピーで名乗るべきは以下の3点のみ。

| 軸 | 競合の欠陥 | LP での見せ方 |
|---|---|---|
| **網羅性** | 「おすすめ10選」形式。全体の中の最安が分からない | 「68製品」という**具体的な数**を出す |
| **鮮度** | 執筆時点の価格が残る。プロテインは頻繁にセールする | 「毎日取得」「更新: 8月6日」を数字で出す |
| **中立性** | 上位記事はすべてアフィリエイト記事 | 「順位は単価だけで決まる」を明記し、**LPにアフィリエイトリンクを置かない** |

## 2. 対象ユーザー

**数値を見る習慣がある層。** 価格.com や PCPartPicker を使いこなす人。

- 筋トレ目的でプロテインを**継続購入**している（=年間コストが効く）
- セール時にまとめ買いする。個人輸入・iHerb を使う層が中核
- 「おすすめ」を信用していない。**自分で計算したいが面倒でやっていない**
- 商品ページを行き来して電卓を叩いた経験がある

**このユーザーが感じている痛みは「わからない」ではなく「面倒くさい」。**
だから LP の仕事は教育ではなく、**「その計算、全製品ぶん終わってます」と見せること**。

### 感情の的

> 「え、その2つそんなに違うの?」

驚きの対象は成分でも効能でもなく、**自分が既にいくら払っているか**。
薬機法の制約下でも、この驚きだけは100%合法に作れる。ここに全部賭ける。

## 3. 絶対制約 🔒

広告審査と薬機法に直結する。**機能要件より優先し、迷ったらより保守的な方を選ぶ。**

### 使ってはいけない語
```
効く / 効果 / 改善 / 高品質 / おすすめ / 人気No.1 / 安心 / 話題の / 選ばれる / 実感
```

### 使ってよい語
```
単価 / 1gあたり / 含有量 / 含有率 / 元素量 / ラベル表示 / 比較 / 一覧 / 出典 / 更新日 / 安い
```

### やってはいけないこと

| # | 禁止 | 理由 |
|---|---|---|
| 1 | 成分の働き・体への作用に言及する | 薬機法 |
| 2 | 独自の総合スコア・おすすめ度を作る | 事実提示ではなく推薦になる |
| 3 | 「だからこちらを選ぶべき」と書く | 判断はユーザーに委ねる |
| 4 | 筋肉・肌・before/after・人物写真を使う | 効能訴求と解釈されうる |
| 5 | 葉・植物・カプセル・錠剤・ハート・チェックマークを使う | 効能または推薦を連想させる |
| 6 | **アフィリエイトリンクを置く** | 広告審査でアフィリエイトサイト判定を受ける |
| 7 | 年齢・性別・体調を入力させる | 要配慮個人情報。取る必要もない |
| 8 | ヒーローにダミーデータを置く | ここで嘘をつくと全部が崩れる |

### 数値の書き方

- 単位と基準を必ず添える。「¥38」ではなく「**¥38 / タンパク質1g**」
- 計算の前提を必ず併記する。「1年で¥100,740の差」には「60g/日 × 365日で計算」を添える
- 「実測」と書かない。**ラベル表示値**であることを明記する

## 4. ブランド

| 項目 | 規則 |
|---|---|
| 表記 | **`pergram`** — 全て小文字。`Pergram` `PerGram` は不可 🔒 |
| 読み | パーグラム |
| 由来 | per gram — 1gあたり、というこのプロダクトの唯一の指標 |
| タグライン | **1gあたり、いくら払ってる?** |
| ロゴ | Archivo 800 のワードマーク + 上下に**ルーラーティック**（長短交互の目盛り） |

小文字固定なのは単位表記（`mg` `g` `mcg`）が小文字だから。**名前を単位と同じ字面の世界に置く。**

**LP では必ずロゴとタグラインをセットで出す。** `-gram` が Instagram / Telegram の連想を呼び、単体だと SNS アプリに見えるため。

## 5. デザイン言語

### 5.1 素材はどこから来ているか

材料は**成分表示パネル**（米国 Supplement Facts / 日本の栄養成分表示）。太罫と細罫で階層を作り、左に名前・右に数値を置く表組みの文法をそのまま UI の文法にする。

これは装飾ではなく立場の宣言で、**「ここはマーケティングの場ではなく、ラベルの数値を読む場だ」**と言っている。

### 5.2 トークン

[service.md](./service.md) と**完全に共通**。LP と本体で見た目が変わると、登録者が本体を見たとき別サービスに見える。

| トークン | 値 | 用途 |
|---|---|---|
| `--ink` | `#14161A` | 本文・罫線。純黒にしないのはラベル印刷の質感 |
| `--paper` | `#FBFAF7` | 背景。ラベル紙の白 |
| `--muted` | `#6B6F76` | 出典・更新日・補足 |
| `--line` | `#DCD9D2` | 細罫 |
| `--signal` | `#1B44C8` | **今アクティブな指標にのみ** |
| `--verified` | `#1F6F4A` | 第三者認証バッジのみ |
| `--warn` | `#B3261E` | LP では未使用 |

**罫線階層**: 6px（セクション上端） / 3px（主要な区切り） / 1px `--ink`（行） / 1px `--line`（副次）
**border-radius**: 0。ただしボタンとチップのみ 2px（触れる要素だけ角を落とす）
**スペーシング**: 4px ベース

### 5.3 書体

すべて OFL / 無料。サブセット化して self-host する（CDN 待ちを作らない）。

| ロール | フォント | 用途 |
|---|---|---|
| Display | **Archivo** 700/800, tracking -0.02em | 見出し、巨大数値 |
| Body | **IBM Plex Sans JP** 400/500 | 本文、UI |
| Data | **IBM Plex Mono** 500 | **すべての数値** |

**絶対規則 🔒**: 数値には `font-variant-numeric: tabular-nums` を必ず適用する。桁が揃わない比較表は比較表として機能しない。

### 5.4 v0.3 で足りなかったこと — 抑制と劇的さは両立する

v0.3 は禁欲的だが**平坦**だった。以下を守れば、写真もグラデーションも使わずにページは劇的になる。

| 原則 | 具体 |
|---|---|
| **1ページに巨大な数値を1つだけ置く** | 年額差を 64〜88px で出す。それ以外は 40px を超えない |
| **`--signal` を安売りしない** | 全68製品の価格を青くしない。**今選ばれているソートキー**と**差分**にだけ使う |
| **色を使えない場所は「動き」と「順序」で語る** | 順位の入れ替わりそのものが視覚効果になる |
| **余白で殴る** | セクション間 96〜128px。詰めない |
| **型スケールを飛ばす** | 12 / 14 / 16 / 20 / 28 / 40 / 88px。中間を使わない |

## 6. ベンチマークと、そこから採るもの

| サービス | 何が効いているか | pergram に採る |
|---|---|---|
| **Wise**（送金手数料） | ヒーローに実額を直接置く（「手数料1,713円」「MUFG比8,739円」）。翻訳の要る文言がなく**計算が語る**。名指しの競合と並べたライブ比較で、価格不安をその場の操作に変える | **年額差を実数で出す**。デモを触れる形にする |
| **Google Flights**（価格グラフ/日付グリッド） | 予測をせず、**実在する価格を並べて分布の形を見せる**。最安がひと目で分かる。数日ずらすだけで大きく変わることが「発見」として起きる | 物差しを**分布の形**として描く。最安・中央・最高に実額を打つ |
| **SupplementMath**（競合） | 「30回分 vs 2lb」の表記差を剥がすという説明が明快 | **1食の分母が製品ごとに違う**ことを ③ で示す |
| **SuppsRadar**（競合） | g / mg / IU に正規化。ブランド提携なしを明示 | 中立性の明示を ⑤ で行う |
| **PCPartPicker** | 単一目的（組む）に全 UI を従属させる | 単一目的（1gあたりで並べる）に従属させる |
| **Camelcamelcamel / Keepa** | 価格履歴と「今が買い時か」の即答 | 「毎日取得」を鮮度の証拠として出す |

### 採らないもの

- 並列比較マトリクスをデフォルトにしない。ユーザーは比較対象を選ぶ段階でつまずく。**デフォルトは単一指標でソートされた1本のリスト**
- Wise 的な明るい配色・イラストは採らない。ラベルの質感を壊す

### ① ヒーロー — 順位が入れ替わる

**このページで唯一記憶される画面。** キャッチコピーとイラストの組み合わせにしない。

```
 │╷│╷│╷│
 pergram
 1gあたり、いくら払ってる?

▌タンパク質1gあたり、いくら払ってる?

市販68製品を、ラベル表示の含有量から並べました。

  ┌──────────────────┬──────────────────┐
  │  1食あたりが安い順 │ タンパク質1gあたり │   ← トグル。右が初期選択
  └──────────────────┴──────────────────┘

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 1   ブランドA ホエイ 3kg        ▲ 6      ¥3.2 /g
     含有率 78%
─────────────────────────────────────────────
 2   ブランドB WPC 3kg           ▼ 1      ¥3.5 /g
     含有率 71%
─────────────────────────────────────────────
 3   ブランドC ホエイ 1kg        ▲12      ¥3.8 /g
     含有率 82%
─────────────────────────────────────────────
 4   …
 5   …
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
残り63製品は公開時にお知らせします。   更新 8/6

        [ 公開時にメールで知らせる ]
```

#### 設計指示

**トグルが仕掛けの中心。**

- **同じ68製品**を、2つのソートキーで並べ替えるトグルを置く
  - 左: **1食あたりが安い順**（世間の見方）
  - 右: **タンパク質1gあたりが安い順**（pergram の見方）— **初期状態はこちら**

- トグルを切り替えると、**行が物理的に並び替わる**（FLIP アニメーション、300〜400ms、`ease-out`）
- 各行に**順位変動バッジ**（`▲6` `▼1`）を出す。ゼロは表示しない
- バッジは `--ink` と `--muted` のみ。**色だけで方向を示さず、必ず三角記号を併記する**
- 切り替え時に `--signal` が非アクティブ側からアクティブ側へ移る。**このページで青が動くのはここだけ**
- `prefers-reduced-motion: reduce` では並べ替えを**アニメーションさせず即座に切り替え**、代わりに変動バッジを常時表示する

**なぜこれが効くか**: 「順位が変わる」という事実そのものが、このプロダクトの存在理由の証明になっている。説明文が一切要らず、薬機法の制約を1ミリも踏まない。しかも**全製品のデータを持っている側にしか作れない**画面で、「おすすめ10選」形式の競合には原理的に真似できない。

#### 左を「1食あたり」にする理由 🔒 — ここは変えないこと

候補は3つあった。**動きの大きさと誠実さを両立するのは1食あたりだけ。**

| 左の候補 | 順位変動 | 判定 |
|---|---|---|
| 袋の絶対価格 | 最大 | 1kg が 3kg より安いのは当たり前。**藁人形**であり中立性を損なう |
| 1kgあたり価格 | 小 | 含有率の差（68〜82% ＝ 約1.2倍）しか効かず、動きが弱い |
| **1食あたり価格** | **大** | **採用。** 1食量の差（21g vs 30g ＝ 約1.4倍）に含有率の差が掛かり、最大1.7倍前後の順位変動が正当に生じる |

さらに「per serving は製品を横断して比較できない」は [product/requirements.md](../product/requirements.md) §4.2 の 🔒 そのものであり、**このプロダクトが立っている原理を画面が直接証明する**構図になる。メーカーが袋に印刷しているのも1食あたりの値なので、ユーザーが実際に目にしている数字でもある。

#### 守ること

- 上位5件は**実データ**。ダミーを入れない 🔒
- ブランド名は実名を出す。伏せると信憑性が消える
- 「残り63製品」という**具体的な数**を出す。「たくさん」ではない
- 数値 `¥3.2 /g` は行内で最大かつ `--signal`
- H1 はタグラインと同義の疑問文にする。断定より「自分はいくら払っているんだろう」という自己参照を起こす
- CTA は1つだけ。ヒーロー内に置き、スクロールしなくても押せる
- ヒーロー画像・イラスト・アイコンは**使わない**。表がヒーロー
- ロゴは左上に小さく。このページの仕事はブランド認知ではなく登録

### ② その差は1年でいくらか

**ページで唯一の巨大数値。** ①で「順位が変わる」ことに驚いた直後に、金額の実感を与える。

```
▌同じ量のタンパク質を1年ぶん摂ると

              ¥100,740
                 差がつく

  最安 ¥3.2/g ―――――――――――― 最高 ¥7.8/g
       ¥70,080/年              ¥170,820/年

  安い ├──●●─●──●●●───●──●────●───────●──┤ 高い
        ▲最安                        ▲最高
                              対数スケール

  タンパク質60g/日 × 365日 で計算。価格は 8/6 時点。
```

#### 設計指示

- `¥100,740` は **Archivo 800 / 88px（モバイル 56px）/ tabular-nums**。ページ内で他にこの大きさを使わない
- 色は `--ink`。`--signal` は使わない（青は①のトグルに予約されている）
- **物差し（コストの物差し）**を対数スケールの横軸として置き、全68製品を1ドットずつプロットする
  - 対数であることを軸ラベルに明記する（線形だと外れ値で潰れる）
  - ドットのホバー/タップで製品名と単価を出す。タップ領域は 44px 以上
  - 分布の**形**が見えることが目的。Google Flights の価格グラフと同じ役割
- 前提（60g/日 × 365日）を `--muted` で必ず併記する 🔒
- **「だから安いものを買うべき」とは書かない。** 事実だけ置いて判断は渡す

### ③ なぜ表示価格で比べられないのか

存在理由を機構として説明する。**3つの罠を、短く3つ並べる。**

```
▌ラベルの数字は、そのままでは比べられない

  ① 含有率が違う
     同じ「3kg」でも  ┌ 含有率82% → タンパク質 2,460g
                      └ 含有率68% → タンパク質 2,040g
     ━━━━━━━━━━━━━━━━━━━━━━━━━━
     ━━━━━━━━━━━━━━━━━━

  ② 「1食」の定義が違う
     A社 1食21g / B社 1食30g。1食あたり価格は比較できない。

  ③ 元素量が違う（他の成分ではもっと大きい）
     酸化マグネシウム   500mg → マグネシウムとして 約300mg
     ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
     グリシン酸マグネシウム 500mg → マグネシウムとして 約50mg
     ━━━

  このサイトは、元素量に換算してから並べます。
```

#### 設計指示

- 横バーの長さで差を見せる。グラフライブラリ不要、CSS の幅だけでよい
- ①②はプロテインの話、③は**他成分でも同じ構造が起きる証拠**として置く（＝このサイトが1成分で終わらないことの予告）
- 「どちらが優れているか」は**書かない**。事実だけ 🔒
- 数値の出典を `--muted` で小さく添える
- 3つを同じ形式で並べる。1つを強調しない

### ④ メール登録

**入力は3つまで。** それ以上は登録率が落ちる。

```
▌公開したらお知らせします

  メールアドレス          [                    ]

  どの成分を見たいですか?（複数選択可）
  [プロテイン] [クレアチン] [EAA/BCAA]
  [HMB] [鉄・亜鉛] [ビタミン] [その他]

  普段どこで買いますか?
  [楽天] [Amazon] [iHerb] [マイプロテイン] [店舗]

           [ 登録する ]

  お送りするのは公開のお知らせのみです。いつでも解除できます。
```

## 8. モバイル最適化

**想定流入の大半はスマートフォン。モバイルを主として設計する。**

| 項目 | 指示 |
|---|---|
| ファーストビュー | H1 + トグル + 上位3行 + CTA が**スクロールなしで入る**こと（390×844 で検証） |
| ヒーローの行 | 2段組み（1段目: 製品名・含有率 / 2段目: 変動バッジと単価を右寄せ大きく） |
| トグル | 横幅いっぱいの2分割。押し間違えない大きさ |

| 物差し | 高さを圧縮。ドットのタップ領域は 44px 維持 |
| CTA | ヒーロー内 + フォーム直上 の2箇所。**追従バーは置かない**（圧迫感が出る） |
| タップ領域 | すべて 44px 以上 |
| フォント | 本文 16px 未満にしない（iOS のズーム発動を防ぐ） |

## 9. アクセシビリティ（実装の下限）

- ランキングは `<ol>` でマークアップする。順位は意味を持つ
- 順位変動を**色だけで表現しない**。三角記号 + 数値を併記する
- トグルは `role="radiogroup"`。並べ替え後に `aria-live="polite"` で結果件数を通知する
- キーボードフォーカスを可視化する。`:focus-visible` に 2px `--signal` のアウトライン
- `prefers-reduced-motion: reduce` を尊重（並べ替えアニメーションを無効化）
- コントラスト比 4.5:1 以上
