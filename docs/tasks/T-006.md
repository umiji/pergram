## 目的

`robots.txt` が `Disallow: /` で全面クロール拒否のため、検索エンジンにも
LLM にも一切認識されていない。validation-plan.md の判定が「継続 → SEO 起点に
切り替え」に振れたときに慌てて用意するのではなく、**LP だけ先にクロールを開け、
LLM 時代の流入経路（ChatGPT / Claude / Perplexity 等の回答内での引用）に必要な
機械可読の土台を今のうちに敷く。**

現状 sitemap.xml / llms.txt / JSON-LD はいずれも存在しない（`grep` で0件）。

## 決定ログ

### 2026-08-18 LP のみクロール許可し、製品一覧は Disallow のままにする
- 決定: `/ja/` を Allow、`/ja/protein/` を Disallow。AI クローラ（GPTBot /
  ClaudeBot / PerplexityBot / Google-Extended / CCBot 等）は学習系も含めて全許可
- 却下案: ①全ページ許可＋プレースホルダ行に `data-nosnippet` → `data-nosnippet` は
  Google のスニペットにしか効かず、GPTBot 等の取得自体は止められないため
  「偽の金額を LLM に読ませない」を満たさない。②全部そのまま許可 → 同上でリスクが残る
- 付帯条件: `Disallow` はクロールを止めるがインデックス登録は止めない。LP から
  `/ja/protein/` へリンクがあるため Google が URL のみで登録する可能性が残る。
  完全に消すには `noindex` メタが要るが、それはクロールを許可しないと読まれないため両立しない。
  被リンクゼロの新規サイトのため確率は低いと判断して受け入れる
- 出典: session decision, no artifact

### 2026-08-18 公開範囲を1つの定数から robots / sitemap / llms の3ファイルに導く
- 決定: `src/build/crawl.js` に公開ポリシーを1つ置き、3ファイルすべてをそこから生成する
- 却下案: ファイルごとに別モジュールへ分ける → robots.txt で Disallow した URL を
  sitemap.xml に載せる、という自己矛盾が静かに起きる。実際に多いミスであり、
  同居させればテストで固定できる
- 出典: session decision, no artifact

### 2026-08-18 LP のヒーローには ItemList を付けない
- 決定: JSON-LD は LP に WebSite / Organization、製品一覧に BreadcrumbList / ItemList
- 却下案: LP のヒーロー3件を ItemList にする → `HERO_PRODUCT_IDS` の β版暫定措置で
  表示順が実際の単価順と一致していない。人間が読む分には「Sample」と明示してあるが、
  構造化データにすると誤った順位を機械可読で断言することになる
- 出典: CLAUDE.md「ヒーローのランキングカードの例外」/ src/templates/lp/hero.js:6-7

### 途中で見つけて直した不具合

JSON-LD のエスケープ処理で `'<'` と書くべきところが `'<'` の
単一バックスラッシュ（= JS では文字 `<` そのもの）になっており、置換が
無効化されていた。製品名に `<` が入ると `<script>` がそこで打ち切られ、
**構造化データが丸ごと壊れたうえページ本体の描画も崩れる**。
`tests/render.test.js` の「🔒 JSON-LD の中で < をエスケープする」が検出した。

```
$ curl -sL -o /dev/null -D- https://pergram.pergram-official.workers.dev/robots.txt
HTTP/1.1 301 Moved Permanently
Location: https://pergram.site/robots.txt
HTTP/1.1 200 OK
Content-Type: text/plain; charset=utf-8

$ curl -sL -o /dev/null -D- https://pergram.pergram-official.workers.dev/sitemap.xml
HTTP/1.1 301 -> https://pergram.site/sitemap.xml
HTTP/1.1 200 OK
Content-Type: application/xml

$ curl -sL -o /dev/null -D- https://pergram.pergram-official.workers.dev/llms.txt
HTTP/1.1 301 -> https://pergram.site/llms.txt
HTTP/1.1 200 OK
Content-Type: text/plain
```

3ファイルとも本番で 200 を返し、Content-Type も想定どおり。
`sitemap.xml` の `<loc>` と `robots.txt` の `Sitemap:` 行は、いずれも
`https://pergram.site/` を指している（**独自ドメインは取得済みで、
`workers.dev` は 301 で転送される**）。

### ⚠️ ただし、本タスクの目的は本番では達成されていない

**Cloudflare が管理する robots.txt の断片が、このリポジトリの出力より前に前置されており、
主要な AI クローラを `Disallow: /` で全面ブロックしている。**

```
User-agent: GPTBot
Disallow: /
（同様に ClaudeBot / CCBot / Google-Extended / Applebot-Extended /
  Bytespider / meta-externalagent / Amazonbot も Disallow: /）

User-agent: *
Content-Signal: search=yes,ai-train=no,use=reference
Allow: /
```

robots.txt は**自分の名前に一致するグループだけ**を読む規約なので、GPTBot や ClaudeBot は
このリポジトリが出す `User-agent: *` の行を**見ない**。`src/build/crawl.js` のコメントが
「🔒 ここを塞ぐと LLM の回答内に pergram が出てこなくなります」と固定している状態に、
**本番はまさに陥っている。**

**完了条件1〜5はいずれも `dist/` の生成物に対するものなので、達成として本タスクは閉じる。**
本番側の是正は Cloudflare ダッシュボードの操作であり、リポジトリ内では直せない。
**別タスク [T-021](T-021.md) として起票した。**
