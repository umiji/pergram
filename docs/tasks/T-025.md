## 目的

**T-011 のレビューが Minor と判定した4件を、まとめて片付ける。**

**いずれも単独では急がない。** T-011 のレビューは「条件付き通過」で、
**通過を妨げていたのは Major 1件（live region）だけ**であり、それは T-011 内で修正済み。
本タスクは残りである。**まとめてあるのは、4件とも同じ2ファイル
（`src/assets/lp.js` / `worker/waitlist.js`）の中にあり、別々に走らせると衝突するため。**

| ID | 対象 | 内容 |
|---|---|---|
| **R-011-2** | `src/assets/lp.js:248-249` | **ステップ2送信後にフォーカスが行き場を失う。** `stepTwo.hidden = true` の時点でフォーカスはその中の送信ボタンにあり、`<body>` に落ちる。**キーボード利用者の次の Tab が文書の先頭へ戻る。** ステップ1は `doneEl.focus()` で受け皿を用意しているのに、ステップ2は用意していない（同一ファイル内で非対称） |
| **R-011-3** | `src/assets/lp.js:197-211` / `:230-254` | **保存に成功しているのに「送信できませんでした」と表示されうる。** `.catch` が `.then` の後ろにあるため、送信成功後の処理（`track()` / `doneEl.hidden` / `focus()`）で例外が出ると、**POST は成功しているのにエラー文言を出してボタンを戻す。** ステップ1で起きると完了状態に切り替わらず、**利用者はステップ2に到達できない** |

| **R-011-6** | `src/assets/lp.js:219` | **ステップ2の送信が無言で終わる分岐がある。** `if (!registeredEmail) return;` はボタンを `disabled` にする前なので固まりはしないが、**押しても何も起きず、画面にもログにも何も残らない。** 通常フローでは到達しないが、到達したときに調べる手がかりが無い |

## 禁止事項

- 🔒 **UPSERT の SQL を変えない**（`COALESCE(NULLIF(excluded.x,''), waitlist.x)`）。**レビューが独立に検証して「正しい」と判定している。** R-011-5 で足すのは**根拠の記録と検査**であって、SQL の変更ではない
- 🔒 **保存列を増やさない**（`email` / `nutrients` / `channel` / `nutrients_other` / `requests` / `created_at` の6列）
- 🔒 **`registeredEmail` を DOM へ出さない。** クロージャに持つ現行の設計は、レビューが「明確に良い設計」と評価している（GA4 にも他スクリプトにも漏れない）
- 🔒 **GA4 に自由記述の本文やメールアドレスを送らない**（0/1 だけ）
- 🔒 **`<fieldset>` / `<legend>` の構造と `form.js:92-96` のコメントを消さない。** 理由が書かれており、消すと次の担当が「整理」して変更範囲外のテストを落とす
- 🔒 **T-011 が解いた live region（`role="status"`）の扱いを戻さない**
- 🔒 **エラー文で謝らない。** 何が起きて、どうすれば直るかだけを書く（`.claude/rules/pergram-ui-copy.md`）
- `src/styles/` `src/templates/` `locales/*.json` を触らない

## 完了条件

1. **ステップ2の送信後、フォーカスが `<body>` に落ちていない**（文脈のある要素に留まっている）
2. **保存の成否と、成功後の画面更新・計測の失敗が、利用者から見て混ざらない。**
   具体的には、`track()` や DOM 操作で例外が出ても、**POST が成功していれば
   「送信できませんでした」を出さない**

   （`freeText()` が `null` を返し `join(',')` が `''` を返すという対応関係）
5. **`freeText()` が空文字を返すよう変わったら落ちる検査**が `tests/waitlist_upsert.test.js` にある
6. 上記1〜3 が自動テストで判定できる
7. `npm test` が通っている（**着手時点の件数から減らさない**。着手時に自分で数え、
   その値を `## 証拠` に書くこと）
