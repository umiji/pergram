## 目的

**T-017 が主CTA（`--signal`）のコントラストを直した結果、同じ問題が `--verified` の側にだけ
取り残された。**

修正前は `--signal` と `--verified` がどちらも `#ea580c` で同値だったため、**1つの問題として
見えていた。** T-017 が `--signal` だけを `#c2410c` へ動かしたことで、
**`--verified` を使う4箇所が単独で AA 未達として残った。**

| 箇所 | 実効色 | 実測 | 要 |
|---|---|---|---|
| `.p-item__best`「1gあたり最安」 | `#fff` on `rgb(234,88,12)` | **3.56:1** | 4.5 |
| `.p-item__rank` 順位の数字 | 同上 | **3.56:1** | 4.5 |
| `.p-item__cost-label`「タンパク質1gあたり」 | `rgb(234,88,12)` on tint | **3.10:1** | 4.5 |
| `.p-item__delta`「最安基準」 | 同上 | **3.10:1** | 4.5 |

**`.p-item__best` / `.p-item__rank` は「白文字を橙に載せて 3.56:1」であり、
T-017 の完了条件1 とまったく同じ不具合の型である。**

🔒 **この4箇所は、この製品の中核そのものである。** 「1gあたり最安」の印と順位の数字は、
pergram が何をする道具なのかを一目で伝える要素であり、**読めないことの害が最も大きい面**である。
加えて `.claude/rules/pergram-ui-copy.md` は「UL 超過・認証の有無・最安を**色だけで表現しない**」と
定めており、**色が読めない状態はその前提を崩す。**

**T-017 が悪化させたものではない**（着手前と同じ値であり、T-017 の完了条件6「他ボタンが
悪化していない」には抵触しない）。**T-017 の変更範囲外だったため、正しく触られずに報告された。**

## 禁止事項

- 🔒 **色をコンポーネントへ直書きしない。** `src/styles/tokens.css` が唯一の出所である
- 🔒 **`--verified` を `--signal` と同値にしない。** T-017 の実装担当が
  **敢えて同値にしない**と決めている（「操作の橙とデータ強調の橙を明度で読み分けさせる」。
  `tokens.css` の当該箇所と T-017 の決定ログに理由がある）。
  **統合すると、その読み分けが消える**
- 🔒 **T-017 が確定させたコントラスト比を下げない。** `tests/styles.test.js` の既存のテストを
  緑のまま保つこと
- 🔒 ブランドの視覚的な一貫性を壊さない。**橙系の主張は保つ**（別系統の色へ振り替えない）
- 🔒 **文字を小さくして「大きな文字」の緩和基準（3:1）へ逃げない。** 背景色側で解く
- 🔒 **`--line` を濃くして `.btn--ghost` の輪郭を道連れで直そうとしない。**
  `--line` はカード・セクション・表の装飾罫線として全面的に使われており、
  サイト全体の罫線がボタンと同じ濃さになる（T-017 の実装担当が検討して却下している）
- `src/templates/` を触らない

## テスト方法

**単体（スタイルの不変条件）はこのタスクの担当が書く。**
`tests/styles.test.js` に、T-017 が作った WCAG の相対輝度の計算がすでにある。**それを使う。**
🔒 **依存パッケージを追加しない。** このリポジトリは依存ゼロで動いている。

**実環境での確認が要る**（`/ja/protein/` の実描画）。**実施者はテスト担当。**
測り方は T-017 の `## 証拠` に手順がある —— `dist/` を**ローカル HTTP で配信**し
（🔒 `file://` で開くと CSS が絶対パスのため当たらず、**エラーにならないまま観測が誤る**）、
Chrome を `--remote-debugging-port` で起動して DevTools Protocol から実効色を取る。
モバイル幅は `Emulation.setDeviceMetricsOverride`（`mobile:true`）、
ホバーは `CSS.forcePseudoState`。**`--window-size` だけでは meta viewport が無視される。**

## 申し送り

**T-017 の実装担当は、`--verified` を紙地の文字に使う場合（3.41:1）が AA 未達であることは
申告していた。しかし白文字を橙に載せる側（3.56:1、`.p-item__best` / `.p-item__rank`）は
申告に含まれていなかった。** 見つけたのは実環境確認をした**テスト担当**である
（製品一覧の「橙の上の文字／橙の文字」を全要素走査した）。

**したがって、`--verified` を使う箇所が上の4つで全部だという保証は、その走査の範囲までである。**
着手したら**自分でもう一度走査すること。**

**T-022（待機リストのステップ2の表示崩れ）も `src/styles/` を触る。同時に走らせない。**
**T-018 も同様。**

**`products.css` の `.btn--ghost` の輪郭 1.23:1 が別途残っている**（T-017 の実装担当が
申告・変更範囲外）。**このタスクの完了条件には入れていない** —— 解き方が
（`--line` を濃くする＝サイト全面に波及する）別の判断を要するためである。
**ついでに直さないこと。** 気づきとして報告に書けばよい。
