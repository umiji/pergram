## 目的

キャンペーン・広告グループ・キーワード・広告文・UTMを、
[docs/ops/google-ads-first-campaign.md](../ops/google-ads-first-campaign.md) フェーズ1〜3の指定どおりに入稿する。

**このタスクは薬機法・景表法に直結する。** 広告文は pergram が外に出す文章の中で最も規制リスクが高い。
成分の効能・効果に触れた時点で N-02 違反であり、広告の否認では済まない。

## 変更範囲

コード変更なし。Google広告管理画面の入力のみ。

| 項目 | 値 |
|---|---|
| キャンペーンタイプ | 検索 |
| ネットワーク | ディスプレイ・検索パートナーの**チェックを外す** |
| 地域 / 言語 | 日本 / 日本語 |
| 予算 | ¥500 / 日 |
| 入札 | 手動CPC、または上限CPC付き「クリック数の最大化」 |
| 広告グループ | 1つのみ（この規模でA/Bテストは統計的に成立しない） |
| マッチタイプ | 完全一致・フレーズ一致のみ。部分一致は使わない |

## 禁止事項

- 🔒 **禁止語を広告文に一切使わない**: 効く / 効果 / 改善 / 高品質 / おすすめ / 人気No.1 / 安心 / 話題の / 選ばれる / 実感
- 🔒 成分の効能・効果に言及しない（N-02）。製品・成分の優劣を述べない
- 🔒 除外キーワードに 育毛 / 薄毛 / AGA を必ず入れる（N-09）
- ブランド表記は `pergram`（全て小文字）。`Pergram` / `PerGram` と書かない
- 初回接触面なので、**タグラインとセットで出す**（「1gあたり、いくら払ってる?」）
- 部分一致キーワードを使わない。無関係な検索に予算を溶かす

- 広告文の禁止語チェックは人間が目視で行う。自動テストの対象外（広告文はリポジトリ内に無いため）
- UTMが正しく効くかの検証は T-004（配信後のGA4リアルタイム確認）で行う。ここでは設定値の一致確認まで

## 決定ログ

### 2026-08-18 UTMは「最終ページURLの接尾辞」に入れる（トラッキングテンプレートは使わない）
- 決定: キャンペーン設定の**最終ページURLの接尾辞**に `utm_source=google&utm_medium=cpc&utm_campaign=protein_unitcost_test&utm_term={keyword}` を入れる。
  トラッキングテンプレートとカスタムパラメータは**全階層で空欄**のままにする
- 却下案: トラッキングテンプレートに `{lpurl}?utm_source=...` を入れる案（同じ着地URLになる定番のレシピ）
  → 却下理由は2点。(a) テンプレートは本来クリックを外部の計測サーバに一度通すための欄で、
  GA4 に直接送る今回は経由させるものが無い。(b) 並列トラッキング（parallel tracking）下でも
  着地ページのURLにパラメータが確実に残るのは接尾辞の側であり、Google が計測用途に推奨しているのもこちら
- 🔒 **接尾辞の欄には `{lpurl}` も先頭の `?` も書かない。**書くと `?` が二重になった壊れたURLになる。
  「接尾辞 = トラッキングテンプレートから先頭の `{lpurl}?` を取り除いたもの」
- 付帯条件: アカウント設定の**自動タグ設定（auto-tagging）をオンに保つ**。
  オフだと `gclid` が付かず、T-002 で行ったGA4リンクとコンバージョンインポートが機能しない
- 出典: [Add a Final URL suffix - Google Ads Help](https://support.google.com/google-ads/answer/9054021)

### 2026-08-18 広告バリアントは1つだけにする
- 決定: 広告グループ1つ・広告文1バリアントで出す
- 却下案: 複数バリアントでA/Bテストする案 → 日予算¥500 × 7日の規模では、
  バリアント間のCTR差が統計的に有意にならず、判断材料にならないため
- 出典: [docs/ops/google-ads-first-campaign.md](../ops/google-ads-first-campaign.md) (2-1)
