# T-003: Google広告 キャンペーン設計と広告文入稿

- 依存: T-002（ブロッカー: アカウントと支払いが無いとキャンペーンを作れない）

## 目的

キャンペーン・広告グループ・キーワード・広告文・UTMを、
[docs/ops/google-ads-first-campaign.md](../ops/google-ads-first-campaign.md) フェーズ1〜3の指定どおりに入稿する。

**このタスクは薬機法・景表法に直結する。** 広告文は pergram が外に出す文章の中で最も規制リスクが高い。
成分の効能・効果に触れた時点で N-02 違反であり、広告の否認では済まない。

## 変更範囲

コード変更なし。Google広告管理画面の入力のみ。

| 項目 | 値 |
|---|---|
| キャンペーンタイプ | 検索 |
| ネットワーク | ディスプレイ・検索パートナーの**チェックを外す** |
| 地域 / 言語 | 日本 / 日本語 |
| 予算 | ¥500 / 日 |
| 入札 | 手動CPC、または上限CPC付き「クリック数の最大化」 |
| 広告グループ | 1つのみ（この規模でA/Bテストは統計的に成立しない） |
| マッチタイプ | 完全一致・フレーズ一致のみ。部分一致は使わない |

## 禁止事項

- 🔒 **禁止語を広告文に一切使わない**: 効く / 効果 / 改善 / 高品質 / おすすめ / 人気No.1 / 安心 / 話題の / 選ばれる / 実感
- 🔒 成分の効能・効果に言及しない（N-02）。製品・成分の優劣を述べない
- 🔒 除外キーワードに 育毛 / 薄毛 / AGA を必ず入れる（N-09）
- ブランド表記は `pergram`（全て小文字）。`Pergram` / `PerGram` と書かない
- 初回接触面なので、**タグラインとセットで出す**（「1gあたり、いくら払ってる?」）
- 部分一致キーワードを使わない。無関係な検索に予算を溶かす

## 完了条件

1. キャンペーン設定が上記の表どおりになっている（ネットワークのチェックが外れていることを含む）
2. キーワード6語が完全一致・フレーズ一致で登録されている
3. 除外キーワード7語（効果 / 副作用 / 飲み方 / おすすめ / ランキング / 育毛 / 薄毛 / AGA）が登録されている
4. 入稿した広告文の全文が `## 証拠` に記録され、禁止語リストと照合済みである
   - 照合方法: `tests/render.test.js` の `BANNED_WORDS` を目視で当てる
5. キャンペーン設定の「最終ページURLの接尾辞」に以下が入っている（**忘れやすい**）
   ```
   utm_source=google&utm_medium=cpc&utm_campaign=protein_unitcost_test&utm_term={keyword}
   ```
6. リンク先URLが `/ja/` である（LPは階層下に置いていない）

## テスト方法

- 広告文の禁止語チェックは人間が目視で行う。自動テストの対象外（広告文はリポジトリ内に無いため）
- UTMが正しく効くかの検証は T-004（配信後のGA4リアルタイム確認）で行う。ここでは設定値の一致確認まで

## 停止条件

- §4の共通のものに加えて:
- 広告文の案が禁止語・効能表現に触れそうで判断がつかない場合、入稿せずに停止して確認する。
  **迷ったらより保守的な方を選ぶ**
