## 目的
薬機法・景表法に対する機械的な砦がいまゼロである。`.media-agent/x/pergram-jp/rules.md` の
「## 禁止表現」13語が、生成物の検査で **1語も拾われていない**（T-032 §2 G-05）。
`core/rules.py` の `_BULLET` が箇条書き（`- ` 始まり）しか読まないのに、当該節が素の行で書かれているため。

実測で `効果` / `高品質` / `中身がスカスカ` / `あなたは不足しています` のいずれも `violation()` が
`None`（違反なし）を返す。**AI に本文を書かせる運用を再開した瞬間、禁止語が素通りする。**
所要15分で、失敗しても壊れるものが無い。Day1 に入れるべき最優先の手当て。

- `.media-agent/x/pergram-jp/rules.md` の「## 禁止表現」節の書式のみ
- 検証用スクリプト（置き場は判断してよい範囲）
