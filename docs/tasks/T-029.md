## 目的
製品名が楽天の生データのまま入っている（例:「【クーポンで2,052円 8月17日AM9:59まで】( 女性用 ソ…」）。
**この状態でスクリーンショットを X に出すと、比較サイトとしての信用を落とす。**
販促の飾り・期限・セット数の表記が本体名に混ざっており、比較表として読めない。

## 変更範囲
- 表示名を整える処理と、そのデータ（`data/product_i18n.json` または表示名の導出処理）
- 対応する単体テスト

## 禁止事項
- `data/products.json` の `id` を変更すること（名寄せが壊れる）
- 価格・含有量・元素量に手を入れること
- 推測でブランド名を補うこと（46製品中29件は `brand` が null。**空欄のままが正しい**）

## 完了条件
1. 製品一覧に出る表示名から、角括弧の販促文言・期限・「送料無料」等の飾りが除かれている
2. 46製品すべてについて、整形後の表示名が40文字以内に収まっている
3. 整形の入出力を検証する単体テストがあり、`npm test` が通る
4. 整形前後の一覧が差分として確認できる

## 判断してよい範囲
- 除去の実装方法（規則ベースか、表示名を別に持つか）
- 40文字に収まらない場合の切り詰め方

## テスト方法
単体: 代表的な汚れた名前を入力として整形結果を検証。回帰: `npm test`。実環境確認: 不要。

## 停止条件
- 規則ベースで落とすと製品の識別ができなくなる（同名になる）製品が出た → オーケストレーターへ上げる
