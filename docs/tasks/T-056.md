## 目的

`src/styles/lp.css:679-686` に、`site.css` と**同じ値**の指定が2つ残っている
（`justify-items: stretch` と `.waitlist-band .request-band__button { width: 100% }`。
出所は `src/styles/site.css:374` と `:381`）。

**T-053 は同じブロックの `:first-child` の規則を「値が同じなので写すと2つ目の出所になる」
という理由で削除した。** 残り2行にはその判断が適用されていない。

`.request-*` は LP と製品一覧の共用部品で、**出所が2つに割れていたことが T-051 の発端**である。
site.css 側を変えたとき、LP だけが古い値で固まる。

## 変更範囲
- `src/styles/lp.css` の `.waitlist-band .request-*` の上書き規則のみ
- `tests/panel_unify.test.js`（または `tests/styles.test.js`）— 検査の追加
- `docs/design/design.md` §3 の T5 と「行送りを明示する」の記述の食い違いのみ

## 禁止事項
- `src/styles/site.css` を変えない（このタスクは重複を消すものであって、共通側の値を変えるものではない）
- LP の見た目を変えない。**削除後も LP の要望の帯が全幅1列のままであること**が前提
- `lp.css` 冒頭の 🔒（段そのものは site.css が唯一の出所）に反する追記をしない
