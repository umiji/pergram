## 目的
**出す前に機械が止める仕組みが無い。** Buffer は一度登録した投稿を API から削除も更新もできないため、
**間違いは出てから直せない。** 検査を登録の前に置くのはこの理由による。

現状、9/3 の下書きは `BufferConnector` を直接呼ぶスクリプトで入れており、
**承認キュー・1日2本の上限・重複判定のいずれも通っていない**（T-032 G-01 / G-02）。

- タスク台帳 CSV への書き込み

## 完了条件
次の6つのそれぞれについて、**検査が非ゼロ終了する**単体テストが通ること。
1. `rules.md` の禁止表現を含む
2. X の重み付き280字を超える（CJK は1文字2）
3. リンクが2本以上ある
4. 網羅を示す語（全メーカー / 全製品 / すべての / 網羅 等）を含む
5. 同じ日の3本目である（`content.posts_per_day` = 2）
6. 台帳内の既存行と重複する（`content.similarity_threshold` = 0.85 を出発点にしてよい）

加えて、**上記のどれにも当たらない本文では終了コード0を返す**テストが通ること。
