## 目的

**PO 報告（2026-09-08）:**

> Request signal に id, created_at は追加されてるが、メールアドレス入力をしないと waitlist 側に
> レコードが追加されてない。メールアドレス追加しなかった場合もアンケート内容がレコードに
> 追加されるようにしておいてくれ。

**これは仕様どおりの挙動である。** `src/assets/request.js` の 🔒 にこう書いてある ——
「アンケートの回答は、メールアドレスの段を送ったときに相乗りする
（**メールアドレスが無ければ保存しない。保存の鍵がそれしかない**）」。

`waitlist` は `email` が主キーなので（`worker/schema.sql`）、**メールアドレスの無い行は
物理的に入らない。** つまり導線はこうなっている。

| 利用者の行動 | いま残るもの |
| --- | --- |
| ボタンを押す | `request_signal` に1行（id / created_at / page） |
| 成分アンケートに答える | **何も残らない** |
| メールアドレスを入れる | `waitlist` に1行（回答も相乗り） |

**「押した → 成分を答えた → メールは入れない」人の回答を、いま全部捨てている。**
次に何を載せるかを決めるための情報そのものであり、`docs/research/validation-plan.md` の
「成分アンケート回答率」の分子でもある。
