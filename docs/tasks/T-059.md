# T-059: 本文の文字サイズが規約（16px 未満にしない）と実装（12.5px）で食い違う

## 目的

**規約と実装が正面から食い違っている。**

| 出所 | 言っていること |
|---|---|
| `.claude/rules/pergram-ui-copy.md` | 「モバイルを主とする。タップ領域 44px 以上、**本文 16px 未満にしない**」 |
| `src/styles/tokens.css` の `--size-sm` | **12.5px** |
| `docs/design/design.md` §3 の T3（本文・リード） | `--size-sm` = **12.5px** |

**リード文・注記・広告表示・解説の本文が、規約の下限を下回っている。**
`--size-base`（16px）は入力欄など一部にしか使われていない。

**これは1要素だけ直せる問題ではない。** T-053 が字送りの階層（T1〜T6）を作って
「同じ役割の文字が段ごとに違う」状態を直したばかりで、**1要素だけ大きくすると
その不揃いへ戻る。** 階層そのものの見直しになる。

規約と実装のどちらが正しいのかも決まっていない。**規約を実態へ合わせるのか、
実装を規約へ合わせるのかは、読みやすさとレイアウトの両方に影響する判断である。**

## 変更範囲

- `src/styles/tokens.css` — 型スケール（`--size-*`）
- `src/styles/site.css` / `products.css` / `lp.css` — 字送りの適用箇所
- `docs/design/design.md` §3（字送りの階層 T1〜T6）
- `.claude/rules/pergram-ui-copy.md` — 下限の記述
- `tests/panel_unify.test.js` — 決めた値を固定する検査

## 禁止事項

- 🔒 **色のトークン（`--signal` / `--signal-hover` / `--line-control` / `--muted-*`）の値を
  変えない。** WCAG のコントラスト比が根拠である（`tokens.css` の 🔒 コメント）
- **1要素だけ大きくして終わりにしない。** T-053 が揃えた階層が壊れる
- **文言を変えない。** 文字を大きくして入らなくなったからといって文を削らない
  （注記は法令順守に関わる。`.claude/rules/pergram-compliance.md`）
- T-053 / T-057 が達成した面の統一と帯の組版を壊さない
