## 目的
4段の①。**題材を問わず**、いま X で表示回数が伸びている投稿の型を集める。pergram の題材（価格・成分）に近いかどうかで選ばない —— 借りるのは骨組みであって題材ではない。2026-09-08 の実行では題材で絞り込み、価格比較ジャンルへ寄せた結果、母集団が小さくなって骨格が0本になった。

## 変更範囲
- `.media-agent/x/pergram-jp/data/`（観測の追加）
- `.media-agent/x/pergram-jp/method-log.md`（新規。リサーチの記録）

## 禁止事項
- **クエリを pergram の題材（価格・単価・プロテイン・成分）で絞らない。** 自ジャンルのクエリは枠の半分以下
- `personas/` `strategy.md` を参照して題材を絞らない（照合は③の仕事）
- `structures/` を書かない（②の仕事）
- 投稿しない
- `config.yaml` の `x_reader.pacing` を勝手に上げない（PO 判断）

## 完了条件
1. 同じ仕事を切り出せたクエリのプールが、**1テーマあたり25件以上**の観測を持つ
2. そのプールで、表示回数の中央値×3以上 かつ 反応率がプール中央値以上 を満たす投稿が、**3本以上 / 3著者以上**あるテーマが 3つ以上ある
3. 各テーマについて、プールした全クエリ・件数・表示中央値・反応率中央値・伸びた群の本数と著者数が `method-log.md` に表で残っている
4. 骨格にしなかったテーマと、その理由（件数不足 / 著者が偏った / プールを混ぜた）も同じ表にある
5. `media-agent x doctor` の当日枠を超えていない
