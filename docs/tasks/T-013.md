# T-013: 「格安」系クエリの反応を広告文とLPの見出しに反映する

- 更新日: 2026-09-02

- 依存: T-008（ブロッカー: 入札単価と広告文を同時に変えると、どちらが効いたか分からなくなる）

## 目的

配信初期の実測で、クリック率が突出したのは「格安」を含む検索語だった。

| 検索語 | クリック率 |
|---|---|
| 格安 プロテイン | **10.34%** |
| プロテイン 格安 | 4.69% |
| プロテイン コスパ ランキング | 5.88% |
| （広告全体） | 3.25% |

全体の3倍以上の反応が出ている。この層は**絶対額の安さを探しており**、
[T-009](T-009.md) で判明した「ヒーローが実データの5倍の単価を出している」問題とも
最も強く衝突していた層でもある。

`格安` `安い` は禁止語リスト（`tests/render.test.js` の `BANNED_WORDS`）に含まれておらず、
[validation-plan.md §4](../research/validation-plan.md) も「『安い』『単価』『比較』のみで訴求する」
と明記している。**使える語である。**

## 変更範囲

| 場所 | 変更内容 |
|---|---|
| Google広告の広告文 | 見出し・説明文に「格安」系の語を検討する |
| `locales/*.json` | LPの見出し（`lp.h1` / `lp.lede`）を検索語と揃えるか検討する |
| 入札キーワード | `格安 プロテイン` / `プロテイン 格安` の優先度を上げる |
| `docs/ops/google-ads-first-campaign.md` | 入稿した最終文言を (6-1) の記録として残す |

## 禁止事項

- 🔒 **禁止語を使わない。** `効く` `効果` `改善` `高品質` `おすすめ` `人気No.1` `安心` `話題の`
  `選ばれる` `実感`。「おすすめ」で検索して来てもらうのは構わないが、**こちらが発する言葉には使えない**
- 🔒 成分の効能・効果に一切言及しない（N-02）。優劣も述べない
- 🔒 数値には必ず単位と基準を添える（「¥38」ではなく「¥38 / タンパク質1g」）
- 🔒 文言をテンプレートに直書きしない。翻訳キー経由
- **入札単価と広告文を同時に変えない**（T-008 の禁止事項と対）
- 「業界最安」「最も安い」のような、確認できない優劣を書かない

## 完了条件

1. 広告文の変更案が作られ、禁止語リストに照らして確認されている
2. LPの見出しを変えるか変えないかが決まっており、変えるなら `npm test` が通っている
3. 入稿した最終文言が `docs/ops/google-ads-first-campaign.md` の (6-1) に記録されている
4. 変更後3日間のクリック率が記録され、変更前（3.25%）と比較されている
5. 🔒 出力に禁止語が含まれていない

## テスト方法

- `npm test`（LPを触った場合）
- Google広告の管理画面で、変更前後のクリック率を同じキーワード群で比較する

## 停止条件

- §4の共通のものに加えて:
- 広告が審査で否認された場合、理由を確認し**該当箇所のみ**修正して再提出する。
  文言全体を作り直さない（何が原因だったか分からなくなる）
- LPの見出しを変える判断になった場合、ブランドのタグライン
  （「1gあたり、いくら払ってる?」）を差し替えることになるなら相談する

## 決定ログ

### 2026-09-02 「格安」系の反応を活かすが、入札調整とは分けて実施する
- 決定: クリック率10.34%という実測を広告文とLPに反映する。ただしT-008の入札調整とは期間を分ける
