## 目的

X（旧 Twitter）のオーガニック投稿を、**思いつきではなく手順で作れるようにする。**

投稿文そのものはモデルが書くが、**落とす判断は機械に持たせる**。文字数・禁止語・
URL の位置・折りたたみ位置・過去投稿との重複は、目視ではなくコマンドで判定する。
薬機法・景表法の制約（N-01〜N-10・禁止語）が投稿にもそのまま掛かるため、
人の注意力に依存させない。

## 決定ログ

- **2026-08-21: 文字数は X の加重で数える。** 日本語1文字＝2、URL は長さに関わらず 23。
  素の `length` で数えると URL 付きの投稿だけが必ず溢れる
- **2026-08-21: アルゴリズムの根拠は公開コードだけを使う。** `xai-org/x-algorithm` の
  `home-mixer/params/param.rs`（2026-08-13/14 公開）。日本語記事に出回っている
  「リプライはいいねの75倍」「通報 -369」は旧版か別リビジョンで、実際の値と食い違う。
  実際は いいね 0.5 / リプライ 5.0（相互フォロー相手は +15.0 で 20.0）/
  リンクのコピー共有 20.0 / 通報 -234.0 / ミュート -58.8 / 興味なし -43.2。
  ブックマークとプロフィールクリックの重みは**存在しない（0.0）**
- **2026-08-21: 外部リンクのペナルティは公開コードに無い。** `OpenLinkWeight` はむしろ +0.2。
  1投稿目に URL を置かない運用は残すが、理由を「ペナルティ回避」から**機会費用**
  （1投稿目を会話 5.0〜20.0 に使う方が取り分が大きい）に変更した
- **2026-08-21: 折りたたみは行数で起きる。** 日本語は140文字が上限なので文字数では切れず、
  ブラウザは11行目以降が「さらに表示」の向こう側に入る。端末差があるので
  **9行以内なら全端末で全文 / 10行超は隠れる前提**の2択でしか扱わない
- **2026-08-21: トピック一覧が価格に偏っていたのを是正。** 当初13項目すべてが価格の
  言い換えで、何を選んでも単価の話になっていた。12カテゴリに作り直し価格系を2つに限定。
  🔒 単価の話は3本に1本まで
- **2026-08-21: ネタ帳の各行は「材料」であって投稿ではない。** 材料をそのまま書くと
  作業報告になる。読み手の持ち帰りへの変換を手順6として独立させた
- **2026-08-21: ペルソナは調査から起こす。** P-B「計算する人」は requirements.md §2.1 が
  中核ターゲットとして定義済み。P-A は指名検索74K、P-C は「おすすめ」90.5K が根拠。
  🔒 **需要の大きさでネタを選ばない** — 効果27.1K・飲むタイミング33.1K・おすすめ90.5K は
  N-02 / N-03 で扱えない。持ち場はコスパ・比較・単価の約15K だけ
- **2026-08-21: 戦略文書との優先順位。** `docs/Marketing/X_post_strategy.md` の例文は
  「コスパ最強」「神コスパ」「個人開発」を含み CLAUDE.md の禁止語に触れる。
  **戦略はあの文書、語彙は CLAUDE.md が勝つ**と skill に明記した
- **2026-08-21: ブランド表記は小文字に統一。** 依頼元のプロンプトは `Pergram` だったが
