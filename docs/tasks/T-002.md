## 決定ログ

### 2026-08-18 入札先をロングテール6語からコスパクラスタへ変更 🔒
- 決定: 入札キーワードをコスパクラスタの主軸7語（`プロテイン コスパ` / `コスパ プロテイン` /
  `プロテイン コスパ 最強` / `コスパ 最強 プロテイン` / `プロテイン おすすめ コスパ` /
  `プロテイン コスパ おすすめ` / `プロテイン コスパ 最強 ランキング`）に差し替える。
  補助として `タンパク質 コスパ`（**競合性 Low**）等を追加
- 理由: 当初指定の6語はキーワードプランナー実測で**合計しても月200回未満**（うち4語はデータなし）。
  7日配信では検索が数十回しか起きず、目的①（成分需要）②（CVR）が測定できない
- 一方コスパクラスタは最上位バケット（月 1,000〜10,000）が7語あり、ページ上部入札単価 ¥6〜¥49。
  **日予算 ¥500 で当初設計の 100〜150 クリックに届く見込みが立った**
- 却下案: 6語のまま配信する → 目的③（審査通過可否）しか得られず、7日の配信期間が無駄になる
- 影響: [validation-plan.md](../research/validation-plan.md) 段2 の 🔒「入札先はロングテールに
  する」の改定を伴う。原則（本番で戦う場所と同じ場所でテストする）は変えず、適用先を
  段0 が「攻略可能」と判定済みのコスパクラスタ（約15K / KD 18〜25%）に修正した
- **製品としての GO/中止 判定は変わらない**（ヘッド層 22万超で GO 済み）。段0 が事前に置いた
  「比較クエリは需要ではなく既存の習慣を測っている」という仮説どおりの結果

### 2026-08-18 除外キーワードから `おすすめ` `ランキング` を外す
- 決定: 除外キーワードを8語から6語（`効果` `副作用` `飲み方` `育毛` `薄毛` `AGA`）に減らす
- 理由: 旧版の除外理由「情報収集意図が強く CVR が落ちる」は**物を売る場合の常識であり、
  メール登録を測るテストには当てはまらない**。買う直前の人は買って帰るだけで登録の動機がなく、
  調べている段階の人のほうが「準備できたら教えて」に応じる動機が強い。加えて目的①を測るなら
  買う直前の人に絞るのはサンプルを偏らせるだけ。実務上も `ランキング` の除外は最大の流入口
  **最上位バケット7語のうち3語**（`プロテイン おすすめ コスパ` / `プロテイン コスパ おすすめ` /
  `プロテイン コスパ 最強 ランキング`）を巻き添えで塞いでいた。最大の在庫の4割強にあたる
- 除外の判断基準を「情報収集の段階かどうか」から **「そのページに答えがあるか」** に置き換えた。
  `効果` `副作用` `飲み方` はその検索に合った広告文が書けない（`効果` は禁止語、
  飲み方・副作用はページに記載なし）ため残す
- 🔒 `育毛` `薄毛` `AGA` は N-09 により**費用の問題ではないので絶対に外さない**
- 🔒 「除外から外す」と「入札する」は別。`プロテイン おすすめ` 単体（月9万回）には入札しない
