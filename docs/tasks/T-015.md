## 目的

`locales/en.json` の `lp.ctaNote` に **"Unsubscribe at any time."** が入っている。
**配信停止の窓口は実装されていない。** できないことを約束している状態である。

`tests/render.test.js` に「🔒 できないことを書かない」という不変条件のテストが既にあるが、
**ja しか見ていないため en が素通りしている。** T-010 の実装担当が ja 側で同じ文言を書いて
RED を踏んだことで発見された。

提供できない条件を表示していることになり、景表法の観点で放置できない。

## 変更範囲

| ファイル | 変更内容 |
|---|---|
| `locales/en.json` | `lp.ctaNote` から配信停止の約束を外す |
| `tests/render.test.js` | 「できないことを書かない」の判定を **ja / en の両方**へ広げる |

## 禁止事項

- 🔒 配信停止の窓口を**実装しない**（範囲外。文言を実態に合わせるだけ）
- 🔒 既存の不変条件テストを弱めない。**対象言語を増やす方向にだけ変える**
- 🔒 文言をテンプレートに直書きしない。`locales/*.json` 経由
- `src/` を触らない見込み。触る必要が出たら報告する

## 完了条件

1. `locales/en.json` の `lp.ctaNote` に、配信停止・解除を約束する表現が無い
2. **「できないことを書かない」の判定が、描画結果ではなく `locales/*.json` を直接検査する形になっており、ja と en の両方を見ている**
   - **2026-09-02 にオーケストレーターが差し替えた条件である。** 旧条件は
     「`tests/render.test.js` の既存テストを ja / en 両方へ広げる」だった
   - 🔒 **差し替えた理由: T-020 により `lp.ctaNote` は全ロケールで描画されなくなった。**
     既存テストは `renderLp()` の**出力 HTML** を検査する作りなので、**`lp.ctaNote` は
     もう検査対象に入っていない。** 対象言語を増やすだけでは、**旧文言を戻しても
     落ちない空振りのテスト**ができあがる（T-020 のレビュー R-020-2）
   - 🔒 **既存の描画ベースの検査を弱めたり消したりしない。** `locales` 直接検査を
     **足す**。描画されている文言と、翻訳ファイルに眠っている文言の両方を見る
3. そのテストが、旧文言（"Unsubscribe at any time."）を `locales/en.json` へ戻すと**落ちる**ことを確認済み
   - 確認は実際に戻して走らせて行う。**戻したものは必ず元へ戻す**
4. `npm test` が通っている（**同じブランチで並行しているタスクの未完成分による失敗は、あなたの責任範囲ではない。その場合は失敗したファイル名を報告に書く**）
5. `npm run build -- --strict` が終了コード 0

## 申し送り

- **発見の経緯**: T-010 の実装担当が ja 側に同じ文言を書いたところ既存テストが落ち、
  en では素通りしていることが判明した。
- **T-010 の完了を待つこと。** `locales/en.json` を T-010 が触っている。


**🔒 `lp.ctaNote` は、もう画面に描画されていない。** T-020（ヒーローの CTA をβ版1本に絞る）が
ヒーローの注記を要素ごと出力しなくなったため、`lp.cta` と `lp.ctaNote` は
**`src/` からも `tests/` からも参照されていない**（`git grep` で `locales/` にしかヒットしない）。

**これがこのタスクの厄介なところである。** 「画面に出ていないなら直さなくてよい」ではない。

- 翻訳ファイルに残っている以上、**次に誰かが注記を復活させた瞬間に、実装できていない約束が画面へ出る**
- 出す約束（配信停止の窓口）は**存在しない**。景表法の問題は、文言が翻訳ファイルにある時点で潜在している

**したがって直す先は `locales/en.json` であり、テストも `locales/*.json` を直接見るものでなければならない。**
描画結果を見るテストは、この文言に対しては**永久に緑のまま**である。

**T-019 の担当も `locales/*.json` と `tests/render.test.js` を触る。** 同時には走らせないが、
**あなたが先である。** T-019 の禁止事項に「en の `lp.ctaNote` に手を出さない（T-015 の担当）」と
書いてあるので、あなたの変更が後から上書きされることはない。
