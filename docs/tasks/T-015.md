## 目的

`locales/en.json` の `lp.ctaNote` に **"Unsubscribe at any time."** が入っている。
**配信停止の窓口は実装されていない。** できないことを約束している状態である。

`tests/render.test.js` に「🔒 できないことを書かない」という不変条件のテストが既にあるが、
**ja しか見ていないため en が素通りしている。** T-010 の実装担当が ja 側で同じ文言を書いて
RED を踏んだことで発見された。

提供できない条件を表示していることになり、景表法の観点で放置できない。

| ファイル | 変更内容 |

## 禁止事項

- 🔒 配信停止の窓口を**実装しない**（範囲外。文言を実態に合わせるだけ）
- 🔒 既存の不変条件テストを弱めない。**対象言語を増やす方向にだけ変える**
- 🔒 文言をテンプレートに直書きしない。`locales/*.json` 経由
- `src/` を触らない見込み。触る必要が出たら報告する

## 決定ログ

### 2026-09-02 「できないことを書かない」の検査を、描画結果と翻訳ファイルの二重にする
- 対象: LP のコピー / 不変条件テスト
- 決定: 既存の描画ベース検査（`renderLp()` の出力 HTML を見る）を**そのまま残し**、
  `locales/ja.json` / `locales/en.json` を直接読んで**全キーの値**を走査する検査を別テストとして追加した。
  検査語は `配信停止` / `解除` / `退会` / `unsubscribe` / `opt out` / `opt-out`（大小文字を無視）。
- 却下案:
  - 既存の描画ベース検査を ja / en 両方へ広げるだけ（起票時の旧完了条件）→ T-020 で `lp.ctaNote` が
    どのロケールでも描画されなくなったため、**旧文言を戻しても落ちない空振りのテスト**になる。
  - 描画ベース検査を翻訳ファイル検査へ**置き換える** → 翻訳ファイルに無い直書き文言（テンプレートに
    ハードコードされた語）を取り逃す。両方が必要。
- 付帯条件: 描画ベース検査は弱めない。翻訳ファイル検査は「足す」方向のみ。
- 出典: `docs/tasks/T-015.md` 完了条件2（2026-09-02 差し替え）/ T-020 のレビュー R-020-2

### 2026-09-02 未参照キー `lp.cta` / `lp.ctaNote` を削除せず残す
- 対象: LP のコピー / locales
- 決定: T-020 で描画されなくなり `src/` からも `tests/` からも参照が無くなった `lp.cta` /
  `lp.ctaNote` を、**削除せず文言だけ実態に合わせて残す**。
- 却下案: 未参照なのだから両キーごと削除する → (a) 削除は本タスクの `変更範囲`（「`lp.ctaNote` から
  配信停止の約束を外す」）を超える。(b) ja 側 `lp.ctaNote` の文言変更は「決めてはならない」と
  明記されており、ja/en 片側だけ消すとキー数の対称性（両ファイル 236 キー）が崩れる。
  (c) 注記を復活させる判断はまだ誰も下していない。
- 付帯条件: **残す以上、翻訳ファイル側の検査が唯一の防波堤になる。** 上の決定と対で成立している。
  未使用キーを機械的に検出する仕組みが無いこと（T-020 のレビュー R-020-10）は未解決のまま。
