## 目的

LPのヒーローに出している3件が、実データの**第17位・19位・20位**である
（[design.md](../design/design.md) の「ヒーローのランキングカードの例外」で記録済み）。
そのため広告から来た人が最初に見る単価は **¥9.9〜¥12 / タンパク質1g**、袋価格は ¥5,656〜¥9,480 になる。

同じサイトの製品一覧には **¥1.92 / g**（袋 ¥8,180・5kg）が第1位として載っており、
**ヒーローの数字は実データの約5倍**。「格安 プロテイン」で検索して来た人（クリック率10.34%と
最も反応が良い層）に対して、最も高い数字を見せている状態になっている。

これは離脱対策である以前に、design.md 自身が「景表法の優良誤認に該当しうる」と記録したまま
広告費を投じている状態の是正にあたる。

**手動指定（`HERO_PRODUCT_IDS`）の仕組みは維持する。** 差し替えるのは並べる3件。

## 禁止事項

- 🔒 **数字を作らない。** 出してよいのは実データの製品・価格・単価・画像だけ（design.md §7 禁止⑧）
- 🔒 **製品一覧（`/ja/protein/`）の並び順に触らない。** 有効成分1単位あたりの価格の昇順のまま
- 🔒 N-03。順位を決めるために独自スコアや加重平均を持ち込まない
- 🔒 LPのヒーローに `ItemList` の構造化データを付けない（手動指定中は表示順が単価順と一致しないため、
  誤った順位を機械に断言することになる）
- 🔒 LPに購入リンク（アフィリエイトリンク）を置かない（design.md §7 禁止⑦）
- design.md の例外の記録を**削除しない**。手動指定を続ける以上、記録も生き続ける

## 停止条件

- §4の共通のものに加えて:
- **上位がソイに偏ることの是非は未確定。** 単価比較としては正しい（タンパク質1gの価格）が、
  ホエイを探している検索意図とずれる可能性がある。「原材料で絞り込めることを
  ヒーローで示すべきか」は表示設計の判断なので、3件を確定する前に相談する
- `config/categories.json` の `unitCostRange.min` を変える場合、絞り込みの挙動が変わるため
  本タスクの範囲を超える。別タスクとして切り直す
