# タスク台帳

このリポジトリの進捗の唯一の出所。2箇所に分かれている。

- [../task-list-pergram.csv](../task-list-pergram.csv) — 索引。ID・日付・タスク名・状態・依存・詳細ファイルへのパスだけ
- `docs/tasks/T-XXX.md` — 1タスク1ファイル。目的・範囲・禁止事項・完了条件・テスト方法・停止条件・3種のログ

**一度に1タスクだけ進める。** 現在のタスクが終端状態（完了 / 保留 / 中止）に達する前に次を始めない。

規約の本体は `~/.claude/skills/task-cycle/SKILL.md`。ここには pergram 固有の差分だけを書く。

## ID規則

- 形式: `T-###`（3桁・連番）
- 一度発行したIDは再利用しない。中断したタスクも行を残す（状態を 保留 / 中止 にする）

## CSVの列

- **作成日 / 更新日**: `YYYY-MM-DD`。分からなければ 不明 と明示する。空欄にしない
- **タスク名**: 10〜40文字程度
- **依存タスク**: `T-001（ブロッカー）` = 先方が完了しないと着手できない / `T-001（推奨）` = 必須ではないがこの順が妥当。理由は各タスクファイルに書く。無い場合は 無し と明示する
- **ドキュメント**: リポジトリルートからの相対パス

## 状態

未着手 / 調査中 / 実装中 / ローカル検証済み / 実環境検証待ち / 完了 / 保留 / 中止

管理画面上の操作が主体のタスク（Google広告・GA4）は、ローカル検証という段階が存在しない。
その場合は 実装中 → 実環境検証待ち → 完了 と進める。

## pergram 固有の差分

- **完了条件に🔒の禁止事項チェックを必ず入れる。** [CLAUDE.md](../../CLAUDE.md) の N-01〜N-10 と禁止語リストは機能要件より優先する
- コードを触るタスクの完了条件には `npm test` の通過を必ず含める
- 広告文・LP文言を触るタスクは、`tests/render.test.js` の `BANNED_WORDS` に照らして確認する
