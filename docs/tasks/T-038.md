## 目的
**9/9 の Day7 ゲートの判定材料が無い。** `media-agent report` は `post` テーブルが0行のため
構造的に空であり（T-032 G-03）、`X_kgi_2weeks.md` §9 が定める判定指標「プロフィールクリック率」は
そもそも取得経路が存在しない（G-04）。

一方 Buffer は**投稿あたりのリンククリック数を実際に返している。**
Day7 の2日前までに動いていて、数字が出ることを確認する時間が要る。

- 出力先の CSV（置き場は判断してよい範囲）
- その単体テスト

## 禁止事項
- `.media-agent/` 配下の変更（T-033 / T-034 の担当分である）

- `media-agent.db` への直接 INSERT

## 完了条件
1. Buffer の送信済み一覧と台帳（T-035）を突き合わせ、**型別の 投稿数 / 表示回数 / クリック数 / クリック率**が CSV へ出る
2. **未照合の件数が 0 でないときは、その件数が出力に含まれる**（0 で埋めない）ことを単体テストで示す
3. 現時点のデータで実行した出力が `## 証拠` に貼られている

## 判断してよい範囲
- 出力の列構成、突き合わせのキー（Buffer post id を推奨）、スクリプトの言語と置き場
