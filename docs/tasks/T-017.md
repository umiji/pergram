## 目的

`btn--signal`（背景 `#ea580c` に白文字）のコントラスト比が **約 3.6:1** で、
WCAG 2.2 AA が本文相当のテキストへ求める **4.5:1** を下回っている。

**T-010 でこれが悪化したわけではない**（signal ボタンの数も色も同じ）。
ただし T-010 によって**待機リスト登録が主導線になった**ため、
**最も押させたいボタンが読みにくい**という状態になった。測っているのはメール登録の件数である。

### 追記（2026-09-02・T-010 のレビュー R-010-1 を合流）

**従（ベータ版導線）の側にも同じ種類の問題がある。こちらのほうが重い。**

T-010 で従へ落とした2つのベータ版導線は `btn--quiet`（`src/styles/lp.css:105-113`）を当てており、
背景 transparent・文字色 `--ink`（本文と同色）・境界 `--line`=rgba(22,24,29,0.1) だけになった。
`--paper`(#fafaf9) に対する**境界のコントラスト比は約 1.25:1**（WCAG 2.2 AA の非テキスト 3:1 未満）。
**「押せる操作である」ことを示す手掛かりが、面でも文字色でも無い。**

T-010 の停止条件（「導線を弱めた結果、流入が実質ゼロになりそうなら相談する」）に該当すると
オーケストレーターが判定した。**`btn--subtle` へ替えても約 1.5:1 で解決しない。**
主従の関係は保ったまま、**従が「押せる」と分かる下限**を確保すること。

## 変更範囲

| ファイル | 変更内容 |

## 禁止事項

- 🔒 **色をコンポーネントへ直書きしない。** `src/styles/tokens.css` が唯一の出所である
- 🔒 ブランドの視覚的な一貫性を壊さない。**橙系の主張は保つ**（別系統の色へ振り替えない）
- 🔒 `btn--signal` が付く**場所**を変えない。それは T-010 の領分
- 🔒 **CTA の主従を逆転させない。** 待機リストが主、ベータ版が従（T-010 の決定）。
  従を見えるようにすることと、従を主と同じ強さにすることは違う
- 🔒 文字を小さくして「大きな文字」の緩和基準（3:1）へ逃げない。**背景色側で解く**
- `src/templates/` を触らない

## 完了条件

1. `btn--signal` の前景色と背景色のコントラスト比が **4.5:1 以上**である
1b. `btn--quiet`（および `btn--subtle` を使う場合はそれも）の**境界または面**が、
   ページ背景に対して**非テキストコントラスト 3:1 以上**である
2. その判定が `tests/styles.test.js` の自動テストになっており、下回ると落ちる
3. 変更前の色を入れるとそのテストが**落ちる**ことを確認済み
4. `npm test` が通っている
5. `npm run build -- --strict` が終了コード 0
6. 他の `btn--*` のコントラスト比が、変更前より悪化していない

## 判断してよい範囲

- コントラスト比の計算のテスト実装（WCAG 2.x の相対輝度の式を使うこと）
- 他のボタンも併せて検査対象にするか

**決めてはならない**: ブランドカラーの系統変更。`btn--signal` を使う箇所の変更。
