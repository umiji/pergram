## 目的

`docs/design/design.md` §9「配色のたたき台」に書かれている16進値が**青と緑**だが、
実装（`src/styles/tokens.css`）は**橙系**である。

**次にデザインを触る担当が §9 を見て配色を決めると、実装と違う色を持ち込む。**
デザイン要件書は「Claude Design への受け渡しはこれ」と CLAUDE.md が指しているため、
外部へ渡る文書でもある。

色の値の唯一の出所は `src/styles/tokens.css` である。§9 はその事実を指すだけの形へ直すか、
実装の値へ揃える。

## 変更範囲
- `docs/design/design.md` §9 のみ

## 禁止事項
- `src/styles/tokens.css` の値を変えない（この作業は文書を実装へ合わせるものであって、逆ではない）
- §9 以外の節を書き換えない。特に「面の体系と字送りの階層（T-053）」は触らない

## 完了条件
- 1. `docs/design/design.md` §9 に、実装に存在しない16進値が残っていない
     （`grep -o '#[0-9a-fA-F]\{6\}' docs/design/design.md` の各値が
      `src/styles/tokens.css` に存在するか、値そのものを書かない形になっている）
- 2. §9 から「色の値の出所は `src/styles/tokens.css`」であることが辿れる
- 3. `npm run build` が成功する（文書だけの変更なので影響しないことの確認）
