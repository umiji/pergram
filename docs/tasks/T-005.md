# T-005: 広告配信7日間のモニタリングと判定

## メタデータ
- 作成日: 2026-08-18
- 更新日: 2026-09-02
- 状態: 実装中
- 進捗: 40%（実績値は取得済み。GA4・D1・検索語句レポートの数字が未取得）
- 依存: T-004（ブロッカー: 配信が始まらないと数字が出ない）

## 目的

7日間の数字を毎日記録し、判定基準に当てはめて**撤退 / 継続 / 加速**を決める。

このタスクの成果物は「広告の成績」ではなく、**次に何を作るかの判断材料**である。
待機リストの「見たい成分」チップの内訳が、P1で整備する成分の決定に直結する。

出典: [docs/ops/google-ads-first-campaign.md](../ops/google-ads-first-campaign.md) フェーズ5〜6

## 変更範囲

コード変更なし。日次の記録と、判定結果のドキュメント化。

| 記録するもの | 出所 |
|---|---|
| 表示回数 / クリック数 / CTR / 平均CPC / 品質スコア | Google広告 |
| ファネル各段の人数（`lp_view` → `cta_click` → `waitlist_start` → `waitlist_submit`） | GA4 探索 → 目標到達プロセス |
| 「見たい成分」チップの内訳 | 待機リストのD1データ |
| 検索語句レポートと、追加した除外キーワード | Google広告 |

## 禁止事項

- 🔒 **独自の判定基準を作らない。** [validation-plan.md §5](../research/validation-plan.md) の基準表をそのまま使う
- 良い数字が出ても「広告を回して伸ばす」に進まない。1ユーザーあたりのアフィリエイト生涯収益は
  楽観的に見ても ¥300〜600 で、CACが¥300を超えた時点で恒久チャネルとしては赤字になる
- 日予算を途中で引き上げない。7日間の条件を揃える（途中で変えると前後の数字が比較できなくなる）
- 🔒 待機リストの自由記述の**本文**を、判定資料としてリポジトリに転記しない（N-01 / N-05 の入力口になりうるため）。
  集計値・チップの内訳だけを扱う

## 完了条件

1. Day 1〜7 の各日について、上記4種類の数字が記録されている（欠測日があるなら欠測と明記する）
2. CPL（登録単価）が算出されている = Google広告の費用 ÷ GA4の `waitlist_submit` 件数
3. 判定基準表（CVR / CPL / 登録者数）に実数を当てはめた結果と、**撤退 / 継続 / 加速のいずれか**が
   明示的に書かれている
4. 「見たい成分」チップの内訳から、次に整備する成分の候補が挙がっている
5. 上記が `docs/ops/` 配下のドキュメントとしてコミットされている

## テスト方法

コードを触らないためテスト対象外。
数字の正しさは、Google広告側とGA4側の突き合わせ（費用はGoogle広告、登録件数はGA4とD1）で担保する。
**GA4の `waitlist_submit` 件数とD1の実レコード数が食い違う場合、D1を正とする。**

## 停止条件

- §4の共通のものに加えて:
- Day 3 時点でクリックが0に近い（表示はされているのにCTRが極端に低い）場合、
  7日を待たずに広告文・キーワードの見直しを相談する
- 検索語句レポートに 育毛 / 薄毛 / AGA 系の語が現れた場合、即座に除外キーワードへ追加する（N-09）

## 決定ログ

### 2026-08-18 判定は8日で打ち切る
- 決定: 設定・審査1日 + 配信7日 = 実質8日で意思決定する
- 却下案: 統計的な確度が出るまで期間を延ばす案 → 有料広告はそもそも恒久チャネルにしない前提であり
  （[validation-plan.md §1](../research/validation-plan.md)）、確度を追う投資対効果が低いため
- 出典: [docs/ops/google-ads-first-campaign.md](../ops/google-ads-first-campaign.md) 冒頭

### 2026-09-02 「判定不能・母数不足」として閉じる
- 決定: 本タスクは[validation-plan.md §5](../research/validation-plan.md)の判定基準表を**適用せずに**閉じる。
  実クリック数が9であり、基準表が前提としているクリック規模（100〜150）に2桁届いていない。
  基準の適用条件そのものが満たされていない
- 却下案: ①基準どおり「登録者数 < 8」を適用して**撤退**判定とする案
  → 撤退アクションは「LPの訴求を1度だけ作り直して再テスト」であり、これを発動すると
  **1度きりの作り直しの枠を、何も学べていない状態で使い切る**。判定材料がないことと
  判定結果が悪いことは違う
  ②配信量を回復させたうえで7日間を取り直し、T-005を開いたまま数字を埋める案
  → 本タスクの禁止事項「日予算を途中で引き上げない／7日間の条件を揃える」に抵触する。
  条件を変えた期間は別の期間として切り直すのが筋
- 付帯条件: ①基準を曲げたのではなく**適用していない**ことを記録に残す（N-03の趣旨と同じく、
  都合のよい独自基準を後から作らない）②配信量を回復させた次の期間は、新しいタスクとして
  取り直す（[T-008](T-008.md)）
- 出典: セッションでの決定（2026-08-28〜09-02 の実績 277表示 / 9クリック / CTR 3.25% / ¥166）

### 2026-09-02 ボトルネックは母数ではなく配信量と特定した
- 決定: 流入不足の原因を「予算・需要・LP」ではなく**オークションで広告枠が取れていないこと**と判断し、
  診断と是正を[T-008](T-008.md)へ引き継ぐ
- 却下案: 「単純に人が来ていないだけ」としてLP改修を先に行う案 → 日予算¥500×6日=¥3,000に対して
  実消化¥166（消化率5.5%）であり、予算は制約になっていない。配信量が回復しないままLPを直しても
  次の期間も判定不能になる
- 出典: セッションでの決定
