## 目的

T-047 で CSP を直し、GA4 の計測は本番で復旧した（ビーコン12本を実測で確認）。
**しかし Google 広告のコンバージョン計測だけ、本番で2件のCSP違反が残っている。**

```
Connecting to 'https://www.google.co.jp/pagead/1p-conversion/18396158699/'
violates ... "connect-src ..." The action has been blocked.
```

Google 広告は 1st-party コンバージョンを**閲覧者の国別ドメイン**（日本なら `www.google.co.jp`）へ送る。
T-047 では `www.google.com` を許可したが、`.co.jp` は別ホストなので届いていない。

**ローカル配信では踏めない。** 国別ドメインは本番の実環境でしか現れず、T-047 の
ローカル実測（違反0件）をすり抜けた。飛ばすと T-007「広告のコンバージョン計測の
疎通確認」が通らない。

## 変更範囲

- `src/build/headers.js` の `MEASUREMENT_CONNECT_SRC`
- `tests/headers.test.js`

## 禁止事項

- `https://*.google.com` のような広い書き方に逃げない。**必要なホストだけを列挙する**
- `connect-src` に `https:` / `*` を書かない
- T-047 で入れた既存のホスト・テスト・`withOrigin` の出し分けを変えない
- CSP の他のディレクティブを触らない

## 決定ログ

### 2026-09-07 広告コンバージョンの国別ドメインは `www.google.co.jp` だけを完全一致で足す
- 対象: CSP / 計測ホストの許可
- 決定: `MEASUREMENT_CONNECT_SRC` へ `https://www.google.co.jp` を**1ホストだけ**追加する。
  他国のドメイン（`google.co.uk` `google.de` 等）は足さない。
- 却下案その1: `https://*.google.co.jp` と書く → `*` はラベルを1つ埋める指定なので
  `www.google.co.jp` 自体には当たるが、**必要のない全サブドメインまで開く。**
  禁止事項の「必要なホストだけを列挙する」に反する。`tests/headers.test.js` の
  T-048 節に guard を新設し、`https://*.google.co.jp` / `https://*.google.com` /
  `https://*.google` を機械で禁じた。
- 却下案その2: 主要国の国別ドメインを先回りして列挙する → 出していない市場のホストを
  開くことになる。タスクの「判断してよい範囲」が既定を「足さない」と定めており、
  **US 市場を出す段で実測して足すのが正しい順序**である。
- 却下案その3: `https://www.google.com` で足りるとみなす → **別ホストなので届かない。**
  本番の実測でコンバージョンのビーコン2件がブロックされている。
  `analytics.google.com` / `ad.doubleclick.net` と同系統の、**「似た名前だが別ホスト」の罠**。
  将来「google.com があるので重複」と読んで消すと、**広告のコンバージョン計測だけが静かに落ちる。**
  この理由を `src/build/headers.js` のコメントにも書いた。
- 出典: `src/build/headers.js` L41-46 / `tests/headers.test.js` の T-048 節 /
  `docs/tasks/T-048.md` 目的（本番実測のコンソール出力）
