## 目的

**流入不足の原因は予算でも需要でもなく、広告が表示されていないこと。**

| | 数値（2026-08-28〜09-02） |
|---|---|
| 日予算 | ¥500 × 6日 = ¥3,000 使える |
| 実消化 | ¥166（**消化率 5.5%**） |
| 表示回数 | 277回（46回/日） |

予算は9割以上余っている。したがって予算を上げても流入は増えない。
オークションで枠が取れていないか、そもそも検索語にマッチしていないかのどちらか。

**もう1つの手がかり:** クリック率が立った3語
（`格安 プロテイン` 10.34% / `プロテイン 格安` 4.69% / `プロテイン コスパ ランキング` 5.88%）は
**すべて補助バケット（月100〜1,000）**の語で、在庫の本体である主軸7語
（`プロテイン コスパ` 等・月1,000〜10,000・競合性 High 指数100）が1つも出ていない。
薄くて安い語だけ勝ち、厚くて競った語で負けている形。入札ランクの問題である可能性が高い。

## 変更範囲

コード変更なし。Google広告管理画面の設定と、診断結果の記録。

| 見るもの | 判断への使い方 |
|---|---|
| 検索インプレッションシェア | 全体でどれだけの機会を取り逃しているか |
| **インプレッションシェア損失率（ランク）** | 大きければ入札単価か品質スコアの問題 |
| インプレッションシェア損失率（予算） | ほぼ0のはず（消化率5.5%で既に裏づけ済み）。大きければ前提が崩れるので診断をやり直す |
| キーワードごとのステータス | 「検索ボリュームが少ない」「有効ではない」で停止している語がないか |
| キーワードごとの品質スコア | 3要素（推定クリック率／広告との関連性／ページの利便性）のどれが低いか |
| 平均掲載順位 / ページ上部インプレッションシェア | 表示されていても下部に沈んでいないか |

診断結果を受けて調整してよいのは**入札単価とマッチタイプ**まで。

## 禁止事項

- 🔒 **日予算（¥500/日）を引き上げない。** 消化率5.5%で予算は制約になっていない。
  上げても効果がないうえ、[T-005](T-005.md) の禁止事項に抵触する
- 🔒 **部分一致を無条件に開放しない。** 開放するなら検索語句レポートを毎日見て
  除外キーワードを追加することとセットにする（[validation-plan.md 段2](../research/validation-plan.md)）
- 🔒 `育毛` `薄毛` `AGA` を除外キーワードから外さない（N-09）。費用の問題ではない
- 🔒 `効果` `副作用` `飲み方` も外さない。**その検索に合った広告文が1文字も書けない**
- ディスプレイネットワーク・検索パートナーをオンにしない
- 入札単価と広告文を同時に変えない。どちらが効いたか分からなくなる

## 完了条件

1. 上記6項目の実測値が記録されている
2. 「ランクによる損失」と「予算による損失」のどちらが支配的かが数値で明示されている
3. 2の結果に応じた対処が1つだけ実施され、**何を・いくつからいくつへ変えたか**が記録されている

4. 変更後3日間の表示回数・クリック数・消化額が記録され、**消化率が改善したかどうか**が判定されている
5. 上記が `docs/ops/` 配下のドキュメントとしてコミットされている

## 停止条件

  T-009 / T-010 の結果を待ってから再評価する
- 対処後も消化率が10%を超えない場合、そもそもこのキーワード群で広告を出し続ける意味を相談する

## 決定ログ

### 2026-09-02 ボトルネックを「母数不足」ではなく「配信量不足」と定義し直した
- 決定: 流入が少ない原因を、日予算・需要・LPではなく**オークションで枠が取れていないこと**と特定し、
  最初に検索インプレッションシェアを読む
- 却下案: ①「単純に人が来ていないだけ」としてLP改修を先に行う案
  → 配信量が回復しないまま改修しても次回も判定不能になり、[validation-plan.md §5](../research/validation-plan.md)
  の「LP訴求の作り直しは1度だけ」という枠を学びなしに使い切る
  ②日予算を引き上げる案 → 消化率5.5%であり予算は制約になっていない
- 出典: セッションでの決定（2026-08-28〜09-02 のGoogle広告実績 277表示 / 9クリック / ¥166）
