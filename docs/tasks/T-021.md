## 目的

**T-006 で敷いた LLMO の土台が、本番では効いていない。**

本番の `https://pergram.site/robots.txt` を実測したところ、このリポジトリが
`src/build/crawl.js` から出力する内容の**前に、Cloudflare が管理する断片が前置**されており、
主要な AI クローラを個別に `Disallow: /` で全面ブロックしていた。

```
User-agent: *
Content-Signal: search=yes,ai-train=no,use=reference
Allow: /

User-agent: GPTBot
Disallow: /
（同様に ClaudeBot / CCBot / Google-Extended / Applebot-Extended /
  Bytespider / meta-externalagent / Amazonbot / CloudflareBrowserRenderingCrawler）
```

robots.txt は**自分の名前に一致するグループだけを読む**規約である。したがって GPTBot も
ClaudeBot も、このリポジトリが出力する `User-agent: *` の行を**一切見ない**。

`src/build/crawl.js` は「🔒 ここを塞ぐと LLM の回答内に pergram が出てこなくなります」と
コメントで固定している。**本番はまさにその状態にある。** T-006 の目的（LLM 時代の流入経路を
今のうちに開けておく）は、リポジトリ側では達成されているが、**配信の実態としては未達成**である。

放置すると、ChatGPT / Claude / Perplexity の回答に pergram が引用される経路が閉じたままになる。
`docs/research/validation-plan.md` の判定が「継続 → SEO 起点に切り替え」へ振れたときに、
**開けてから検索・LLM に認識されるまでの時間が丸ごと後ろ倒しになる。**

### 2026-09-02 AI クローラのブロックは解除し、学習利用への反対の意思表示だけ残す
- 対象: クロール許可 / robots.txt
- 決定: Cloudflare の AI クローラのブロック（`GPTBot` / `ClaudeBot` / `CCBot` /
  `Google-Extended` / `Applebot-Extended` / `Bytespider` / `meta-externalagent` /
  `Amazonbot` に対する `Disallow: /`）を**全面解除**する。
  ただし `Content-Signal: ai-train=no`（AI の学習利用は認めないという意思表示）は**残す**
- 却下案:
  - **B案（`Content-Signal` も外して最も開いた状態にする）** → 引用されやすさは最大になるが、
    学習利用に対する意思表示が一切無くなる。**引用を得るために必要なのは `ai-input` を
    開けることであって、`ai-train` を開けることではない。** 対価なく捨てる理由が無い
  - **C案（現状維持）** → T-006 で敷いた LLMO の土台が本番で永久に効かない。
    `docs/research/validation-plan.md` が「SEO 起点へ切り替え」と判定したときに開けても、

    取り戻せない**
- 付帯条件: **`Content-Signal` は法的拘束力のある仕組みではなく、各社が従う保証はない。**
  「`ai-train=no` を出しているから学習には使われない」と読まないこと
