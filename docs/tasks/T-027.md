## 目的
X 運用の KGI（14日で オーガニック流入 300 ユーザー）は、**測れなければ達成も未達も判定できない**。
GA4 の参照元だけでは「X から来た総数」しか分からず、Day7 ゲートで「どの型を捨てるか」を決められない。
投稿に載せる文字列を短く保ったまま型を識別するため、短縮パスから UTM 付き URL へ 302 で飛ばす。

1. `npm run build` の出力 `dist/_redirects` に、型 A〜D の4行が含まれる
   （`/x/a  /ja/?utm_source=x&utm_medium=social&utm_campaign=type_a  302` の形）

3. 上記を検証する単体テストが追加され、`npm test` が通る

## 決定ログ
### 2026-09-02 X の流入計測は UTM ではなく短縮パス経由にする
- 対象: 計測 / X運用
- 決定: 投稿に載せる URL は `pergram.site/x/<型>` とし、`_redirects` で UTM 付き URL へ 302 する
- 却下案: UTM を直に貼る → X は URL を t.co で一律23文字として数えるため文字数の不利は無いが、リンク先を後から変えられず、投稿に残る文字列が読みにくい / GA4 の参照元だけで済ませる → X からの総数は測れるが型別の内訳が取れず、Day7 ゲートの判断ができない
