## 目的

**日次の価格更新が 2026-08-21 から12回連続で失敗しており、公開中の価格が 2026-08-24 で止まっている。**

`.github/workflows/prices.yml` は毎日 06:00 JST に走るが、2026-08-21 以降すべて 10〜13 秒で
失敗している。失敗を知らせる仕掛けは正しく動いており、Issue #19 が開いたままコメントが積まれている。

**原因は特定済み。** 最新の失敗ログ（run 33569554924）に楽天APIの応答がそのまま出ている。

```
楽天 API が 403 を返しました: {
  "errors": { "errorCode": 403, "errorMessage": "HTTP_REFERRER_NOT_ALLOWED" }
```

`scripts/rakuten_api.js` は `RAKUTEN_APP_URL` を `Referer` ヘッダに載せている（41〜47行）。
403 `HTTP_REFERRER_NOT_ALLOWED` は、**送っている Referer が楽天のデベロッパー画面に登録された
アプリURLと一致していない**ことを意味する。`REQUEST_CONTEXT_BODY_HTTP_REFERRER_MISSING`
（Referer が無い場合）とは別のエラーである。

**直近にドメインを移した経緯がある**（コミット 9bff404「旧ドメインを新ドメインへ恒久転送する」）。
登録済みアプリURLか GitHub Secret の `RAKUTEN_APP_URL` のどちらかが旧ドメインのまま、
という筋が最も濃い。ただし**確認していない。断定せずに切り分けること。**

放置すると、価格が古いまま広告費を投じ続けることになる。T-009 がヒーローに出す単価も
この止まったスナップショットに基づく。

## 変更範囲

| `.github/workflows/prices.yml` | 必要なら環境変数・環境（`environment:`）の指定 |
| `data/price_snapshots.json` | 復旧後の再取得の結果（`npm run prices:refresh` の出力） |

**GitHub Secret / 楽天デベロッパー画面の設定変更は、このリポジトリの外にある。**
必要と判断したら**自分で変えようとせず**、何をどう変えるべきかを具体的に書いて報告すること
（PO が実施する）。

## 禁止事項

- 🔒 **`RAKUTEN_AFFILIATE_ID` を空のまま実行しない。** 無いと公開中の購入リンクを素の商品URLで
  全上書きする。`scripts/rakuten_api.js` の `readCredentials` が実行前に止めるようになっている。
  **この停止を回避する変更を入れない**
- 🔒 認証情報（App ID / Access Key / Affiliate ID / App URL の実値）を、コード・ログ・
  タスクファイル・コミットメッセージのどこにも書かない。**報告にも実値を貼らない**
- 🔒 バリデーション（`npm run validate`）を通さずに `data/price_snapshots.json` を差し替えない。
  異常値が公開データへ入る
- 🔒 `.github/workflows/prices.yml` の「失敗を Issue で知らせる」ステップを削らない・弱めない。
  8日間の沈黙を受けて入れた仕掛けである
- リトライやフォールバックで 403 を握り潰さない。**失敗は失敗のまま落とす**
- `main` へ直接コミットしない

## 完了条件

1. 403 `HTTP_REFERRER_NOT_ALLOWED` の**原因が特定され**、タスクの `## 決定ログ` に記録されている
   （送っていた Referer と、登録されているべき値の食い違いが何だったか）
2. 次のいずれかが満たされている
   - **(a) リポジトリ内の修正で直る場合**: 修正を入れ、`npm run prices:refresh` がローカルで
     成功し、`data/price_snapshots.json` の `fetched_at` が当日の日付で更新されている
   - **(b) リポジトリ外の設定変更が要る場合**: **何を・どこで・どの値に変えるべきか**が
     手順として `## 証拠` に書かれており、PO がそれだけを見て実施できる状態になっている
3. `npm run validate` が通っている
4. `npm test` が通っている
5. 403 が再発したときに原因へ最短で辿り着けるよう、
   `.github/workflows/prices.yml` の失敗通知の本文に **403 系の切り分け**が追記されている
   （現在はエンドポイント版の廃止＝400 のことしか書かれていない）
