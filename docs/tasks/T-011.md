## 目的

「なぜプロテインが高くなったのか」は、**買っている本人が理由を知らないまま払っている**話で、
読み手（P-A 量を飲む人）がいちばん反応する題材。ただし現状、手元にあるのは
まとめ記事とメーカーの note 経由の**二次情報だけ**で、投稿に書ける状態にない。

🔒 外部の数字は一次ソースを確認してから書く。まとめ記事の数字を写さない。

## 変更範囲

- `.claude/skills/x-post/reference/topics.md` の「11. 市場と相場」に、確認できた数字と
  出典を追記する（現状は論点と当たり先だけ）

## 確認すべき論点と当たり先

| 論点 | 一次ソース |
|---|---|
| ホエイパウダーの輸入単価が数年で数倍になった | 財務省 貿易統計（品目別の輸入額 ÷ 数量で自分で割る） |
| 国内メーカーが価格改定を公表している（改定率つき） | 各社の公式リリース・お知らせページ |
| GLP-1 系の薬の普及でたんぱく質需要が増えた | 一次の統計、またはメーカーの公式見解 |
| 円安・物流費・関税の上乗せ | 為替の公表値・各社リリース |

二次情報で見かけた値（**未確認。そのまま書かない**）: 輸入平均単価 2021年1月
約746円/kg → 2026年1月 約2,234円/kg、米国産WPI 24,250ドル/トン、
グロング +31.7% / VALX +22.3% / ザバス +6〜28%。

## 禁止事項

- 🔒 二次記事の数字をそのまま投稿に書かない
- 🔒 値上げを煽らない。「今が買い時」「もっと上がる」は予想であって事実ではない
- 🔒 特定メーカーを責める書き方にしない。公表されている事実の引用にとどめる
- 🔒 需要増の説明で薬（GLP-1）の効能に踏み込まない（N-02）

## 完了条件

1. 各論点について、一次ソースの URL と取得日を記録している
2. 投稿に書ける形（数字・単位・基準・時点がそろった1行）に整形している
3. 出典を投稿に添えられる長さ（機関名＋年月）に短縮できている
4. `topics.md` の「11. 市場と相場」を更新している
5. 一次ソースで確認できなかった論点は**削除する**（保留にして残さない）

## テスト方法

`npm run x:lint` で、書いた下書きが禁止語・文字数に触れないことを確認する。
数字そのものの正しさは一次ソースとの突き合わせで担保する。

## 停止条件

- 貿易統計の品目分類が特定できず、ホエイ単体の輸入単価が出せない場合は、
  その論点を落として他の論点だけで書く（推定で埋めない）
