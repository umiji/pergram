## 登録が止まっている理由

```
$ media-agent queue channels --account x/pergram-jp
エラー: Buffer が HTTP 401 を返しました:
{"errors":[{"message":"Access token is not valid","extensions":{"code":"UNAUTHENTICATED"}}]}
```

- `media-agent env check` では `BUFFER_API_KEY` は **[設定済み]**。値が無いのではなく、**トークンが通っていない**
- 配信の段階は `test` → **`draft` へ切替済み**（`media-agent mode set draft`）。
  トークンが通れば、そのまま Buffer の下書きに入る。**この段階では公開されない**
- **`media-agent` には、手書きの本文を投稿候補として登録する経路が無い。**
  `post` / `run` はどちらも AI が本文を生成する。上の2本は人が書いたものなので、
  CLI 経由では Buffer へ入らない。トークン修復後も、Buffer の画面へ手で貼るか、
  本文を差し込む経路を作るかの判断が要る
