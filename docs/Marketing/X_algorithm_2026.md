投稿文の作り方は [X_post_strategy.md](X_post_strategy.md)、実際の書き方は

## スコアの決まり方

```
Final Score = Σ ( weight_i × P(action_i) )
```

重みが掛かるのは**その行動が起きる予測確率**（滞在時間などは予測値）であって、
生の回数ではない。「いいねを100個集める」ことが効くのではなく、
**「その行動が起きそうな投稿だ」と判定されること**が効く。

スコアの後に3つの調整が入る。

| 調整 | 中身 | 定数 |
|---|---|---|
| Out-of-Network Discount | フォロー外の閲覧者に出すとき割り引く | `OonWeightFactor` 0.75 / トピック経由 `TopicOonWeightFactor` 0.5 |
| Author Diversity | 同じ書き手の2投稿目以降を減衰させる | 減衰 0.5 / 下限 0.25 |
| Cold Start（新規の押し上げ） | 表示が閾値未満の書き手を上位に差し込む | 表示 1000 未満・フォロワー 1000 以下・投稿から24時間以内 → 15〜16位 |

## ここから決まる運用則

1. **人に渡せる投稿を書く。** 最大の正の重みは「リンクをコピーして共有」の 20.0
   （いいねの40倍）。**そのまま誰かに送れる事実**——具体的な数字、比較の結論、一覧——が
   これを起こす。「うちのサービスを見てください」では起きない。
2. **会話を作る。** リプライは 5.0、相互フォロー相手なら 20.0。いいねの10〜40倍。
   投稿の終わりを問いかけか、意見の言い切りにする。
   **来たリプライには必ず返す**（相手の次の行動が再びリプライになる）。
3. **相互フォローを作っておく。** 15.0 の上乗せは「相互フォローの相手へのリプライ」に付く。
   普段からその界隈と相互になっていること自体が効く。宣伝リプの連投ではなく、
   有益な補足を続けることでそこへ行く。
4. **連投しない。** 同じ書き手の2投稿目は 0.5 倍、以降 0.25 倍まで落ちる。
   1日に3本流すより、1本に集中して会話を回す方が届く。
5. **🔒 同じ話を繰り返さない。** ミュート -58.8 / 興味なし -43.2 は、いいね100個超を
   一撃で打ち消す。同じ切り口の繰り返しがミュートへの最短路。
   `npm run x:feed` の重複チェックはスコアを守るための機構でもある。
6. **フォロー外は 0.75 倍が前提。** トピック経由なら 0.5 倍。数を撒いて外へ広げるより、
   関心の合うフォロワーの中で会話が起きる方が結果的に外へ出る。
7. **いまは押し上げがある。** 表示 1000 未満・フォロワー 1000 以下・24時間以内の投稿は
   15〜16位に差し込まれる。**β版のいまが最も出やすい期間**で、ここで
   通報・ミュートを踏むと最も高くつく。
8. **プロフィールへの誘導を目的にしない。** プロフィールクリックの重みは 0.0。
   単純な滞在も 0.0 で、効くのは連続滞在時間（0.004）だけ。
9. **画像はスコアのために貼らない。** 展開・再生は各 0.05 しかない。画像の価値は
   「読まれること」（滞在しなかった -0.02 を避けること）であって、スコアではない。
   動画は10秒未満だと動画として扱われない（`MinVideoDurationMs` 10000）。
10. **外部リンクへのペナルティは公開コードに無い。** `OpenLinkWeight` はむしろ +0.2。
    ⚠️「URLを貼ると伸びない」は広く言われるが、**根拠になる定数は見当たらない。**
    それでも1投稿目にURLを置かないのは、ペナルティ回避ではなく**機会費用**の話として扱う
    ——1投稿目は会話（5.0〜20.0）に使い、リンクはその後に置く方が取り分が大きい。

## 🔒 係数を追って中身を歪めない

| やりがちなこと | 何が起きるか |
|---|---|
| 会話を増やすために煽る・対立を作る | 通報 -234.0。1件で いいね468個分が飛ぶ |
| 毎回「どっちだと思う?」で締める | 飽きられてミュート -58.8 |
| リンクを送らせるために数字を盛る | 景表法。CLAUDE.md の禁止が常に優先する |
| 反応欲しさに成分の効きに触れる | 薬機法（N-02）。スコアの話より先に守る |

**スコアはあとから付いてくるものであって、目的にしない。**
