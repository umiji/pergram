# Pergram サービスナレッジ＆デザイン仕様書

## 1. サービス概要
- **名称**: Pergram（パーグラム）
- **タグライン**: 「1gあたり、いくら払ってる?」
- **URL**: https://pergram.site/ja/
- **核心価値**: プロテイン・サプリメントを「有効成分1単位（タンパク質1g）あたりの実質価格」で横並びに比較するWebサービス。
- **特徴**: 
  - 袋の内容量ではなく、ラベル表示のタンパク質含有率を掛けた実質タンパク質量で割って単価を算出。
  - レビュー星評価やアフィリエイト報酬額で順位を操作せず、純粋な計算値の昇順のみで並べる中立性。
  - 登録不要・完全無料（現在β版運用中）。
- **参照情報**: 詳細な仕様や最新の取り扱い情報は、紐付けられたNotebook内の公式サイトを参照。

## 2. 過去投稿の管理と重複回避
- 紐付けられたNotebook内の「過去投稿スプレッドシート」を毎回確認すること。
- 直近で投稿された内容と同じフック（例: 「3kgで安いは損」が直近にあれば、次は「セール時の電卓の手間」や「成分含有率の落とし穴」にするなど）を避け、多面的な切り口で発信を継続する。

## 3. デザイントークン
- `--paper`（背景色）: #FAFAF9（温かみのあるオフホワイト紙地）
- `--surface`（カード背景）: #FFFFFF（純白）
- `--ink`（文字色）: #0F172A（知的な濃紺・黒インク）
- `--signal`（アクセント）: #EA580C（インパルス・オレンジ）
- `--signal-band`（1位ハイライト背景）: #FFF7ED（ペールオレンジ）
- `--muted`（補助文字色）: #64748B / #94A3B8

## 4. UIコンポーネント構造
1. **ランキングリスト（List View）**:
   - 1位行: 背景 #FFF7ED、オレンジ丸バッジ「1」、商品名、右端に特大オレンジ文字「¥9.9/g」、下に「袋 ¥5,656」。
   - 2位・3位行: 背景 #FFFFFF、グレー丸バッジ「2」「3」、右端に黒文字「¥11/g」「¥12/g」。
2. **単一商品カード（Card View）**:
   - 白地角丸カード。商品画像、商品名、中央に「タンパク質1gあたり ¥9.9/g」のハイライトボックス。
   - 下部に「¥5,656 / 800g（含有率: 71%）」＋ダークネイビーの「最安ストアを見る」ボタン。

## 5. マーケティング・トンマナ規約
- 「ツール」ではなく「サービス」「Webサービス」と呼ぶ。
- 「個人開発」などのアマチュア感のある言葉は使わず、公式アカウントとして信頼感のあるクリーンなトーンを保つ。
- 1投稿目は140文字以内厳守。
- 普段は単発ポストで運用し、サイトへ誘導したい告知時のみツリー（2投稿目にURL）にする。
