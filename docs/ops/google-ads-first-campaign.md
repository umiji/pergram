## 0. 前提（必ず読む）

この広告テストの目的は3点に限定される。**「広告を回して伸ばす」ためではない。**

| # | 検証したいこと | 判断への影響 |
|---|---|---|
| 1 | どの成分に最も需要があるか | P1 で作る成分を決める |
| 2 | LP のメッセージが刺さるか（CVR） | 訴求の方向性 |
| 3 | 薬機法の制約下で広告が書けるか | 事業のマーケティング可否そのもの |

1ユーザーあたりのアフィリエイト生涯収益は楽観的に見ても ¥300〜600。CAC が ¥300 を超えた時点で
永続チャネルとしては赤字になるため、**良い数字が出ても「広告を回して伸ばす」に進んではいけない。**

## 1. Google広告の仕組み（初めての人向け）

### オークションと広告ランク

検索結果に広告が出るたびに、その枠を巡ってオークションが行われる。決まるのは
**入札単価 × 品質スコア = 広告ランク** の順位。品質スコアが高いと、入札額が低くても
上位に出せる（＝実際に払うCPCも下がる）。

品質スコアは主に3つで決まる:
- 推定クリック率（このキーワードで、この広告がどれだけクリックされそうか）
- 広告とキーワードの関連性（広告文にキーワードの文脈が含まれているか）
- 遷移先ページの利便性（LPがキーワードの意図に合っているか、表示が速いか）

→ 今回の設計で言うと、**「単価」「比較」で検索した人に、単価比較ができるLPを見せる**ことが
そのまま品質スコアに効く。ズレた広告文にしない。

### キーワードのマッチタイプ

| マッチタイプ | 書き方 | 挙動 |
|---|---|---|
| 完全一致 | `[プロテイン 単価]` | ほぼそのままの検索語のみ |
| フレーズ一致 | `"プロテイン 単価"` | 語順を保った検索語（前後に語が付くのは許容） |
| 部分一致 | `プロテイン 単価` | 関連語まで広く拾う。母数は増えるが関連性が落ちる |

validation-plan.md の指定どおり、**完全一致・フレーズ一致から開始する**（部分一致は使わない）。
無関係な検索に広告費を溶かすリスクを避けるため。

### 検索ネットワークのみを使う理由

Google広告には「ディスプレイネットワーク」「検索パートナー」への配信オプションがあるが、
今回はオフにする。理由: 検索広告は「今まさにその語で検索した人」という顕在需要に直撃できるが、
ディスプレイ/パートナーは意図が薄く、少ない予算で薄めるとどのシグナルも読めなくなる。

### 課金の仕組み

**Google広告に最低課金額はない。** 日予算は上限であってコミット額ではなく、課金は実クリック分のみ。
いつでも停止でき、その時点までの消化分だけ支払う。

- [x] **(2-3)** 除外キーワードを登録:
```
効果 副作用 飲み方 育毛 薄毛 AGA
```

除外の判断基準は「情報収集の段階かどうか」**ではなく**「そのページに答えがあるか」。

| 語 | 除外する理由 |
|---|---|
| `効果` `副作用` `飲み方` | **その検索に合った広告文が1文字も書けない。** `効果` は禁止語であり、飲み方・副作用はページに一行も無い。検索語と広告内容がズレると品質スコアが落ち、同じ掲載位置に高いCPCを要求される。二重に損 |
| `育毛` `薄毛` `AGA` | 🔒 N-09（AGA・育毛・薄毛の文脈で成分を扱わない）。**費用の問題ではないので絶対に外さない** |

**`おすすめ` `ランキング` は 2026-08-18 に除外から外した。** 理由は3点:

1. **ページに答えがある。** 安い順に並んだ一覧そのものが「どれを買うべきか」への回答になっている
2. **測るのは購入ではなくメール登録。** 「情報収集の段階は登録率が落ちる」は物を売る場合の常識であり、待機リストには当てはまらない。買う直前の人は買って帰るだけで登録の動機がなく、調べている段階の人のほうが「準備できたら教えて」に応じる動機が強い
3. **本テストの目的①（どの成分に需要があるか）を測るなら、買う直前の人に絞り込むのはサンプルを偏らせるだけ**

🔒 **そして実データがこの判断を裏づけた。** 最上位バケット（月 1,000〜10,000）の7語のうち
**3語が旧除外語で消えていた**:

| 消えていたキーワード | ボリューム | 塞いでいた除外語 |
|---|---|---|
| プロテイン おすすめ コスパ | 月 1,000〜10,000 | `おすすめ` |
| プロテイン コスパ おすすめ | 月 1,000〜10,000 | `おすすめ` |
| プロテイン コスパ 最強 ランキング | 月 1,000〜10,000 | `ランキング` |

**最大の在庫の4割強を、自分で塞いだまま配信するところだった。**

🔒 **ただし「除外から外す」と「入札する」は別。** `プロテイン おすすめ` 単体（月9万回）に
入札はしない。日予算 ¥500 では一瞬で溶けて他の語のデータが取れなくなる。除外から外すのは
`プロテイン コスパ おすすめ` のような組み合わせを拾えるようにするため。

🔒 **検索する側の言葉と、こちらが発する言葉は別。** `おすすめ` で来てもらうのは構わないが、
広告文とページに「おすすめ」と書くのは禁止語なのでできない（§3）。使うのは「単価」「比較」「一覧」だけ。

- [x] **(3-2)** リンク先URLにUTMパラメータを設定（重要・忘れやすい）

`{keyword}` は Google広告の ValueTrack パラメータで、実際にマッチしたキーワードに自動置換される。

## 3. 広告効果をどこで見るか

## 4. モニタすべき数字・判定基準

[validation-plan.md §5](../research/validation-plan.md#5-判定基準予算-50000-の場合) の基準をそのまま採用する。独自の基準は作らない。

| 指標 | 撤退 | 継続 | 加速 |
|---|---|---|---|
| LP → メール登録 CVR | < 5% | 5〜12% | > 12% |
| CPL（登録単価） | > ¥400 | ¥150〜400 | < ¥150 |
| 登録者数 | < 8 | 8〜20 | > 20 |
| 成分アンケート回答率 | < 30% | 30〜50% | > 50% |
| 成分の集中度 | 分散 | — | 上位2成分に 50% 超 |

### 7日圧縮で読み方に注意すること

7日配信では想定クリック数が50〜90程度になる見込み（元の14日設計でも100〜150クリックで
「統計的に有意ではない」と明記されている水準）。**この規模で得られるのは「数」ではなく
「方向性」と「審査通過の可否」。** 登録者が10人でも、そのうち7人がプロテインを選んだなら
方向性としては十分、という読み方をする。

日次で見るべきもの: 検索語句レポート（除外キーワード追加のため）、GA4のリアルタイム流入。
週次（最終日）でまとめて見れば十分なもの: CVR・CPL・成分集中度の最終判定。

### 判定後のアクション

| 結果 | 次の一手 |
|---|---|
| 加速 | P1 を最多得票の成分で着手。広告は止める（CAC が合わないため） |
| 継続 | P1 着手。ただしSEO起点に切り替え、データコンテンツを増産 |
| 撤退 | LPの訴求を1度だけ作り直して再テスト。2回目も駄目なら企画を再検討 |

## 5. キーワード調査の結果と、入札先の変更（2026-08-18）

生データは [query-volume-research.md](../research/query-volume-research.md) の
「Keyword=Google広告 入札候補（追加調査 / 2026-08-18）」に記録。
取得: キーワードプランナー「過去の指標」/ **地域=日本・言語=日本語** / 2025-08〜2026-07 / 156語。

### 🔒 取得時に一度やらかしたこと — 地域設定

**初回の取得は地域が United States のままだった。** 日本語キーワードなので全語が最下位バケットに
落ち、「全語 0〜10回/月」という結論が出た。**地域=日本で取り直したものが上記の正データ。**
段0 が「初期値が United States になっていることがある」と警告していたとおりの失敗をしている。
以後の取得でも最初に地域と言語を確認すること。

なお**結論そのものは取り直しても変わらなかった**（当初6語は日本でも在庫がない）。
変わったのは根拠の数字と、コスパクラスタの規模が把握できた点。

### 数値はバケット値である 🔒

広告費を使っていないアカウントではボリュームがレンジで返るため、
`5000`=月1,000〜10,000 / `500`=月100〜1,000 / `50`=月10〜100 の3値しか現れない。
**そのままの回数と読まない。**「3か月の推移」「前年比」の `-90%` `900%` `∞` も
バケットを1段またいだだけの見かけの変動なので読まない。

### 結果A: 当初の入札候補6語は在庫なし

| キーワード | ボリューム |
| --- | --- |
| タンパク質 含有 率 高い プロテイン | 月 10〜100 |
| マイ プロテイン 単価 | 月 10〜100 |
| プロテイン タンパク質 単価 | データなし |
| プロテイン 1g あたり 価格 | データなし |
| プロテイン 3kg 単価 | データなし |
| エクス プロー ジョン ザバス 比較 | データなし |

**6語合計でも月200回に届かない。**7日配信では検索が数十回しか起きず、テストが成立しない。

### 結果B: コスパクラスタには十分な在庫がある

最上位バケット（月 1,000〜10,000）が7語。ページ上部入札単価は **¥6〜¥49**。

| キーワード | 競合性(指数) | ページ上部入札単価 |
| --- | --- | --- |
| プロテイン コスパ / コスパ プロテイン | High (100) | ¥7 〜 ¥49 |
| プロテイン コスパ 最強 / コスパ 最強 プロテイン | High (100) | ¥7 〜 ¥42 |
| プロテイン おすすめ コスパ / プロテイン コスパ おすすめ | High (97) | ¥6 〜 ¥36 |
| プロテイン コスパ 最強 ランキング | High (95) | ¥6 〜 ¥28 |

**日予算 ¥500 が消化できる見込みが立った。** この単価なら1日あたり 10〜70 クリック相当で、
7日で当初設計の 100〜150 クリックに届きうる（Semrush の $0.11〜0.18 ≒ ¥16〜27 とも整合）。

競合性 High は**広告主が多いという意味**であり、SEO の難易度ではない。
段0 の KD（コスパ系 18〜25%）とは別指標なので混同しない。

### 何が壊れて、何が壊れないか 🔒

## 6. なぜ7日で意思決定するか

検証している3目的は必要な期間がそれぞれ違う:

| 目的 | 結論が出るまで |
|---|---|
| ①成分需要の大きさ | すでに完了。`query-volume-research.md` のヘッド語ボリューム（22万超）が
撤退基準（10万未満）を大きく上回っている |
| ③薬機法下で広告文が書けるか | 1〜2日（審査結果） |
| ②LP訴求のCVR・成分別の相対人気 | 日数に依存するが、このキーワード群・この予算では
統計的に高い確度に届く前に検索母数（在庫）が尽きる可能性が高い。150クリックでも
「有意ではない」と設計時点で認めている以上、7日でも14日でも読み方の性質は変わらない |

CAC経済性上どのみち恒久チャネルにはしないため、統計的厳密性を追う投資対効果は低い。
**設定・審査1日 + 配信7日 = 実質8日**で、方向性と審査通過可否という当初の目的には十分届く。
