## 0. 前提（必ず読む）

この広告テストの目的は3点に限定される。**「広告を回して伸ばす」ためではない。**

| # | 検証したいこと | 判断への影響 |
|---|---|---|
| 1 | どの成分に最も需要があるか | P1 で作る成分を決める |
| 2 | LP のメッセージが刺さるか（CVR） | 訴求の方向性 |
| 3 | 薬機法の制約下で広告が書けるか | 事業のマーケティング可否そのもの |

1ユーザーあたりのアフィリエイト生涯収益は楽観的に見ても ¥300〜600。CAC が ¥300 を超えた時点で
永続チャネルとしては赤字になるため、**良い数字が出ても「広告を回して伸ばす」に進んではいけない。**

## 1. Google広告の仕組み（初めての人向け）

### オークションと広告ランク

検索結果に広告が出るたびに、その枠を巡ってオークションが行われる。決まるのは
**入札単価 × 品質スコア = 広告ランク** の順位。品質スコアが高いと、入札額が低くても
上位に出せる（＝実際に払うCPCも下がる）。

品質スコアは主に3つで決まる:
- 推定クリック率（このキーワードで、この広告がどれだけクリックされそうか）
- 広告とキーワードの関連性（広告文にキーワードの文脈が含まれているか）
- 遷移先ページの利便性（LPがキーワードの意図に合っているか、表示が速いか）

→ 今回の設計で言うと、**「単価」「比較」で検索した人に、単価比較ができるLPを見せる**ことが
そのまま品質スコアに効く。ズレた広告文にしない。

### キーワードのマッチタイプ

| マッチタイプ | 書き方 | 挙動 |
|---|---|---|
| 完全一致 | `[プロテイン 単価]` | ほぼそのままの検索語のみ |
| フレーズ一致 | `"プロテイン 単価"` | 語順を保った検索語（前後に語が付くのは許容） |
| 部分一致 | `プロテイン 単価` | 関連語まで広く拾う。母数は増えるが関連性が落ちる |

validation-plan.md の指定どおり、**完全一致・フレーズ一致から開始する**（部分一致は使わない）。
無関係な検索に広告費を溶かすリスクを避けるため。

### 検索ネットワークのみを使う理由

Google広告には「ディスプレイネットワーク」「検索パートナー」への配信オプションがあるが、
今回はオフにする。理由: 検索広告は「今まさにその語で検索した人」という顕在需要に直撃できるが、
ディスプレイ/パートナーは意図が薄く、少ない予算で薄めるとどのシグナルも読めなくなる。

### 課金の仕組み

**Google広告に最低課金額はない。** 日予算は上限であってコミット額ではなく、課金は実クリック分のみ。
いつでも停止でき、その時点までの消化分だけ支払う。

### フェーズ3: 広告文

**許可語 / 禁止語**（[CLAUDE.md](../../CLAUDE.md) の禁止語リストと `tests/render.test.js` の
`BANNED_WORDS` に準拠）:

| 使ってよい | 使ってはいけない |
|---|---|
| 単価 / 1gあたり / 比較 / 一覧 / 含有量 / ラベル表示 / 更新日 / 認証 | 効く / 効果 / 改善 / 高品質 / おすすめ / 人気No.1 / 安心 / 話題の / 選ばれる / 実感 |

- [ ] **(3-1)** 広告文を作成（許可語/禁止語チェック込み）。たたき台（例。確定文言は入稿前に必ず読み直すこと）:
```
見出し1: プロテインを1gあたりの価格で比較
見出し2: 内容量と価格を並べるだけ
見出し3: 表示価格ではなく単価で見る
説明文1: パッケージの値段ではなく、タンパク質1gあたりの価格で並べ替え。
説明文2: 含有量の表示に惑わされない比較一覧。
```
成分の効能・効果には一切言及しない（N-02）。優劣も述べない（「〇〇は吸収が良い」等は書かない）。
実際に入稿した最終文言は **(6-1)** のDeliverableに記録する。

- [ ] **(3-2)** リンク先URLにUTMパラメータを設定（重要・忘れやすい）

`src/assets/lp.js` は URL の `utm_source` と `utm_term` を読んで `lp_view` イベントに送っている。
Google広告の自動タグ（`gclid`）だけではこの2つは埋まらず、**付け忘れると全流入が
`source=(direct)` / `keyword=(none)` になり、どの広告からの流入か分からなくなる。**

キャンペーン設定 →「その他の設定」→「**最終ページURLの接尾辞**」に以下を入れる
（個々の広告のURLを毎回書き換えなくて済む）:
```
utm_source=google&utm_medium=cpc&utm_campaign=protein_unitcost_test&utm_term={keyword}
```
`{keyword}` は Google広告の ValueTrack パラメータで、実際にマッチしたキーワードに自動置換される。

## 3. 広告効果をどこで見るか

### Google広告管理画面

| タブ | 見るもの |
|---|---|
| 概要 | 全体のクリック数・費用・CTRのサマリ |
| キャンペーン | 日別の予算消化・クリック単価の推移 |
| 広告グループ → キーワード | キーワードごとの品質スコア・CPC・掲載順位 |
| 検索語句レポート | 実際にどんな検索語で表示・クリックされたか。**除外キーワード追加の材料** |
| 広告 | 広告文ごとのCTR（今回は1バリアントのみなので参考程度） |

### GA4

| レポート | 見るもの |
|---|---|
| 集客 → トラフィック獲得 | `google / cpc` 経由のセッション数（UTMが正しく届いているかの確認） |
| リアルタイム | 配信直後の初動確認 |
| 探索 → 目標到達プロセス | `lp_view → cta_click → waitlist_start → waitlist_submit` の離脱ポイント |

**使い分け:** 「広告費に対してどれだけクリックされたか」はGoogle広告側、
「クリックの先でどれだけ登録に至ったか」はGA4側で見る。CPL（登録単価）を出すには両方の数字が要る
（Google広告の費用 ÷ GA4の `waitlist_submit` 件数）。

## 4. モニタすべき数字・判定基準

[validation-plan.md §5](../research/validation-plan.md#5-判定基準予算-50000-の場合) の基準をそのまま採用する。独自の基準は作らない。

| 指標 | 撤退 | 継続 | 加速 |
|---|---|---|---|
| LP → メール登録 CVR | < 5% | 5〜12% | > 12% |
| CPL（登録単価） | > ¥400 | ¥150〜400 | < ¥150 |
| 登録者数 | < 8 | 8〜20 | > 20 |
| 成分アンケート回答率 | < 30% | 30〜50% | > 50% |
| 成分の集中度 | 分散 | — | 上位2成分に 50% 超 |

### 7日圧縮で読み方に注意すること

7日配信では想定クリック数が50〜90程度になる見込み（元の14日設計でも100〜150クリックで
「統計的に有意ではない」と明記されている水準）。**この規模で得られるのは「数」ではなく
「方向性」と「審査通過の可否」。** 登録者が10人でも、そのうち7人がプロテインを選んだなら
方向性としては十分、という読み方をする。

日次で見るべきもの: 検索語句レポート（除外キーワード追加のため）、GA4のリアルタイム流入。
週次（最終日）でまとめて見れば十分なもの: CVR・CPL・成分集中度の最終判定。

### 判定後のアクション

| 結果 | 次の一手 |
|---|---|
| 加速 | P1 を最多得票の成分で着手。広告は止める（CAC が合わないため） |
| 継続 | P1 着手。ただしSEO起点に切り替え、データコンテンツを増産 |
| 撤退 | LPの訴求を1度だけ作り直して再テスト。2回目も駄目なら企画を再検討 |

## 6. なぜ7日で意思決定するか

検証している3目的は必要な期間がそれぞれ違う:

| 目的 | 結論が出るまで |
|---|---|
| ①成分需要の大きさ | すでに完了。`query-volume-research.md` のヘッド語ボリューム（22万超）が
撤退基準（10万未満）を大きく上回っている |
| ③薬機法下で広告文が書けるか | 1〜2日（審査結果） |
| ②LP訴求のCVR・成分別の相対人気 | 日数に依存するが、このキーワード群・この予算では
統計的に高い確度に届く前に検索母数（在庫）が尽きる可能性が高い。150クリックでも
「有意ではない」と設計時点で認めている以上、7日でも14日でも読み方の性質は変わらない |

CAC経済性上どのみち恒久チャネルにはしないため、統計的厳密性を追う投資対効果は低い。
**設定・審査1日 + 配信7日 = 実質8日**で、方向性と審査通過可否という当初の目的には十分届く。

## 7. リスクと対策

| リスク | 可能性 | 対策 |
|---|---|---|
| UTMパラメータを付け忘れ、`lp_view`の`source`/`keyword`が全部`(direct)`/`(none)`になる | 中 | フェーズ4でDay 1のうちにGA4リアルタイムで確認する手順を明記済み |
| 広告文が薬機法・CLAUDE.mdの禁止語に抵触して審査落ち | 中 | フェーズ3に許可語/禁止語の対照表を明記 |
| 「アフィリエイト」表記が広告審査担当者に誤解を招く | 低 | 検証段階ではLPにアフィリエイトリンクを置かない方針（validation-plan.md §4）。現状のLP実装にアフィリエイトリンクがないことを確認済み |
| 日予算の上限設定を誤り、想定外の費用が出る | 低 | フェーズ1で¥500/日の設定を保存前に再確認する |
| `robots.txt` の `Disallow: /` で広告のクロール・審査が通らない | なし（確認済み） | AdsBot-Google は `User-agent: *` の指定を無視するため、専用の`User-agent: AdsBot-Google`行がない限りブロックされない。着地ページのクロール可否は問題にならない |
