# 先行需要検証プラン (v0.3)

プロダクト: **pergram**（パーグラム）
関連: [product/requirements.md](../product/requirements.md) / [design/service.md](../design/service.md) / [design/design.md](../design/design.md)

---

## 1. 前提: 有料広告は獲得チャネルにならない 🔒

1ユーザーあたりのアフィリエイト生涯収益は楽観的に見ても ¥300〜600。
**CAC が ¥300 を超えた時点で永続チャネルとしては赤字**になる。

したがって本テストで良い数字が出ても「広告を回して伸ばす」に進んではいけない。
本番の獲得チャネルは SEO・データコンテンツ・Chrome 拡張。

**広告テストの目的は以下の3点に限定する。**

| # | 検証したいこと | 判断への影響 |
|---|---|---|
| 1 | どの成分に最も需要があるか | P1 で作る成分を決める |
| 2 | LP のメッセージが刺さるか（CVR） | 訴求の方向性 |
| 3 | **薬機法の制約下で広告が書けるか** | 事業のマーケティング可否そのもの |

3 が最大の収穫。「効く」「改善」を一切使わずに訴求できないなら、この事業はマーケティングが成立しない。それを ¥50,000 で先に知れるのは安い。

## 2. 3段階の検証設計

### 段0: キーワードボリューム調査（¥0 / 1日）

#### 取得手順 🔒 間違えやすい
Google キーワードプランナーには「予測」と「過去の指標」があり、**必要なのは後者**。

1. キーワードプランナー →「**検索ボリュームと予測のデータを確認する**」
2. キーワードを貼り付け
3. **地域「日本」/ 言語「日本語」に変更**（初期値が United States になっていることがある）
4. 「**過去の指標**」タブを開く（「予測」タブではない）
5. CSV をダウンロード

**よくある失敗**: 「Keyword Forecasts」を書き出すと、月間検索ボリュームではなく将来の広告パフォーマンス予測が出る。地域が米国のままだと日本語キーワードは全てゼロになる。

**制約**: 広告費を使っていないアカウントでは、ボリュームが「1万〜10万」のような広いレンジ表示になり正確な数値は出ない。順位付けの参考として扱う。
**補完ツール**: ラッコキーワード（サジェスト網羅）、Google トレンド（相対比較）

#### 2層に分けて見る 🔒
比較クエリのボリュームは、**需要ではなく既存の習慣**を測っている。単価で比べるツールが存在しないため、まだ誰もそう検索していない、という状態がありうる。ここがゼロでも需要がないとは限らない。

| 層 | 例 | 意味 | 判定への使い方 |
|---|---|---|---|
| **ヘッド**（成分名単体） | クレアチン / プロテイン / EAA / HMB / 亜鉛 サプリ / 鉄 サプリ | **市場の大きさ** | ここが小さければ中止 |
| モディファイア | 最安 / コスパ / 比較 / 単価 / 安い / タンパク質量 | 単価で考える習慣の有無 | 参考。小さくても中止しない |
| 指名系 | マイプロテイン 安い / iHerb クレアチン / ザバス 比較 | 個人輸入・価格感度層の厚み | P1 の訴求先を決める |

#### 実測結果（2026-08-05）— **判定: GO**
| クラスタ | 月間 | KD |
|---|---|---|
| ヘッド「プロテイン」 | 135K | 47% |
| ヘッド「クレアチン」 | 90.5K | 34% |
| **プロテイン コスパ系（攻略可能）** | **約15K** | **18〜25%** |
| クレアチン コスパ系 | 約0.5K | — |

ヘッド合計 22万超で中止条件を大きく上回る。ただし**ヘッドは攻略できない**（検索意図が効果・飲み方であり、pergram は薬機法上答えられない）。
攻略可能なコスパクラスタで**プロテインがクレアチンの約30倍**。→ P1 をプロテインに変更。

| 判定 | 基準 |
|---|---|
| **中止条件** | **ヘッド層の合計月間ボリュームが 10万未満** |
| 続行 | ヘッドが十分にあれば、モディファイアが小さくても段1へ進む |
| 補足 | モディファイアが大きい成分は、既に価格で考える層がいる＝P1 候補として優先度が上がる |

### 段1: データコンテンツの反応テスト（¥0 / 3日）

**段1 が実質的な主戦場。** 段2 は検索在庫が小さく統計精度が出ないため、母数は X / note のオーガニックで取るほうが現実的。

**LP は不要。** サイトを作らずに需要を測れるのが段1を先に置く理由。必要なのは画像1枚だけ。

#### なぜクレアチンなら半日で終わるか
クレアチンモノハイドレートは純度がほぼ 100%。**成分表を読む必要がなく、内容量(g)と価格の2つだけで単価が出る。**

```
単価 = 価格 ÷ 内容量g
```

| 手順 | 方法 | 所要 |
|---|---|---|
| 製品リスト取得 | 楽天商品検索 API（無料・審査が軽い）で「クレアチン」検索 | 30分 |
| 内容量の抽出 | 商品名から正規表現で `500g` `1kg` `250g` を拾う | 1時間 |
| 拾えなかった分 | 手作業で商品ページを確認 | 2時間 |
| 画像生成 | [design/service.md](../design/service.md) のトークンで HTML テンプレ → スクリーンショット | 2時間 |

**合計 半日〜1日で 30〜50 製品**。

#### 初版データセットの絞り込み 🔒
**モノハイドレートの粉末のみを対象とする。**

| 除外するもの | 理由 |
|---|---|
| カプセル製品 | 1粒あたり含有量が必要になり、ラベル参照が発生する |
| HCl・その他形態 | 元素量換算が必要（[product/requirements.md](../product/requirements.md) §4.1） |
| ブレンド品（他成分混合） | 単価計算の分母が定義できない |

混ぜると計算が壊れる。除外した製品は「対象外」として記録し、P1 で順次取り込む。

#### 記録する項目
`ブランド / 製品名 / 内容量g / 価格 / 販売元 / 取得日 / 商品URL`
この形式のまま [product/requirements.md](../product/requirements.md) の `Product` + `PriceSnapshot` に流し込める。

#### 投稿設計
| 項目 | 内容 |
|---|---|
| 第1弾 | **意外な事実から入る**。「同じ表示量でも中身が違う」系（[design/ad-lp.md](../design/ad-lp.md) ②のネタ） |
| 第2弾 | 全製品の単価一覧表 |
| 形式 | **画像1枚で完結**させる。リンクは配信が落ちるのでリプライに置く |
| 投稿先 | X、note |
| 見るもの | 保存数・引用RT、コメントの質（「これが欲しかった」系か「知ってる」系か） |
| 副産物 | **この成果物はそのまま P1 のデータになる**ため捨てにならない |

このプロダクトは成果物そのものが広告として機能する。段2 より先に必ずやる。

### 段2: LP + Google 検索広告（実消化 ¥3,000〜6,000 / 2週間）

**Google 広告に最低課金額はない。** 日予算は上限であってコミット額ではなく、課金は実クリック分のみ。いつでも停止でき、その時点までの消化分だけ支払う。

| 項目 | 内容 |
|---|---|
| チャネル | **Google 検索広告のみ** |
| 日予算 | **¥500 × 14日**（上限 ¥7,000） |
| 実消化見込み | ¥3,000〜6,000 |
| 実 CPC | ¥20〜40（Semrush: $0.11〜0.18） |
| 想定クリック | 100〜150 |
| バリアント数 | **1つだけ**。この規模では A/B テストは統計的に成立しない |

**当初の ¥50,000 案は誤り。** 検索在庫が足りず使い切れない。クレアチン系クエリだけを見て試算していたことが原因。

#### 入札先はロングテールにする 🔒
ヘッドクラスタ（「プロテイン コスパ」）で広告を打っても、そこはオーガニックで取れない場所なので検証の意味が薄い。
オーガニックで狙う型と同じロングテールで打ち、**そこでの反応を測る**。

## 3. チャネル選定

| チャネル | 判定 | 理由 |
|---|---|---|
| **Google 検索広告** | ◎ 採用 | 「クレアチン 最安」等の顕在需要に直撃。意図が明確で CVR が読める |
| X 広告 | △ | 筋トレ層は濃いが、広告よりオーガニック投稿の方が効く。段1 でカバー |
| Meta (IG/FB) | ✗ | 健康関連のターゲティング制限が厳しく、変数が増えるだけ |
| YouTube | ✗ | 単価が合わない |
| Reddit | ✗ | 英語圏向け。日本市場では不要 |

### 入札キーワード（完全一致・フレーズ一致から開始）
```
プロテイン タンパク質 単価 / プロテイン 1gあたり 価格
プロテイン 3kg 単価 / タンパク質含有率 高い プロテイン
エクスプロージョン ザバス 比較 / マイプロテイン 単価
クレアチン コスパ / クレアチン 1gあたり
```
除外キーワード: `効果` `副作用` `飲み方` `おすすめ` `ランキング` `育毛` `薄毛` `AGA`
（前4語は情報収集意図が強く CVR が落ちる。後3語は [product/requirements.md](../product/requirements.md) N-09 により対象外）

## 4. 広告審査のリスク管理 🔒

| リスク | 対策 |
|---|---|
| 健康・医療関連ポリシーによる審査落ち | 広告文・LP から効能語を完全に排除。[design/service.md](../design/service.md) §7 の禁止語リストを適用 |
| アフィリエイトサイト扱いによる制限 | 検証段階では**アフィリエイトリンクを LP に置かない**。純粋な待機リストのみ |
| 薬機法違反表現 | 「安い」「単価」「比較」のみで訴求する。成分の働きに一切言及しない |

**広告文で使ってよい語**: 単価 / 1gあたり / 比較 / 一覧 / 含有量 / ラベル表示
**使ってはいけない語**: 効く / 改善 / 高品質 / おすすめ / 人気 / 安心 / 話題

## 5. 判定基準（予算 ¥50,000 の場合）

| 指標 | 撤退 | 継続 | 加速 |
|---|---|---|---|
| LP → メール登録 CVR | < 5% | 5〜12% | > 12% |
| CPL（登録単価） | > ¥400 | ¥150〜400 | < ¥150 |
| 登録者数 | < 8 | 8〜20 | > 20 |
| 成分アンケート回答率 | < 30% | 30〜50% | > 50% |
| 成分の集中度 | 分散 | — | 上位2成分に 50% 超 |

### 最重要の出力は「数」ではなく「構成」と「審査通過」
100〜150 クリックでは統計的に有意な CVR は出ない。**この規模で得られるのは方向性と、以下の2点。**

1. **薬機法の制約下で広告文が書けるか**（審査通過の可否）— 配信量と無関係に判定できる
2. どの成分・どの訴求に反応が集中するか — 段0 の追加調査と段1 の反応で補完する

登録者が 10 人でも、そのうち 7 人がプロテインを選んだなら方向性としては十分。

### 判定後のアクション
| 結果 | 次の一手 |
|---|---|
| 加速 | P1 を最多得票の成分で着手。広告は止める（CAC が合わないため） |
| 継続 | P1 着手。ただし SEO 起点に切り替え、段1 のコンテンツを増産 |
| 撤退 | LP の訴求を1度だけ作り直して再テスト。2回目も駄目なら企画を再検討 |

## 6. 待機リストで取るデータ

**サーバに保存してよいのは以下のみ**（[product/requirements.md](../product/requirements.md) §3.4）。健康状態・体調は一切取らない。

| 項目 | 形式 | 目的 |
|---|---|---|
| メールアドレス | 必須 | 公開通知 |
| 見たい成分 | チップ選択・複数可 | **P1 の対象決定（最重要）** |
| 普段の購入先 | チップ選択・単一 | アフィリエイト提携の優先順位（楽天 / Amazon / iHerb / マイプロテイン / ドラッグストア） |

**入力項目は3つまで。** 年齢・性別・体調は取らない（取る必要がないうえ、GDPR / 個人情報保護法の面倒が増えるだけ）。

## 7. 計測設計（GA4）

| イベント | パラメータ | 目的 |
|---|---|---|
| `lp_view` | source, keyword | 流入 |
| `demo_interact` | nutrient_id, action | ランキングデモに触ったか（＝価値が伝わったか） |
| `ruler_filter` | filter_key | プレミアム幅の理解度 |
| `waitlist_start` | — | フォームに触れた |
| `waitlist_submit` | selected_nutrients, purchase_channel | **主 KPI** |
| `scroll_depth` | 25/50/75/100 | どこで離脱するか |

`demo_interact` が低いのに `waitlist_submit` が高い場合、デモが理解されずに雰囲気で登録されている＝訴求が実体と乖離している合図。

## 8. スケジュール

| 週 | 内容 |
|---|---|
| W1 | 段0 キーワード調査（地域＝日本 / 過去の指標タブ）→ 段1 用のクレアチンデータを 30〜50 製品分収集 |
| W2 | 段1 コンテンツ投稿・反応観察。並行して LP 制作 |
| W3-4 | 段2 広告配信 |
| W5 | 判定・P1 着手判断 |

**W1 のデータ収集は捨てにならない。** そのまま [product/requirements.md](../product/requirements.md) の P1 成果物になる。
