### 🔒 数値の読み方 — バケット値であって実測値ではない

広告費を使っていないアカウントではボリュームがレンジで返る。CSV にはその**代表値**が入るため、
`50` `500` `5000` という値しか現れない。**そのままの回数と読んではいけない。**

| CSV の値 | 実際の意味 |
| --- | --- |
| 5000 | 月 1,000〜10,000 回 |
| 500 | 月 100〜1,000 回 |
| 50 | 月 10〜100 回 |
| 0 | ほぼゼロ |
| 空欄 / `--` | 検索が少なすぎてデータが出ない |

同じ理由で「3か月の推移」「前年比」に現れる `-90%` `900%` `∞` `-100%` は
**バケットを1段またいだだけの見かけの変動**であり、傾向として読む意味がない。

### 分布と、そこから言えること

156語の内訳: 5000 が7語 / 500 が18語 / 50 が125語 / 0 が2語 / 空欄が4語。

- **予算が消化できる見込みが立った。** 主要クラスタのページ上部入札単価は ¥6〜¥49。
  日予算 ¥500 なら 1日あたり 10〜70 クリック相当で、7日で当初設計の 100〜150 クリックに届きうる
  （Semrush の $0.11〜0.18 ≒ ¥16〜27 とも整合）
- **競合性 High は「広告主が多い」という意味**であって、SEO の難易度ではない。
  段0 で使った KD（18〜25%）とは別の指標なので混同しない
- **ブランド名 × コスパ は全て 50 バケット**（マイプロテイン / ザバス / ビーレジェンド /
  DNS / ゴールドスタンダード / グロング / コストコ / マツキヨ 等）。§5 の追加提案にあった
  「競合ブランド名 × 単価系」は、**掛け合わせでは在庫が立たない**ことが確認できた
- **価格不満系も 50 バケット**（`プロテイン 安い サイト` `プロテイン 格安 サイト`
  `プロテイン 安く 購入` `国内 プロテイン 安い`）。しかも入札単価の高額側が
  ¥149〜¥245 と高い。**在庫が小さく単価が高いので、入札先としては不利**
- `プロテイン 含有 量 コスパ`（50 / ¥7〜¥27）は語としては最も pergram 的だが在庫が小さい。
  SEO で取りにいく語であって、広告で買う語ではない
