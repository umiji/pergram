# X 投稿コーパス（伸びた／平凡 の対照サンプル）

pergram の X オーガニック投稿の「型」を、推測ではなく**対照付きの実データ**から
決めるための収集台帳。

## なぜ対で集めるのか

伸びた投稿だけを集めて共通点を探すと、必ず共通点が見つかる。だがそれは
**同じ構造で書いて伸びなかった投稿が見えていないだけ**で、その特徴に説明力が
あるかどうかは分からない（生存者バイアス）。

同一アカウントから「伸びた1本」と「平凡な1本」を対で取ることで、フォロワー数・
アカウントの質・投稿時期といった交絡要因が相殺され、**差分を投稿そのものに
帰属できる**。

## 収集ルール 🔒

| 項目 | ルール |
|---|---|
| 単位 | 1アカウントにつき必ず**2本（伸びた／平凡）**。片方だけの登録は使わない |
| 目標 | 20アカウント = 40本 |
| 「伸びた」の判定 | 絶対値ではなく**そのアカウントの直近30本程度の中での相対上位** |
| 「平凡」の判定 | **中央値あたり**。最下位を選ばない（告知・連投など別の失敗要因が混ざる） |
| 本文 | 改行も含めて**全文をそのままコピペ**。要約・整形をしない |
| 除外 | 疾患・症状を扱うアカウント（pergram は同じ手法を採れないため、型が歪む） |
| 除外 | プレゼント企画・相互フォロー系（エンゲージメントの発生機序が別物） |

他人のインプレッションは外から見えないので、数値は見えるものだけでよい。
**見えない項目は空欄のままにする。推測で埋めない。**

## 単独サンプル（⚠️ 対照なし）

**収集ルール上、対で登録できないもの。**同じ書き手の平凡な投稿が取れていないので、
「この要素が効いた」とは言えない（生存者バイアス）。**型の仮説を起こすためだけに使う。**
対照が取れたら下の「サンプル」へ移し、そこで初めて検証する。

### S-01 @gunso_stingray（フォロワー約500人 / 領域: 筋トレ・減量）

- 投稿日: 2026-08-12 16:50
- **表示 5.6M**（自アカウント外の実測値がスクリーンショットで見えている稀なケース）
- いいね 2.3K / リポスト 85 / 返信 64 / **ブックマーク 995**
- 画像: あり（栄養成分表示の実物写真1枚）
- 外部リンク: なし
- 本文（要約せず全文。⚠️ 一部はスクリーンショットの折りたたみで読めていない）:
```
これ普通に売っていいの？
スーパーで見つけたとんでもない減量食
100gあたり
たんぱく質63.8g。
脂質3.1g。

さらに
カルシウム2,200mg。
```

#### 計測できた形式的な特徴

| 項目 | 値 | pergram の現行ルールとの関係 |
|---|---|---|
| 文字数 | **174字（加重297）** | 🔒 日本語の上限140字を超えている。**この書き手は X Premium** |
| 行数 | **28行** | 折りたたみ線が「炭水化物0.1g。」に落ちる |
| 折りたたみ | **あり**（意図的と見られる） | うちの「9行以内に収める」は**この型には当てはまらない** |
| ブックマーク / リポスト | **11.7倍** | 拡散より「あとで探す」が主。保存される投稿だった |
| 返信 / いいね | 2.8% | 「分かった人いますか？」が効いている |

#### 抽出した型

10要素に分解して `.claude/skills/x-post/reference/formats.md` の
**型H「正体当てクイズ（消去法つき）」**に落とした。要点は
「規範への抵触で始める / 数字を先・正体を後 / 1行1情報で縦に積む / 異常値を選ぶ /
数字を素人の言葉に翻訳する / 消去法で候補を潰す / 承認欲求を刺激する /
答えは画像側 / 一次資料の写真」。

#### 🔒 この1本から言ってはいけないこと

- 「長い投稿ほど伸びる」— **対照が無い**。同じ書き手の短い投稿の成績を知らない
- 「クイズ形式なら伸びる」— 同上。題材（異常な栄養成分表示）の力かもしれない
- 「ブックマークが多いと伸びる」— ブックマークの重みは公開コード上 **0.0**
  （[X_algorithm_2026.md](../Marketing/X_algorithm_2026.md)）。相関であって原因ではない

**次にやること**: この書き手の平凡な投稿を1本取って対にする。そこで初めて
「型Hの要素のどれが効いたか」を差分として言える。
