# 効果の確認

対象アカウント: `$ARGUMENTS`

**このコマンドは投稿を行わない。** 集計を読むだけ。

## 手順

1. まず指標を取り込む。X 上の投稿の指標は、取り込まない限り DB に入らない。

   ```bash
   media-agent x metrics --account <アカウント>
   ```

   - 「未照合」が出た投稿は、この Project から出したものではないか、本文が編集されている。
     **異常ではない**ので、そのまま報告する。
   - 「指標が取れず」が出たら抽出が壊れている可能性がある。`media-agent x doctor --live` を勧める。
   - X の読み取りが無効なら、この段は飛ばして 2 へ進む（過去に取り込んだ分の集計はできる）。

2. 集計する。

   ```bash
   media-agent report --account <アカウント>
   ```

## 報告のしかた

- **「測定できている割合」を最初に伝える。** これが低いと、平均値はどれも当てにならない。
  半分以下なら「まだ比較できる段階ではない」とはっきり言う。
- **「未測定」の件数を平均値と一緒に読み上げる。** 平均だけを見せると、n=1 の平均と
  n=30 の平均が同じ顔をする。
- 平均が「未取得」と出ている区分は、**0 ではなく「まだ測れていない」**である。
  「伸びていない」と読み替えてはいけない。

## 判断を急がない

- 投稿数が少ないうちは、ペルソナ間・playbook 間の差は偶然である可能性のほうが高い。
  **差があるように見えても、まず件数を確認する。**
- 「この playbook は効いていない」と結論づけるのは、同じ条件で十分な件数が溜まってから。
  利用者が結論を急いでいる場合は、件数を根拠に「まだ言えない」と伝える。

## 次にできること

- 型を見直したいなら `/media-learn`。
- 特定の playbook を試すなら `media-agent post --playbook <ID>`（投稿はされない）。
