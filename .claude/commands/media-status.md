# メディア運用の状態確認

対象アカウント: `$ARGUMENTS`

**このコマンドは投稿を一切行わない。** 読み取りだけで完結する。

## 手順

1. アカウントが指定されていなければ、まず登録済みの一覧を出して利用者に選んでもらう。

   ```bash
   media-agent accounts
   ```

2. 状態を表示する。

   ```bash
   media-agent status --account <アカウント>
   ```

3. 環境に問題がないかを確認する（ネットワーク通信は行わない）。

   ```bash
   media-agent doctor --account <アカウント>
   ```

4. 送信待ちや失敗が残っていないかを確認する。

   ```bash
   media-agent queue list --account <アカウント>
   ```

## 報告のしかた

- `doctor` に FAIL があれば、それを最初に伝える。原因と対処をそのまま引用する。
- WARN は「動くが精度が落ちる」ものなので、FAIL と混ぜずに分けて伝える。
- 送信待ちや失敗が残っている場合は件数と Run ID を伝える。
- 問題がなければ短く済ませる。長い出力をそのまま貼らない。
