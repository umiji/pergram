# 投稿候補の生成と確認

対象アカウント: `$ARGUMENTS`

**このコマンドは投稿を行わない。** 候補を作って中身を見るところまで。

## 手順

1. アカウントが指定されていなければ、一覧を出して選んでもらう。

   ```bash
   media-agent accounts
   ```

2. 情報を集める。

   ```bash
   media-agent research --account <アカウント>
   ```

3. 候補を生成して評価する。**`post` は投稿しない** — 候補の生成・評価・選定までを行う。

   ```bash
   media-agent post --account <アカウント>
   ```

   保存もせず内容だけ見たい場合は `--dry-run` を付ける。

4. 生成された候補を利用者に見せる。

## 報告のしかた

- 採用された候補の本文を**そのまま全文**見せる。要約しない。投稿されるのはその文面なので、
  利用者が読むべきなのは実物である。
- 評価スコアと、採用・不採用の理由を添える。
- 落ちた候補も、なぜ落ちたかが分かる程度に短く触れる。
- 生成物の質が低いと感じたら、`strategy.md` と `rules.md` が記入済みかを確認する。
  未記入だと評価側がターゲットやトーンと照合できず、汎用的な出来にしかならない。

## 出すかどうかの判断

内容がよければ、実際に配信するかを利用者に尋ねる。配信は `/media-run` で行う。
**このコマンドの中で勝手に配信しないこと。**
