# ペルソナから投稿文までの手順

「何を書くか」を思いつきで決めないための道筋。**上から順に1つずつ落としていく。**

```
① ペルソナを選ぶ  →  ② その人の関心を出す  →  ③ 🔒 答えられない関心を捨てる
   →  ④ トピックに割り当てる  →  ⑤ メッセージを1行にする
   →  ⑥ 型に流し込む  →  ⑦ 機械に通す
```

⑤より前を飛ばすと「作業報告」になり、⑤を飛ばすと「材料の羅列」になる。
どちらも読み手には何も残らない。

---

## ① ペルソナ

根拠は [requirements.md §2.1](../../../../docs/product/requirements.md)（中核ターゲットの定義）と
[validation-plan.md 段0](../../../../docs/research/validation-plan.md)・
[query-volume-research.md](../../../../docs/research/query-volume-research.md) の実測ボリューム。
**思いつきで足さない。**足すなら先に調査側を更新する。

### P-A 量を飲む人（いまのフォロワーの中心）

| 項目 | 中身 |
|---|---|
| 誰 | 週3〜5回トレーニング。月に2〜4kg 消費する。大容量・国内ブランド中心 |
| 根拠 | 指名検索「エクスプロージョン プロテイン」74K。大容量常用層が厚い |
| 口に出す不満 | 「また値上げ」「セールって結局安いのか」「3kg買ったけど得だったのか」 |
| うちが答えられる | 実質いくら払っているか。袋の値段と単価のずれ。セール前後の単価 |
| 🔒 答えられない | 味・溶けやすさ・飲み方・効き方 |

### P-B 計算する人（🔒 中核ターゲット）

| 項目 | 中身 |
|---|---|
| 誰 | iHerb・個人輸入も使う。為替と送料込みで自分で単価を出す習慣がある |
| 根拠 | requirements.md §2.1「数字で考える層であり、pergram の想定読者そのもの」 |
| 口に出す不満 | 「送料込みだと逆転する」「関税ラインを超えた」「表示の基準がバラバラで比べられない」 |
| うちが答えられる | 計算の前提（含有率・元素量・送料の扱い）。表示の読み方。データの作り方 |
| 🔒 答えられない | 個別の関税判断、届くまでの日数 |

### P-C 始めたばかりの人

| 項目 | 中身 |
|---|---|
| 誰 | 最近飲み始めた。選ぶ物差しを持っていない |
| 根拠 | 「プロテイン おすすめ」90.5K。ヘッド「プロテイン」135K |
| 口に出す不満 | 「何を見て選べばいいのか分からない」「高いのと安いので何が違うのか」 |
| うちが答えられる | 見る場所（裏面の栄養成分表示）。単価という物差しの存在 |
| 🔒 答えられない | **この層の関心の大半（効果・飲むタイミング・おすすめ）** |

## ② その人の関心を出す

ペルソナの言葉で書く。**うちが言いたいことではなく、その人が口に出すこと。**
検索されている言葉は固有名詞ごと使う（X のアルゴリズムに読み手層を認識させる）。

---

## ③ 🔒 答えられない関心を捨てる ← いちばん重要

**需要の大きさで選ばない。**実測ボリュームが大きい関心ほど、うちが答えられない。

| 関心 | 月間 | 扱えるか |
|---|---:|---|
| プロテイン 効果 | 27.1K | ❌ N-02 |
| プロテイン 飲むタイミング | 33.1K | ❌ N-02 |
| プロテイン おすすめ | 90.5K | ❌ N-03（順位は単価だけで決まる） |
| クレアチン はげる | 9.9K | ❌ N-09 |
| プロテイン コスパ・比較・単価 | 約15K | ⭕ **ここだけが持ち場** |

捨てた関心に**隣接する答えられる問い**へずらす。ここが腕の見せどころ。

| 答えられない問い | ずらした先（答えられる） |
|---|---|
| どれがおすすめ? | 何を見れば自分で選べるか |
| 高いのと安いので何が違う? | 値段の差が何の差なのか（含有率・内容量・送料） |
| セールで買うべき? | セールの前後で単価がどう動いたか |
| WPIとWPCどっち? | 種類ごとに単価の帯がどう違うか（優劣は書かない） |

## ④ トピックに割り当てる

[topics.md](topics.md) の12カテゴリのどれかに落とす。
`npm run x:feed` の「まだ話していないトピック」と突き合わせる。

| ペルソナ | 相性のよいトピック |
|---|---|
| P-A 量を飲む人 | 市場と相場 / 価格の動き / 買い物の実務 |
| P-B 計算する人 | 表示の読み方 / 作る側の裏話 / 成分の単位 / 制度と出典 |
| P-C 始めた人 | 単価という考え方 / 表示の読み方 / 製品の種類 |

🔒 **同じペルソナに2本続けない。**同じ人にばかり話しかけると、他の層が離れる。

## ⑤ メッセージを1行にする

材料を**読み手の持ち帰り**に変換する（SKILL.md 手順6の変換表）。
1投稿1メッセージ。2つ入れると両方伝わらない。

- ⭕「ECの『安い順』は最安を教えてくれない」（明日の買い物が変わる）
- ❌「除外リストを書く作業から始まりました」（作業報告）
- ❌「pergram なら一発で分かります」（宣伝であって持ち帰りではない）

**テスト**: 「だから何?」に1行で答える。答えられなければ捨てて④に戻る。

## ⑥ 型に流し込む

[formats.md](formats.md) から、**メッセージの性質**で選ぶ。トピックで選ばない。

| メッセージの性質 | 型 |
|---|---|
| 思っていたことがひっくり返る | 三段＋引き / 二分法 |
| 見る場所・手順が変わる | 3ステップ図解 |
| 気づいた瞬間がある | 会話ログ（🔒 自分の作業ログに限る） |
| 順位・数字が主役 | リード＋図解画像（`x:card`） |
| 意見を聞きたい | 短い断定＋問いかけ（単発） |

⚠️ 型が3回続いたら変える。トピックを変えても型が同じなら同じ投稿に見える。

## ⑦ 機械に通す

```bash
npm run x:lint -- draft.txt --feed
```

文字数・禁止語・URL の位置・折りたたみ位置・過去投稿との近さ。
**error が残った文章を出さない。**

## 1週間の組み方（例）

ペルソナと型を回す。単価の話は3本に1本まで。

| 曜日 | ペルソナ | トピック | 型 |
|---|---|---|---|
| 月 | P-C | 単価という考え方 | 二分法 |
| 水 | P-B | 表示の読み方 | 3ステップ |
| 金 | P-A | 市場と相場 | 三段＋引き |
| 日 | P-A | 単価の出し方（`x:facts`） | リード＋画像 |
