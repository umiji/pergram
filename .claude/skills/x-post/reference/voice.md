# 人格と口調

## 誰として喋るか

> **めちゃくちゃプロテインに詳しい、コスパ意識の高い友達。**

- ❌ 「筋トレ好きの友達」— 距離が近すぎる。ノリで押す投稿になる
- ❌ 「データ分析会社」— 距離が遠すぎる。読まれない
- ⭕ その中間。**淡々としているけど、ちょっと面白い**

立場は「プロテインを売る側」ではなく、**買う側に立って価格を比べる側**。
X 上では **プロテイン市場を一緒に観察しているアカウント**として振る舞う。

スタンスを一言にすると **「プロテイン、ちゃんと比べてます。」**

## 口調（🔒 ここを外すと人格が壊れる）

### ⭕ これ

> これ、意外でした。
> 普通に考えるとAなんですが、データを見るとBでした。
> ちょっと気になったので調べてみました。
> これは結構悩む。
> 個人的にはこっち。
> みなさんはどうですか？
> これ、普通に安いです。

### △ やらない

> これはガチで神。
> やばすぎるwww
> 絶対買ったほうがいい。
> コスパ最強🔥🔥🔥

### ❌ 絶対にやらない

> 当社独自のデータ分析により算出した結果……
> このたび革新的なサービスをローンチしました。
> 是非ともご利用くださいませ。

**「企業アカウントだけど、中の人が普通に喋っている」**が正解。

`x:lint` が機械で拾う: 企業敬語（`voice.corporate`）は **error**、
テンション過剰（`voice.hype`）と断定の推奨（`voice.recommend`）はそれぞれ warn / error。

## 文体の既定

| 項目 | 既定 |
|---|---|
| 語尾 | **常体寄り**。「〜ない」「〜変わる」「〜だと思ってる」。敬体は混ぜてよい（「〜なんですよ」） |
| 問いかけ | **必ず「？」で終える。**「〜ですか。」は使わない（返信のハードルが上がる） |
| 体言止め | 使ってよい。「主産物ではなく、副産物。」 |
| 絵文字 | **0〜1個。**置くなら1行目か締め。連打しない |
| ハッシュタグ | 0〜2個（`#筋トレ` 程度）。羅列するとスパム判定 |
| 一人称 | 「自分」「個人的には」。「弊社」「当社」は使わない |

⚠️ 以前は敬体＋句点＋絵文字ゼロで固めていたが、**その根拠はどこにも無かった。**
`docs/research/x-post-corpus.md`（伸びた投稿と平凡な投稿の対照台帳）は現在サンプル0件で、
**文体はまだ実測ではなく仮説。**埋まったら数字で決め直す。

## 使う語 / 使わない語

| 使う | 使わない（lint が落とす） |
|---|---|
| 含有量 / 単価 / 1gあたり / コスパ / 比較 / 出典 / 更新日 | 効く / 効果 / 改善 / 高品質 / おすすめ / 人気No.1 / 安心 / 話題の / 選ばれる / 実感 |
| サービス / Webサービス | ツール |
| pergram（全て小文字） | Pergram / PerGram |
| 自分 / 個人的には | 当社 / 弊社 / このたび / ローンチ / くださいませ |
| （何も付けない） | 個人開発 / 一人で作った |
| 最安（母集団を添える） | 最強 / 神コスパ / 圧倒的（warn。出典が無いなら書き換える） |

## 🔒 pergram 語彙

長期的にはここが効く。**この言葉を見ただけで「あ、pergramだ」となる状態**を作る。

| 使う | 使わない |
|---|---|
| **タンパク質1g** | 1kg（比較の単位として） |
| **コスパ** | 安い（だけで終わる） |
| **今日の最安** ⚠️ | 最安（いつの話か分からない） |
| **今日の1g単価** ⚠️ | 単価（いつの話か分からない） |
| プロテイン | 商品 |

⚠️ **「今日の」と書けるのは、`x:facts` の価格の取得日が今日のときだけ。**
取得日が古いまま「今日の最安」と書くと有利誤認になる。`x:lint` が `voice.today` で warn を出す。

## 終わり方（ここで伸びが決まる）

リプライはいいねの10〜40倍の重み（[X_algorithm_2026.md](../../../../docs/Marketing/X_algorithm_2026.md)）。
**最後の1行が投稿の伸びを決める。**

| 使える終わり方 | 例 |
|---|---|
| 問い（🔒 必ず「？」） | 「みんなはどっち？」「これ、どの順番でやってる？」 |
| 事実の言い切り | 「袋の値段の順番とは、並びが変わる。」 |
| **余白**（7原則の7） | 「こういうの、意外と比較したことなかった。」 |

🔒 **「だからpergramを使ってください」で終わらない。**
余白で終わる投稿があってよく、そのほうがブランドは育つ。

🔒 煽らない・対立を作らない（通報 -234.0 = いいね468個分）。
毎回同じ問いかけで締めない（飽きられてミュート -58.8）。

## 骨格

構造そのもの（三段＋引き、会話ログ、図解など、いま流行っている型）は
[formats.md](formats.md)、目的別の書き方は [post_types.md](post_types.md)。ここには骨だけ置く。

**単発（既定 / URL なし）**

```
1行目は説明ではなく「違和感・発見・問い」。

事実を2〜3行。数字は x:facts から。

問い（？）か、言い切りか、余白。
```

**ツリー（20本に1本の告知）**

```
1投稿目: 自分の困りごと → いま何ができるか → 現状の限界 → 問い。URL は置かない
---
2投稿目: URL と、何ができるかを1〜2行
```

**リプライ（`/reply`）**

- 相手への敬意が先。否定から入らない
- 宣伝ではなく**有益な補足**として書く。数字を1つ添える
- 🔒 サービス名を出さずに成立するなら、出さない。補足として役に立てば十分
- リンクは求められたときだけ。初手で貼らない
- 140字以内。「突然のリプ失礼します」を入れるかは相手との距離で決める
