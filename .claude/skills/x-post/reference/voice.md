# 文体・フック・型

CLAUDE.md「コピーの規則」＋ [docs/Marketing/X_post_strategy.md](../../../../docs/Marketing/X_post_strategy.md)。
⚠️ 戦略文書の**例文**は禁止語を含む。狙いだけ借りて、語彙は下の表に従う。

## トーン

- 公式アカウント。清潔感のある知的な書き方。煽らない、媚びない、謝らない
- 能動態。事実だけを書き、優劣を述べない
- 絵文字は0〜1個。無くてよい。連打しない
- ハッシュタグは0〜2個（`#筋トレ` 程度）。羅列するとスパム判定される
- 時間帯の指定があれば合わせる（朝は短く要点、夜は落ち着いた語り口）

## 使う語 / 使わない語

| 使う | 使わない（lint が落とす） |
|---|---|
| 含有量 / 元素量 / 単価 / 1gあたり / 認証 / 出典 / 更新日 / 比較 / 一覧 | 効く / 効果 / 改善 / 高品質 / おすすめ / 人気No.1 / 安心 / 話題の / 選ばれる / 実感 |
| サービス / Webサービス | ツール |
| pergram（全て小文字） | Pergram / PerGram |
| 公式アカウントとしての「私たち」 | 個人開発 / 一人で作った |
| 最安（母集団を添える） | 最強 / 神コスパ / 圧倒的（lint が warn を出す。出典が無いなら書き換える） |

## 3層で組む

1. **フック（1行目）** — 指を止める。損失回避・意外性・手間の共感
   例: 「袋の値段では順位が出ない」「電卓を叩くのをやめた」「同じ3kgでも中身が違う」
2. **トピックと固有名詞** — X のアルゴリズムに読者層を認識させる
   例: プロテイン / タンパク質1gあたり / WPI / WPC / 含有率 / セール / 楽天
3. **具体的な数字** — `npm run x:facts` の出力からのみ。単位と基準を必ず添える

## 切り口（直近と被らせない）

`npm run x:feed` が「使ったテーマ / まだ使っていないテーマ」を出す。そこから選ぶ。

| 切り口 | 中身 |
|---|---|
| 内容量の罠 | 大容量＝安いとは限らない。含有率で割ると順が変わる |
| 電卓の手間 | セールのたびに手計算していた話 |
| 含有率 | 同じ「プロテイン」でも中身の割合が違う |
| WPI / WPC | 種類ごとに単価の帯が違う（事実の提示まで。優劣は書かない） |
| 値上げ | 値上げ局面で単価がどう動いたか |
| セール連動 | セール時の単価を取り直した結果 |
| 中立性 | 順位の決め方そのもの（報酬額を混ぜない設計） |
| 更新頻度 | いつ取得した価格か |
| 送料 | 送料込み／別で単価の見え方が変わる |
| β版の現状 | 何ができて何がまだか。誇張しない |

## 型

**単発（会話を増やす / URL なし）**

```
フック1行。

事実を2〜3行。数字は x:facts から。

問いかけ、または言い切り。
```

**ツリー（サイトへ送る）**

```
1投稿目: フック＋事実。URL を置かない。ここだけで完結して読める
---
2投稿目: 一覧はこちら <URL>／何ができるかを1〜2行／登録不要・無料
```

**リプライ（`/reply`）**

- 相手への敬意が先。否定から入らない
- 宣伝ではなく**有益な補足**として書く。数字を1つ添える
- リンクは求められたときだけ。初手で貼らない
- 140字以内。「突然のリプ失礼します」を入れるかは相手との距離で決める
