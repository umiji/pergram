# 投稿の構造（いまタイムラインでよく見る型）

⚠️ **出所は検索で集めた二次情報（2026-08-21 確認）。**重みの数値は
[X_algorithm_2026.md](../../../../docs/Marketing/X_algorithm_2026.md)（公開コード）が勝つ。
表示の仕様は端末とバージョンで変わる。**型は流行り廃りがあるので、そのまま長く使わない。**

## なぜ「最後だけ見せない」型が増えたのか

タイムラインでは投稿の途中に「さらに表示」の境目ができる。

| 端末 | 隠れる条件 |
|---|---|
| ブラウザ | 141文字目以降。または **11行目以降** |
| スマホアプリ | 141文字目以降（行数は問わないという報告と、10行前後で折りたたむという報告の両方がある） |

⚠️ 端末差があるので厳密に当てにいかない。**9行以内なら全端末で全文、10行を超えたら
「隠れる前提で組む」**の2択で扱う。どこで切れるかは `npm run x:lint` が線を引いて見せる。

🔒 **折りたたみは避けるものではなく、設計して使うもの。**
実測サンプル（[x-post-corpus.md](../../../../docs/research/x-post-corpus.md) S-01、5.6M表示）は
**28行**で、しかも折りたたみ線が数字の途中に落ちている。それでも伸びた。
条件は1つだけ:

> **折りたたみ線の手前で「続きが気になる」が完成していること。**

線の手前が説明で終わっていると、そこで閉じられる。`x:lint` の `layout.fold` は
「隠れる位置が意図どおりか」を聞いているのであって、短くしろとは言っていない。

日本語は140文字が上限（＝加重280）なので、**文字数ではなく行数で境目を作る**のが
いま多い形。境目の向こうに答えを置くと、次の3つが起きる。

- 投稿そのもののクリック（0.4）
- 「答えは?」がリプライになる（5.0 / 相互フォロー相手なら 20.0）
- 読み飛ばし（-0.02）を避けられる

🔒 **ただし、境目の向こうに実質が無ければただの釣り。**
釣りは「興味なし -43.2」「ミュート -58.8」への最短路で、いいね100個分が一撃で飛ぶ。

## 型

そのまま流用しない。**pergram 版**の列まで読んでから使う。

### A. ラベル＋三段＋引き

```
男のレベルは
初回デートに持ってくるバッグで差がつく。

🥉それはやめよっか…
・リュック
・パンパンの肩掛け

🥈マイナスではない
・小さめのショルダー

🥇センスよき↓
```

- **構造**: ラベル1行 → 主張1行 → 空行 → 3段（各段は見出し＋箇条書き2〜3） → 最上段だけ伏せて `↓`
- **効く理由**: 段が3つだと読む負担が軽い。自分がどれかを当てはめられる。最後が空いているので続きを探す
- **pergram 版**: 🔒 **優劣の断定（「それはやめよっか」）は使えない**（コピーの規則・景表法）。
  ランクではなく**分かることの段階**に置き換える

  ```
  プロテインの単価は
  袋の値段では出ません。

  ここまでで分かること
  ・袋の値段
  ・内容量

  もう一段で分かること
  ・1食あたりの価格

  最後まで割って初めて出るもの↓
  ```

### B. 会話ログ・寸劇

```
～◯◯にて～
ぼく「〜ですか?」
担当「〜ですよ」

↓(場面転換)↓

ぼく「まず、〜とは…」
```

- **構造**: 場面の見出し → 短い掛け合い → `↓(転換)↓` → オチの直前で切る
- **効く理由**: 台詞は読むのが速くリズムが出る。難しい話を軽くできる
- **pergram 版**: 🔒 **実在の店員・メーカー・他人の発言を作らない**（創作した会話は事実ではない）。
  使うなら**自分の作業ログ**にする

  ```
  ～価格を取り直していたら～

  ぼく「この5kg、安いな」
  ぼく「…含有率85%か」
  ぼく「割ると ¥1.9 / タンパク質1g」

  ↓(そのまま隣の3kgを割る)↓
  ```

### C. リード1〜2行 ＋ 図解画像

- **構造**: 断定か問いを1〜2行 → 本体は画像1枚 → 「保存」を促す一言
- **効く理由**: 本文が短いので読み切られる。情報は画像に集約
- **pergram 版**: `npm run x:card --type rank` がこの画像。
  ⚠️ 画像の重みは 0.05 しかない。**画像はスコアのためではなく読まれるために貼る**

### D. 二分法（これまで / これから）

- **構造**: 見出し → ❌側3行 → ⭕側3行 → 締めの1行
- **pergram 版**: ❌⭕ は「間違い / 正解」ではなく「袋の値段で見る / 1gあたりで見る」の
  **見方の違い**として書く。`--type split` の画像と対になる

### E. ◯選・数字ラベル

- **構造**: 「◯◯3選」→ 箇条書き → 具体例
- **pergram 版**: 数字は `npm run x:facts` の出力から。
  🔒 「おすすめ3選」は書けない（N-03）。「1gあたりが安い3件」なら事実

### F. 体験 → 学び → チェックリスト

- **構造**: 自分の失敗の告白 → 抽象化した学び → 再現用の箇条書き
- **pergram 版**: 公式アカウントとしての体験（価格を取り直していて気づいたこと）に限る。
  「個人開発」の語りにしない

### G. ミーム構文（タゴサク構文など）

- 短い・断定的・理屈っぽい語調をそのまま借りる型。参加しやすいので広がる
- **pergram では基本使わない。** 出所の文脈（映画・事件・人物）を背負うため、
  取り違えると一撃で信用を失う。公式アカウントが払うコストに合わない

### H. 正体当てクイズ（消去法つき）← **実測サンプルから起こした型**

出所は [x-post-corpus.md](../../../../docs/research/x-post-corpus.md) の S-01
（フォロワー約500・**5.6M表示 / いいね2.3K / ブックマーク995 / リプ64**）。
栄養成分表示だけを先に出し、商品名を最後まで伏せる。

```
これ普通に売っていいの？

スーパーで見つけたとんでもない減量食

100gあたり

たんぱく質63.8g。

脂質3.1g。

炭水化物0.1g。

さらに

カルシウム2,200mg。

袋の中身の半分以上が
たんぱく質です。

でも、

プロテインではありません。

サラダチキンでもありません。

ここまでで分かった人いますか？

正体は↓
（成分表示の実物写真）
```

**分解すると10個。全部入れて初めて効く。**

| # | 要素 | やること |
|---|---|---|
| 1 | **規範への抵触で始める** | 「これ普通に売っていいの？」— 説明ゼロ。"何かおかしい"の信号だけ |
| 2 | **場面は身近に** | スーパー。誰でも遭遇しうる場所にする |
| 3 | **数字が先、正体は後** | 普通は商品名→成分。**順序を逆にする** |
| 4 | **1行1情報で縦に積む** | 数字を1行ずつ改行。行間が空いてスクロールが止まる |
| 5 | 🔒 **異常値を選ぶ** | 63.8g/100g も 炭水化物0.1g も明らかに変。**普通の数字では成立しない** |
| 6 | **数字を翻訳する** | 「63.8g」→「袋の中身の半分以上がたんぱく質」。素人の言葉に直す |
| 7 | **消去法で候補を潰す** | 「プロテインではありません」「サラダチキンでもありません」— 読者の推測を封じる |
| 8 | **承認欲求を刺激する** | 「分かった人はかなりすごい」→ 分かる人は答えたくなる（リプが伸びる） |
| 9 | **答えは画像側に置く** | 本文だけで完結させない。画像クリックと滞在が伸びる |
| 10 | 🔒 **一次資料の写真** | 成分表示の実物。「本当だ」を作っているのは文章ではなく写真 |

ブックマーク（995）がリポスト（85）の**11倍**。「あとで探したい」を作っている。

#### pergram 版

うちは46製品分の栄養成分表示と含有率を持っている。**在庫としてネタがある側。**

```
これ同じ棚に並んでます。

A：1kg / 3,590円
B：1kg / 3,580円

10円差。

でもタンパク質1gあたりだと、
片方がもう片方の倍近い。

含有率が違うだけです。

どっちが安いほうか分かりますか？
```

🔒 **この型を使うときの制約**

- **N-02**: 「減量食」「体脂肪」の文脈に寄せない。**うちは成分表示の読み方までで、体への働きに進まない**
- **N-03**: 答えを「この商品がいい」にしない。**答えは「読み方」か「数字の構造」にする**
- **優良誤認**: 特定商品を「とんでもない」と持ち上げない。事実の異常さだけを置く
- 🔒 **写真は実物だけ。**成分表示の写真を生成しない。数字の図解が要るなら
  `npm run x:card`（実データからしか作らない）
- 🔒 **数字は `npm run x:facts` から。**クイズだからといって作らない
- **1行目の自問は敬語にしない。**「これ普通に売っていいの？」を敬語にすると指が止まらない
  （`voice.casualQuestion` は最終行の問いと読者を指す問いだけを見る）

⚠️ **サンプルは1本で、対照が取れていない。**同じ書き手の平凡な投稿と比べていないので、
上の10要素のどれが効いたかは**まだ分からない**（生存者バイアス）。
仮説として使い、対照が集まったら検証する。

## 組み方の目安

| 項目 | 目安 |
|---|---|
| 1行の長さ | 20〜25文字（iPhone は 22 前後）。**1行目は必ず1行に収める** |
| 行数 | 9行以内なら全端末で全文。超えるなら境目を意図して置く |
| ブロック | 空行で区切って3つまで |
| 記号 | `・` `↓` `／` でリズムを作る。絵文字は0〜2個 |
| 締め | 問いかけか言い切り（[voice.md](voice.md) の「終わり方」） |

## 🔒 型を使うときに守ること

1. **引きの向こうに実質を置く。** 開いて損した投稿はミュートされる
2. **優劣を断定しない。** 三段は「良い / 悪い」ではなく「分かることの段階」
3. **会話・体験を創作しない。** 数字は `x:facts`、出来事は実際にあったことだけ
4. **同じ型を続けない。** 3回続いたら別の型に変える（`npm run x:feed` で直近を見る）。
   型の繰り返しは内容の繰り返しと同じくらい早く飽きられる
5. **流行の型に寿命がある前提で使う。** ここの型が古びていたら、この文書を書き直す
