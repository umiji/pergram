# ネタ帳（何の話をするか）

## 読み手と、どこまで離れてよいか

読み手の定義と、そこから投稿までの手順は [persona.md](persona.md)。
**この文書はその④で使うネタ帳**であって、ここから読み始めない。

読み手はコスパ重視のトレーニー（P-A 量を飲む人 / P-B 計算する人 / P-C 始めた人）。
立ち上げ期なので、**うちのサービスの話より、業界の話・裏話の方が読まれる。**

サービスから離れてよい。ただし線が1本ある。

> **pergram の視点（数字・単位・比較・出典）が入っていれば、題材は何でもよい。**

- ⭕ プロテインの原料相場がなぜ上がったのか（数字と出典がある）
- ⭕ スーパーの棚に単位価格が出ている理由（制度の話）
- ⭕ 商品データを作る側から見た EC の実情（自分たちの一次体験）
- ❌ 今日の天気・時事ネタへの相乗り（視点が無く、公式アカウントである意味も無い）
- ❌ トレーニングの方法・食べ方の話（🔒 N-02。効能に一歩で届く）

🔒 **外部の数字は一次ソースを確認してから書く。** ブログやまとめ記事の数字を写さない
（財務省貿易統計、メーカーの公式リリース、官公庁・自治体の資料に当たる）。
うちのデータの数字は `npm run x:facts` から。

🔒 **単価の話は3本に1本まで。** 単価はサービスの中心だが、それしか言わないアカウントは
飽きられる。飽きはミュート（-58.8）で返ってきて、いいね100個分を一撃で消す。
`npm run x:feed` が直近の偏りを数で出すので、**まず「まだ話していないトピック」から選ぶ。**

トピックは10カテゴリ。うち価格系は2つだけ（`src/lib/x_feed.js` の `TOPIC_LEXICON`）。
以下は各カテゴリの**具体的な種**で、**出所**の列にあるものからしか数字を引かない。

## 1. 単価の出し方（価格系・使いすぎ注意）

| 種 | 出所 |
|---|---|
| 含有率が高い製品が単価も安いとは限らない | `x:facts` の上位5件 |
| 同じ製品の容量違いで1gあたりがどう変わるか | `x:facts`（内容量と価格が並ぶ） |
| 1食あたりの価格では製品を横断して比べられない理由（1食はメーカーが決めた単位） | requirements.md §4.2 |

## 2. 価格の動き（価格系・使いすぎ注意）

| 種 | 出所 |
|---|---|
| セール前後で単価がどう動いたか | `x:facts` を前後で取って比べる |
| いつ取得した価格なのか（「毎日更新」と書く前に取得日を見る） | `x:facts` の取得日 |

## 3. 表示の読み方 ← **いちばん厚い鉱脈**

商品ページの栄養成分表示は、そのままでは読めない。実際に読み取りで踏んだ罠が
`tests/caption.test.js` に固定してある。**どれも単価の話ではなく「ラベルの読み方」の話**で、
プロテインを買う人全員に当てはまる。

| 種 | 出所 |
|---|---|
| 「1食(30g)あたり／100gあたり」の2列表を1行に潰すと、24gと80gのどちらの基準か分からなくなる | `tests/caption.test.js` |
| 「アミノ酸組成(タンパク質100gあたり)」の100は含有量ではなく**基準**の表示 | 同上 |
| 「ホエイたんぱく質100%」は原材料の表示であって含有率ではない | 同上 |
| 「81.9%（製品無水あたり）」は水分を除いた値。製品そのままの値ではない | 同上 |
| 「たんぱく質 20%OFF」の20を含有率と読むと単価が4倍狂う | 同上 |
| 蛋白質／タンパク質／たん白質の表記ゆれ | 同上 |

🔒 **読み方の説明までにとどめる。**「だからこの製品がよい」に進むと優劣の断定になる。

## 4. 作る側の裏話 ← **立ち上げ期はここが強い**

価格比較を作る側から見た EC の実情。**自分たちの一次体験なので出典に困らない**うえ、
買う側にもそのまま役に立つ。

| 種 | 出所 |
|---|---|
| EC の検索で「プロテイン」を引くと、バー・シェイカー・ドリンク・ゼリー・クッキーが混ざる。除外リストを書いて弾いている | `scripts/collect_rakuten.js` の `EXCLUDE_PATTERNS` |
| **価格の安い順で取ったら、41件すべてが下限価格すぐ上の小容量品だった。**主力の商品帯にはページを重ねても届かない | 同ファイルの `SORT` のコメント（実際に踏んだ） |
| 商品説明文からタンパク質量を自動で読めたのは100件中34件。残りは人が商品ページを見て埋めた | `scripts/enrich_draft.js` の冒頭 |
| 読めなかったものを推測で埋めない。空欄のまま人に回す | CLAUDE.md |
| 同じ商品が別の商品に見える（名寄せ）。JAN が無いと突き合わせられない | requirements.md Q-07 |
| **レビューの星は1件も使っていない。**転載しない方針で、順位にも入れない | CLAUDE.md N-08 |
| 商品名から内容量は読めるが、タンパク質量は読めない | `src/lib/normalize_protein.js` |
| 掲載している製品数と、そのうち価格が取れている数 | `x:facts` |

🔒 「個人開発」「一人で作った」の語りにしない。**作業の中身**を書く。
🔒 特定の EC やメーカーを責める書き方にしない。仕様の説明にとどめる。

## 5. 買い物の実務

| 種 | 出所 |
|---|---|
| 送料込みと送料別で、同じ価格が別の意味になる | `data/price_snapshots.json` の `postage_included` |
| 個人輸入の免税ライン（課税価格1万円 = 海外小売価格 約16,666円） | requirements.md Q-19。**⚠️ 廃止の可能性があるので、書く前に施行状況を確認する** |
| 送料無料ラインと免税ラインの両方に収める買い方 | requirements.md Q-20 |
| 大容量を買ったときの使い切り（開封後の扱い） | 🔒 保存性の効能に踏み込まない。事実だけ |

## 6. 成分の単位

| 種 | 出所 |
|---|---|
| 酸化マグネシウム500mgに含まれる元素マグネシウムは約300mg。ラベルの数字と有効成分量は違う | CLAUDE.md「元素量換算」 |
| mg / mcg / IU の書き分け | 🔒 単位の説明まで。摂取量の推奨をしない |

🔒 このカテゴリは**成分の働きに一歩で届く**ので特に慎重に。書けるのは換算と単位だけ。

## 7. 制度と出典

| 種 | 出所 |
|---|---|
| 成分の働きを書けるのは、栄養機能食品の規格基準にある定型文だけという制度の話 | CLAUDE.md「ホワイトリスト方式」 |
| 「機能性表示食品」は届出制で、届出表示がデータベースで公開されている | 同上 |
| 推奨量・上限量が定められていない成分では「定められていない」と書く | CLAUDE.md |

🔒 **制度の説明までにとどめる。**定型文を引用して「だから効く」に進まない（N-02）。

## 8. サービスの方針

| 種 | 出所 |
|---|---|
| 報酬率を下書きに保存していない。持たなければ「報酬の高い順」を作れない | `tests/collect.test.js` |
| アフィリエイトリンクを使っているが、順位は単価だけで決まる | CLAUDE.md |
| 症状や体調の入力を受け付けない | CLAUDE.md N-01 / N-05 |
| 独自の総合スコアを作らない | CLAUDE.md N-03 |

これは**中立性を宣言する回**になる。多用すると自画自賛に見えるので、月1本まで。

## 9. 製品の種類

| 種 | 出所 |
|---|---|
| WPI / WPC / ソイ / カゼインで単価の帯が違う | `data/product_attributes.json` と `x:facts` |
| ブレンド品は種類を判定できないので分類していない | `src/lib/normalize_protein.js` |
| フレーバー違いで価格が変わることがある | `data/products.json` |

🔒 種類の優劣を書かない（「WPIの方がよい」は書けない）。単価の帯の違いは事実。

## 11. 市場と相場 ← **筋トレ勢がいちばん反応する**

「なぜプロテインが高くなったのか」は、買っている本人が理由を知らないまま払っている話。
⚠️ **数字は必ず一次ソースで確認してから書く。**下は二次情報で見かけた論点の見出しで、
そのまま書いてよい数字ではない。

| 論点 | 一次ソースの当たり先 |
|---|---|
| ホエイパウダーの輸入単価が数年で数倍になった | 財務省 貿易統計（品目別の輸入額 ÷ 数量） |
| 国内メーカーが価格改定を公表している（改定率つき） | 各社の公式リリース・お知らせ |
| GLP-1 系の薬が広まって、たんぱく質の需要そのものが増えた | 一次の統計か、メーカーの公式見解 |
| 円安・物流費・関税が上乗せされている | 為替の公表値・各社リリース |

🔒 **値上げを煽らない。**「今が買い時」「もっと上がる」は予想であって事実ではない。
書けるのは「いつ・いくらだったか」と「メーカーが何と言っているか」まで。

## 12. 単価という考え方 ← **pergram の存在理由そのもの**

**スーパーの棚には単位価格（ユニットプライス）が出ているのに、ネット通販には無い。**
この非対称が、そのままサービスの理由になる。制度なので一次ソースが公開されている。

| 種 | 一次ソースの当たり先 |
|---|---|
| 自治体の消費者保護条例が、一定規模以上の店舗に単位価格表示を義務づけている（対象品目・売場面積は自治体ごとに違う） | 大阪市・京都市・東京都などの条例と解説ページ |
| 単位価格表示の国際規格 ISO 21041 がある | 日本規格協会 |
| 「ステルス値上げ」は単位価格を見れば分かる | 自治体の消費者向け解説 |
| 他ジャンルの単位あたり価格（コーヒー豆の100gあたり、洗剤の10mlあたり）と同じ見方 | 棚の表示そのもの |

🔒 制度の紹介にとどめ、「だから pergram を使え」に直結させない。事実を置けば十分。

## 🔒 ここにあるのは材料であって、投稿ではない

各行は「起きたこと」で、そのまま書くと**「で、それが何?」**という投稿になる。
必ず**読み手の持ち帰り**に変換してから書く（SKILL.md の手順6）。

```
材料: ECの検索にプロテインバーが混ざる
❌   「除外する語を書き並べる作業から始まりました」  ← 作業報告。読み手に何も残らない
⭕   「ECの『安い順』は最安を教えてくれない」        ← 明日の買い物が変わる
```

変換できない材料は、まだ投稿にする時期ではない。捨てて別のを選ぶ。

## 選び方

1. `npm run x:feed` の「まだ話していないトピック」から選ぶ
2. 直近2本と**同じカテゴリを選ばない**
3. 価格系（1・2）は3本に1本まで
4. カテゴリを決めてから、[formats.md](formats.md) で**型**を決める。
   トピックが変わっても型が同じだと、結局同じ投稿に見える
