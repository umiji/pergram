# ネタ帳（何の話をするか）

## この文書の立ち位置

読み手の定義と、そこから投稿までの手順は [persona.md](persona.md)。
**この文書はその④で使う地図**であって、ここから読み始めない。

初版は13項目すべてが価格の言い換えで、どれを選んでも単価の話になった。
次の版は12項目に広げたが、半分が「うちのデータ」「うちの作業」の話だったため、
**どれを選んでも最後はサービスの紹介に着地した**。読み手からはそれが宣伝に見える。

いまの版は**族（family）を5つに分け、価格系と自社系に上限を置いてある。**
上限は文章ではなく `npm run x:feed` が数で出す。

## 🔒 配分（ここが守れないと、何を足しても同じ投稿になる）

| 何 | 上限 | 数える人 |
|---|---|---|
| 価格の話（単価の出し方 / 価格の動き） | **3本に1本** | `x:feed` の「価格の話」 |
| うちの話（族Ⅴ） | **5本に1本** | `x:feed` の「うちの話」 |
| URL を貼る投稿（＝告知） | **10本に1本** | `x:feed` の「URL を貼った投稿」 |
| 同じ族 | **2本続けない** | `x:feed` の「族ごとの本数」 |

🔒 **サービスの告知は毎回しない。**既定は「告知しない」。
残りの9本は、読んで終わってよい。**すべての投稿の着地点が自分たちの紹介になっている
アカウントは、読み手からはステルスマーケティングに見える。**

サービスから離れてよい。線は1本だけ。

> **pergram の視点（数字・単位・比較・出典）が入っていれば、題材は何でもよい。**

- ⭕ ホエイがチーズの副産物であること（事実。数字と出所がある）
- ⭕ スーパーの棚に単位価格が出ている理由（制度）
- ⭕ 円安と乳価が値段のどこに乗っているか（一次統計）
- ❌ 今日の天気・時事への相乗り（視点が無く、公式アカウントである意味も無い）
- ❌ トレーニングの方法・食べ方（🔒 N-02。効能に一歩で届く）

🔒 **外部の数字は一次ソースを確認してから書く。**まとめ記事の数字を写さない
（財務省貿易統計、農水省、メーカーの公式リリース、官公庁・自治体の資料に当たる）。
うちのデータの数字は `npm run x:facts` から。

## Ⅰ 読み手が実際に読んでいるもの（先に全部出す）

**うちが話せることから考えない。**トレーニー・サプリを買う人が X で足を止めるものを
先に全部並べ、そのあとで扱えるかを判定する。⭕ の列が持ち場で、❌ にも
**隣接する扱える問い**がある。ここを飛ばすと、また単価の話に戻る。

| 読み手が読みたいもの | 扱えるか | ずらした先（実際に書く形） |
|---|---|---|
| セールが安いのか本当のところ | ⭕ | セールの仕組み（ポイント還元・買い回りの実質） |
| また値上げした、なぜ高い | ⭕ | 相場と値上げ（貿易統計・価格改定リリース） |
| 新製品・終売・リニューアル | ⭕ | 業界の動き（公表された事実まで） |
| WPI と WPC は何が違う | ⭕ | 製品の種類と製法（**製法の違いまで。優劣と体への働きは書かない**） |
| このプロテインは何でできている | ⭕ | 原料と生産（チーズの副産物、乳清、生産国） |
| 海外のほうが安いのか | ⭕ | 海外事情（為替・関税・送料込みの単価） |
| 買って失敗した / 損した | ⭕ | 失敗談・買い方の実務 |
| ラベルの見方が分からない | ⭕ | 表示の読み方（**いちばん厚い鉱脈**） |
| 「◯%が実感」みたいな広告は本当か | ⭕ | 数字の読み方（母数・n・出典の見方） |
| ダマになる / 溶けない / 湿気る | ⭕ | 保管と扱い（**物理の話まで。体への影響は書かない**） |
| ドラッグストアとネットどっちが安い | ⭕ | 買う場所 |
| 業界の裏側・作り手の話 | ⭕（族Ⅴ・上限あり） | 作る側の裏話 |
| **どれがおすすめ** | ❌ N-03 | 何を見れば自分で選べるか（表示の読み方） |
| **効果・筋肥大・回復** | ❌ N-02 | 含有量と単価の事実だけ |
| **飲むタイミング・飲み方** | ❌ N-02 | 使い切り・保管という物理の話 |
| **味・美味しさのレビュー** | ❌ 主観 | フレーバーで価格が変わるという事実 |
| **トレーニングのやり方** | ❌ N-02 に一歩 | 扱わない |
| **論文・研究の紹介** | ❌ N-02 | 扱わない（成分の働きの断定になる） |
| **育毛・妊活・美容** | ❌ N-09 / N-10 | 扱わない |

## Ⅱ ジャンル地図（22ジャンル・5族）

族の名前とジャンル名は `src/lib/x_feed.js` の `TOPIC_FAMILIES` / `TOPIC_LEXICON` と
**同じ綴りで揃えてある**（`x:feed` の出力から、この見出しを直接引ける）。

### 族① お金の話 — 財布に直接効く。ただし価格系は3本に1本

#### 1. 単価の出し方 🔒価格系

| 種 | 出所 |
|---|---|
| 含有率が高い製品が単価も安いとは限らない | `x:facts` の上位5件 |
| 同じ製品の容量違いで1gあたりがどう変わるか | `x:facts`（内容量と価格が並ぶ） |
| 1食あたりの価格では製品を横断して比べられない（1食はメーカーが決めた単位） | requirements.md §4.2 |

#### 2. 価格の動き 🔒価格系

| 種 | 出所 |
|---|---|
| セール前後で単価がどう動いたか | `x:facts` を前後で取って比べる |
| いつ取得した価格なのか（「毎日更新」と書く前に取得日を見る） | `x:facts` の取得日 |

#### 3. 相場と値上げ ← **筋トレ勢がいちばん反応する**

「なぜ高くなったのか」は、買っている本人が理由を知らないまま払っている話。
⚠️ 下は**論点の見出し**であって、そのまま書いてよい数字ではない。

| 論点 | 一次ソースの当たり先 |
|---|---|
| ホエイパウダーの輸入単価が数年でどう動いたか | 財務省 貿易統計（品目別の輸入額 ÷ 数量） |
| 国内メーカーが価格改定を公表している（改定率つき） | 各社の公式リリース |
| 生乳・乳価の推移が原料価格のどこに乗るか | 農林水産省の統計 |
| 円安・物流費・関税の上乗せ | 為替の公表値・各社リリース |
| たんぱく質の需要そのものが増えている | 一次の統計かメーカーの公式見解 |

🔒 **値上げを煽らない。**「今が買い時」「もっと上がる」は予想であって事実ではない。
書けるのは「いつ・いくらだったか」と「メーカーが何と言っているか」まで。

#### 4. セールの仕組み ← **読み手が本当に知りたいのはここ**

| 種 | 出所 |
|---|---|
| ポイント還元は値引きと同じではない（付与上限・期間限定・失効） | 各 EC の規約ページ |
| 買い回りは「1店舗あたりいくら買うか」で実質が変わる | 各 EC のキャンペーン規約 |
| 送料無料ラインに乗せるための買い足しが、単価を上げることがある | `x:facts` の送料区分 |
| 定期購入の初回価格と2回目以降の差 | 各商品ページの表示 |

🔒 還元率を単価に足し引きして「実質最安」と断定しない。条件が人によって違う。

#### 5. 買い方の実務

| 種 | 出所 |
|---|---|
| 送料込みと送料別で、同じ価格が別の意味になる | `data/price_snapshots.json` の `postage_included` |
| 個人輸入の免税ライン（課税価格1万円 = 海外小売価格 約16,666円） | requirements.md Q-19。⚠️ **廃止の可能性。施行状況を確認してから書く** |
| 送料無料ラインと免税ラインの両方に収める買い方 | requirements.md Q-20 |
| 大容量の使い切り・小分け・賞味期限の表示の意味 | 🔒 保存性の効能に踏み込まない。事実だけ |

### 族② 読み方 — ラベルと数字のリテラシー。買う人全員に当てはまる

#### 6. 表示の読み方 ← **いちばん厚い鉱脈**

商品ページの栄養成分表示は、そのままでは読めない。実際に読み取りで踏んだ罠が
`tests/caption.test.js` に固定してある。**どれも単価の話ではない。**

| 種 | 出所 |
|---|---|
| 「1食(30g)あたり／100gあたり」の2列表を1行に潰すと、24gと80gのどちらの基準か分からなくなる | `tests/caption.test.js` |
| 「アミノ酸組成(タンパク質100gあたり)」の100は含有量ではなく**基準**の表示 | 同上 |
| 「ホエイたんぱく質100%」は原材料の表示であって含有率ではない | 同上 |
| 「81.9%（製品無水あたり）」は水分を除いた値。製品そのままの値ではない | 同上 |
| 「たんぱく質 20%OFF」の20を含有率と読むと単価が4倍狂う | 同上 |
| 蛋白質／タンパク質／たん白質の表記ゆれ | 同上 |

🔒 **読み方の説明までにとどめる。**「だからこの製品がよい」に進むと優劣の断定になる。

#### 7. 単位と換算

| 種 | 出所 |
|---|---|
| 酸化マグネシウム500mgに含まれる元素マグネシウムは約300mg。ラベルの数字と有効成分量は違う | CLAUDE.md「元素量換算」 |
| mg / mcg / μg / IU の書き分け | 🔒 単位の説明まで。摂取量の推奨をしない |
| 海外製品のポンド表記（1 lb = 453.6 g）。2.2lb と 1kg は同じではない | 単位の定義 |
| 付属スクープの容量は製品ごとに違う。「スクープ1杯」は単位にならない | 各商品ページの表示 |

🔒 この族は**成分の働きに一歩で届く**ので特に慎重に。書けるのは換算と単位だけ。

#### 8. 数字の読み方 ← **サプリ広告の読み解きそのもの**

| 種 | 出所 |
|---|---|
| 「◯%が実感」の母数（n）がどこに書いてあるか。書いていないこともある | 各広告の表示 |
| 平均と中央値で印象が変わる | 統計の定義 |
| 「当社比」「一部の商品を除く」の但し書きが打ち消し表示に当たる場面 | 消費者庁の打ち消し表示の考え方 |

🔒 **特定の広告を名指しで批判しない。**読み方の説明にとどめる。

#### 9. 単位価格という考え方 ← **pergram の存在理由そのもの**

**スーパーの棚には単位価格が出ているのに、ネット通販には無い。**
この非対称が、そのままサービスの理由になる。制度なので一次ソースが公開されている。

| 種 | 一次ソースの当たり先 |
|---|---|
| 自治体の消費者保護条例が、一定規模以上の店舗に単位価格表示を義務づけている（対象品目・売場面積は自治体ごとに違う） | 大阪市・京都市・東京都などの条例と解説 |
| 単位価格表示の国際規格 ISO 21041 がある | 日本規格協会 |
| 「ステルス値上げ」は単位価格を見れば分かる | 自治体の消費者向け解説 |
| 他ジャンルの単位あたり価格（コーヒー豆の100gあたり、洗剤の10mlあたり）と同じ見方 | 棚の表示そのもの |

🔒 制度の紹介にとどめ、「だから pergram を使え」に直結させない。事実を置けば十分。

### 族③ 業界と製品 — 買っている本人が理由を知らないまま払っている話

#### 10. 製品の種類と製法

| 種 | 出所 |
|---|---|
| WPC / WPI / WPH は精製の工程が違う（膜処理・イオン交換・加水分解） | メーカーの製法説明 |
| ソイ・カゼイン・ピープロテインは原料が違う | 同上 |
| 種類ごとに単価の帯が違う | `data/product_attributes.json` と `x:facts` |
| ブレンド品は種類を判定できないので分類していない | `src/lib/normalize_protein.js` |
| フレーバー違いで価格が変わることがある | `data/products.json` |

🔒 **工程と組成の説明まで。**「WPIの方がよい」「吸収が」は書けない（N-02 / 優劣の断定）。

#### 11. 原料と生産

| 種 | 出所 |
|---|---|
| ホエイ（乳清）はチーズを作るときに出るもの。主産物ではない | 乳業各社・農水省の解説 |
| 生産国とメーカーが一致しない（OEM・充填だけ国内、等） | 商品ページの原産国表示 |
| ロットによって成分表示の値が変わることがある | 商品ページの改定履歴 |

#### 12. 歴史

| 種 | 出所 |
|---|---|
| プロテインパウダーが一般の店頭に並ぶまでの経緯 | メーカー社史・業界団体の資料 |
| 昔は何を単位にして売られていたか | 当時のカタログ・公表資料 |

🔒 一次資料が取れない逸話は書かない。「らしい」で書き始めたら捨てる。

#### 13. 業界の動き

| 種 | 出所 |
|---|---|
| 新製品・リニューアル・終売の公表 | 各社リリース |
| 内容量やフレーバーの改定（価格据え置きで容量が変わる） | 商品ページ・リリース |
| 自主回収の公表 | 各社リリース・消費者庁のリコール情報 |

🔒 **個社を責める書き方にしない。**公表された事実の紹介にとどめ、是非を論じない。

#### 14. 規制と表示制度

| 種 | 出所 |
|---|---|
| 成分の働きを書けるのは、栄養機能食品の規格基準にある定型文だけ | CLAUDE.md「ホワイトリスト方式」 |
| 「機能性表示食品」は届出制で、届出表示がデータベースで公開されている | 消費者庁の届出データベース |
| 推奨量・上限量が定められていない成分では「定められていない」と書く | 食事摂取基準(2025年版) |
| 食品表示法が栄養成分表示に求めている項目と順序 | 消費者庁の食品表示基準 |

🔒 **制度の説明までにとどめる。**定型文を引用して「だから効く」に進まない（N-02）。

#### 15. 海外事情

| 種 | 出所 |
|---|---|
| 同じ製品の国内価格と海外小売価格（為替・送料・関税を入れて単価で並べる） | `x:facts` と公表レート |
| 表示のルールが国で違う（1食あたりの定義、義務表示の項目） | 各国の表示規則 |
| 海外通販の送料・関税で、安く見えたものが逆転する | requirements.md Q-18 / Q-19 |

## 🔒 ここにあるのは材料であって、投稿ではない

各行は「起きたこと」で、そのまま書くと**「で、それが何?」**という投稿になる。
必ず**読み手の持ち帰り**に変換してから書く（SKILL.md の手順6）。

```
材料: ECの検索にプロテインバーが混ざる
❌   「除外する語を書き並べる作業から始まりました」  ← 作業報告。読み手に何も残らない
❌   「だから pergram を作りました」                ← 宣伝。持ち帰りではない
⭕   「ECの『安い順』は最安を教えてくれない」        ← 明日の買い物が変わる
```

変換できない材料は、まだ投稿にする時期ではない。捨てて別のを選ぶ。

## 選び方（印象で決めない）

```bash
npm run x:feed
```

出力の **「次の1本の候補」** が、下の4つをすでに適用した結果になっている。

1. 直近2本と同じ族を外す
2. 価格系が3本に1本を超えていたら価格系を外す
3. うちの話が5本に1本を超えていたら族⑤を外す
4. 残りを「話していない順 → 族が薄い順」に並べる

候補の上から1つ選び、**この文書の同じ見出しから種を取る**。
候補を無視して別のジャンルにするなら、その理由を1行で言えるときだけにする。

最後に [formats.md](formats.md) で**型**を決める。
トピックが変わっても型が同じだと、結局同じ投稿に見える。
