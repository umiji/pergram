# サービス仕様（投稿に書いてよいこと）

出所は [docs/product/requirements.md](../../../../docs/product/requirements.md) と
[CLAUDE.md](../../../../CLAUDE.md)。**数字はこの文書ではなく `npm run x:facts` が出す。**
ここに書くのは「変わらない仕様」だけで、件数・単価・更新日は毎回取り直す。

## pergram とは

- サプリメント・プロテインを **有効成分1単位あたりの価格** で並べ替える静的サイト
- いま扱っているのは **タンパク質（プロテイン）** の1成分のみ
- 並び順を決めるのは **タンパク質1gあたりの価格だけ**。品質評価も編集部の推しも無い
- 登録不要・無料。β版
- 表示言語は日本語（`/ja/`）と英語（`/en/`）。掲載製品や免責は市場（JP / US）で変わる

## 言えること（事実）

| 言えること | 補足 |
|---|---|
| 袋の価格ではなく、含有率で割った実質のタンパク質量で単価を出している | 1kg・含有率75% なら タンパク質750g |
| 並び順は単価の昇順だけで決まる | 報酬額・ブランド・在庫は順位に影響しない |
| 含有率はメーカーが公表する栄養成分表示の値 | 推定値で埋めていない。読めない製品は載せない |
| 価格は各 EC から取り直している | 取得日は `x:facts` が出す。「毎日更新」と書く前に取得日を見る |
| アフィリエイトリンクを含む | 順位には影響しない。この2つは必ずセットで書く |
| 登録不要・無料で使える | 待機リストは任意 |

## 言えないこと 🔒

- **成分の働き・効能・体感**（N-02）。「タンパク質は筋肉に必要」も書かない
- **おすすめ・ランキング的な優劣**（N-03）。「1位」と言えるのは単価の順位としてだけ
- **全EC対応**。β版では楽天以外の価格欄は表示例（`x:facts` が現状を出す）
- **検索で見つかる**。製品一覧は robots.txt で塞いでいる期間がある（`x:facts` が出す）
- **他社サービスの優劣**。比較対象を貶さない

## URL

🔒 **サイトの URL をこの文書に書かない。**唯一の出所は
[src/lib/site.js](../../../../src/lib/site.js) の `SITE_ORIGIN` で、
`npm run x:facts` がそこから組み立てて出す。投稿にはその出力を貼る。

| ページ | 用途 |
|---|---|
| `/ja/` | LP（トップ）。サービス紹介のツリーはここへ送る |
| `/ja/protein/` | 製品一覧。「一覧を見る」「ランキングを見る」はここへ送る |

## 数字を書くときの型

- 必ず単位と基準を添える: ❌「¥9.9」→ ⭕「¥9.9 / タンパク質1g」
- 含有率は「含有率 75%」。「タンパク質75g」と混ぜない
- 製品名を出すときは `x:facts` の表記をそのまま使う（EC の商品名は長い。切るなら … を付ける）
- 最安を言うときは母集団を添える（「掲載46製品の中で」）。母集団の無い「最安」は書かない
