# アイキャッチ（16:9）

出所は [docs/Marketing/X_eyecatch_image_method.md](../../../../docs/Marketing/X_eyecatch_image_method.md)。
⚠️ あの文書は画像生成モデル（ImageFX）向けのプロンプト集だが、**実装は生成モデルを使わない**。

## なぜ生成モデルを使わないか

- 生成モデルは**数字を作る**。「¥9.9/g」と書かれた画像の 9.9 が実データと違えば、
  それは pergram が言った嘘になる（🔒 N-03・景表法）
- 生成モデルは**色と字を揃えられない**。画面と別の色・別の書体になり、同じサービスに見えない
- ネオン・3D・葉・カプセル・人物といった **使ってはいけないビジュアル**（CLAUDE.md）に寄る

代わりに、実際の画面と同じトークン（`src/styles/tokens.css`）と同じ実データから
SVG を組み立てる。**画像に出る数字は必ず `data/` にある数字**になる。

## 作り方

```bash
# ランキング型（実データの上位3件）
npm run x:card -- --type rank --headline "袋の値段では、順位は出ない。" --png

# 1商品フォーカス型（真実暴露）
npm run x:card -- --type focus --headline "3kgで安い、は本当か。" --rank 1 --png

# 二分割対比型（Before / After）
npm run x:card -- --type split --headline "見る場所を1つ変えるだけ" \
  --left "袋の価格で選ぶ" --right "タンパク質1gあたりの価格で選ぶ" --png

# 3ステップ図解型（Tips）
npm run x:card -- --type steps --headline "プロテインの単価の出し方" \
  --steps "袋の値段を見ない|含有率を見る|1gあたりで比べる" --png
```

出力は `dist/assets/x_card_<type>.svg` と同名の `.html`（`--out` で変えられる）。
`--png` を付けると rsvg-convert / ImageMagick / Chrome のうち見つかったもので
PNG にする。**X は SVG を受け付けない。**変換器が1つも無ければ `.html` を
ブラウザで開いて 1600×900 で撮る。

## 構図の選び方（投稿文のフックから決める）

| 投稿のフックが | 構図 | 型 |
|---|---|---|
| 検証・ランキング・「どれが安い？」 | 実データの上位3行 | `rank` |
| 真実暴露・「大容量＝安いとは限らない」 | 1商品のカード | `focus` |
| 手間の解消・「これまで vs これから」 | 左右の対比 | `split` |
| 選び方・Tips・手順 | 3ステップの図解 | `steps` |

## 🔒 決まりごと

- **`rank` / `focus` は実データが無ければ作らない**（スクリプトが落ちる）。
  ダミーの順位を SNS に流さない
- 見出しの文言も投稿文と同じ禁止語チェックを通る。引っかかると画像を作らずに落ちる
- 何の順に並んでいるかを画像の中に必ず書く（既定で「タンパク質1gあたりの価格が安い順」）。
  `--sub` で変えられるが、基準そのものを消さない
- 色は `tokens.css` から読む。**スクリプトにもここにも16進数を書かない**
- 画像を添えたら、投稿文の中でも同じ数字を使う。画像と本文で数字がずれない
