# 型｜Build in Public

**向ける読み手**: `builder`（主）

**狙い**: 個人開発・エンジニア界隈から観客を借りる。筋トレ層とは別の観客。
**未完成であることを隠さない**のがこの型の核。

## 組み立て

1. 作った動機を具体的な面倒として書く
2. 機能または詰まった点を3点まで。箇条書き
3. 入っていないものを正直に書き、リプで募集する

## 言ってよいこと

- 46製品しか入っていない / 楽天のみ / 商品名が生データのまま
- 登録不要
- 「この製品も入れてほしい」の募集

## やらないこと 🔒

- 網羅を示す語
- 完成しているかのような書き方
- 数字が1つも入らない苦労話
