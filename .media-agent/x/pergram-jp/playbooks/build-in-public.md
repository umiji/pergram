# 型D｜Build in Public

**狙い**: 個人開発・エンジニア界隈からの拡散。筋トレ層とは別の観客を借りる。
**未完成であることを隠さない**のがこの型の核。46製品しかないことを弱点ではなく募集の理由にする。

## 組み立て

1. **1〜2行目**: 作った動機を具体的な面倒として書く（「セールのたびに電卓を叩くのが面倒で」）
2. **中盤**: 機能を3点まで。箇条書き
3. **最後**: 入っていないものを正直に書き、リプで募集する

## 言ってよいこと

- 登録不要
- 46製品しか入っていない（件数を隠さない）
- 「この製品も入れてほしい」の募集

## やらないこと

- 網羅を示す語（全メーカー / 全比較 / すべての）
- 完成しているかのような書き方
- 開発の苦労話だけで数字が1つも入らない投稿

## 例

```
セールのたびに「結局タンパク質1gあたりいくらだ」と電卓を叩くのが面倒で、
楽天の製品を集めて単価を自動計算するサイトを作りました。

・タンパク質1gあたりの単価で並べ替え
・WPC / WPI / ソイ の種別で絞り込み
・登録不要

まだ46製品しか入っていません。「この製品も入れてほしい」があればリプで教えてください。
```
