# 型｜種別を揃えた単価の開き

**向ける読み手**: `price-shock`（主）/ `sale-hunter`

**狙い**: 種別を揃えたうえで単価の幅を見せる。**種別を揃えているので「別物を並べている」と
反論されない。** 単価の話はこの1本に集約する（4本に分けていた頃は、同じ話題を言い換えていた）。

## 組み立て

1. 読み手が実際に言っていること、または迷っていることから入る
2. 種別・件数・取得元・単価のレンジをこの順で出す
3. 内容量でも税込価格でもなく1gあたりで並べるとこうなる、で閉じる
4. 取得日は1行目か本文中に溶かす。**末尾に括弧で足さない**（続きがあるように読める）

## 使う数字（投稿前に必ず再計算する）

- WPC 11製品 ¥4.88〜¥11.65（中央値 ¥5.89）
- WPI 9製品 ¥6.86〜¥10.53（中央値 ¥8.25）
- ソイ 22製品 ¥1.92〜¥34.55（中央値 ¥6.71）
- **同じソイの中で18倍**（¥1.92 → ¥34.55）。種別を揃えているので出してよい

## やらないこと 🔒

- 種別を混ぜて「18倍」とだけ出す（ソイとホエイは別物として扱われる）
- 製品名・ブランド名を出して割高だと評する
- 網羅を示す語（全メーカー / 全比較 / すべての）
- 単価の低さを製品の良さとして語る。**比較軸であって、買い手の目的とは別である**
