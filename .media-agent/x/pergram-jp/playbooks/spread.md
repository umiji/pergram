# 型A｜同じ種別の中の開き

**狙い**: 種別を揃えたうえで単価の幅を見せる。種別を揃えているので「別物を並べている」と反論されない。
4つの型の中で最も安全に伸ばせる。迷ったらこれを使う。

## 組み立て

1. **1行目**: 自分も勘違いしていた、という立ち位置から入る。断定で始めない
2. **2〜3行目**: 種別・件数・取得元・単価のレンジ・倍率をこの順で出す
3. **最後**: 「内容量でも税込価格でもなく、1gあたりで並べ直すとこうなる」で締める
4. 取得日を必ず添える

## 使う数字（投稿前に必ず再計算する）

- WPC 11製品 ¥4.88〜¥11.65 / 2.4倍 ← **この型の本命**
- WPI 9製品 ¥6.86〜¥10.53 / 1.5倍
- ソイ 22製品 ¥1.92〜¥34.55 / 18.0倍

## やらないこと

- 種別を混ぜて「18倍」とだけ出す（ソイとホエイは別物として扱われる）
- 特定の製品名を出して割高だと評する
- 網羅を示す語（全メーカー / 全比較 / すべての）

## 例

```
「WPCなら似たようなもの」と思って選んでいたんですが、
楽天で取れた WPC 11製品をタンパク質1gあたりの単価に直したら
¥4.88 〜 ¥11.65 でした。同じ WPC で 2.4倍の開きです。

内容量でも税込価格でもなく、
「タンパク質1gあたりいくらか」で並べ直すとこうなります。
（2026-09-02 時点・楽天で取得した46製品）
```
