# 型｜「おすすめ順」は何で決まっているのか

**向ける読み手**: `price-shock`（主）/ `builder`

**狙い**: pergram の存在理由そのもの。**実測で最も伸びた投稿（17imp）がこの型。**

## 組み立て

1. 「おすすめ10選」の順位が何で決まっているかを問いに置く
2. pergram 側の答え（並べているのはたんぱく質1gあたりの単価だけ。報酬額を順位に入れない）
3. **自分の限界も同時に出す**（46製品・楽天のみ）

## 使う数字（投稿前に必ず再計算する）

- 46製品・楽天で取得・取得日
- 報酬率は下書きにも保存していない（持っていないので「報酬の高い順」を作れない）

## やらないこと 🔒

- 他社サイト・他社メディアを名指しで批判する
- 網羅を示す語（全メーカー / 全比較 / すべての）。**自分の限界を隠すとこの型は自壊する**
- 「うちは中立です」とだけ言って数字が無い投稿
