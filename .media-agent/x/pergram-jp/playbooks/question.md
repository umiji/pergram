# 型C｜問いかけ

**狙い**: リプライを発生させる。会話が起きるとアルゴリズム評価が上がり、表示が伸びる。
数字は前置きで、**本体は最後の問い**。

## 組み立て

1. **1〜2行目**: 数字を短く置く（件数と取得元を添える）
2. **3〜4行目**: 自分が答えを持っていない論点を正直に書く。ここが問いの土台になる
3. **最後**: 二択で聞く。「どう思いますか」ではなく「AとBのどちらを優先しますか」

## 使える論点

- 種別（ソイ/WPC/WPI）と単価、どちらを優先するか
- 大容量で単価を下げるか、飲みきれる量にするか
- フレーバーの好みと単価、どちらを取るか

## やらないこと

- 特定製品への投票を募る（優劣の評価になる）
- 症状・目的・体調を聞く（悩みの入力を受け付けない）
- 答えを誘導する書き方（「やっぱりAですよね？」）

## 例

```
タンパク質1gあたりの単価で並べると、
いま手元のデータでは ¥1.92 〜 ¥34.55 まで開きます（46製品・楽天）。

種別で分けるとソイが一番安く出るんですが、
ホエイから乗り換えてまで単価を取りにいくかは別の話だと思っていて。
みなさんは種別と単価、どちらを優先していますか。
```
