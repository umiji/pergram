# 型｜豆知識（製法・原料・作られ方）

**向ける読み手**: 全員（セグメントを絞らない唯一の型）

**狙い**: 単価の話をしない日を作る。**実測で2番目に伸びた投稿（16imp「チョコ味は香料の
組み合わせで作る」）がこの型。** 毎日同じ話題のアカウントはフォローされない。

## 組み立て

1. 誰もが見たことがあるものの、裏側を1つ
2. **数字を必ず1つ入れる**（数字の無い投稿は作らない）
3. 短く終わる。教訓をつけない

## 扱ってよいこと

- 製法の違い（WPC と WPI がどう作り分けられるか）
- 原料・味の作られ方
- 溶けやすさ・粉の粒度など、物性の話
- 表示ルールそのものの話

## やらないこと 🔒

- **体にどう作用するかを書く。** これを外すと N-02 に落ちる。この型で最も踏みやすい地雷
- 出典の無い豆知識。**思いついたことを書かない。** 一次情報を確認してから書く
- 特定ブランドの製法を名指しで論評する
