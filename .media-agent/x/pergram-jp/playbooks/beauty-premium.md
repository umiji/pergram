# 型｜「女性向け」と書かれた製品の単価が高く出る理由

**向ける読み手**: `beauty-first`（主）/ `price-shock`

**狙い**: 伸びているセグメントに、**判定ではなく選ぶ基準**を渡す。
この型は「安い方がいい」と言うためのものではない。**言ったら失敗である。**

## 組み立て

1. 事実を出す（「女性向け」と名前に入っている製品は、たんぱく質1gあたりの単価が高く出る）
2. **理由を必ず添える**（たんぱく質の割合が低いから。残りには別の栄養素が入っている）
3. **選ぶ基準を2つ並べて終わる** — 「たんぱく質だけが欲しいのか、それ以外も込みで欲しいのか」
4. どちらが正しいとは書かない

## やらないこと 🔒

- **ブランドを名指しする。** 「"女性向け"と名前に入っている製品」というカテゴリ単位で書く
  （`rules.md`「特定ブランドの優劣を述べる」）
- **「割高」「損している」と評する。** この層は他の栄養素に払っている
- **効能に触れる**（美容にいい/よくない）。N-02
- 美容医療・妊活の文脈へ寄せる。N-10
- 残りの67%が何かを推測して書く。**pergram は持っていない**
