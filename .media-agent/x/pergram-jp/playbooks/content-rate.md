# 型B｜含有率

**狙い**: 「1kg 買ってもタンパク質は 1kg ではない」という一次情報。
単価そのものより気づきが強く、保存されやすい。

## 組み立て

1. **1行目**: 事実を短く言い切る（「プロテイン1kgを買っても、中身のタンパク質は1kgではありません」）
2. **2行目**: 手元のデータの含有率の幅を出す（件数を添える）
3. **3行目**: 含有率の差が単価に何倍で効くかへ接続する
4. 具体的な製品名は出さない。幅だけを出す

## 使う数字（投稿前に必ず再計算する）

- 46製品の1食あたり含有率は 60% 〜 90%
- 含有率60%と90%では、同じ内容量・同じ価格でも1gあたり単価が1.5倍変わる

## やらないこと

- 含有率が低い製品を名指しして貶す（単価と含有量を並べるのは可、優劣を述べるのは不可）
- タンパク質の働きや必要性を自分の言葉で説明する（成分の機能に触れる独自文章は書かない）

## 例

```
プロテイン1kgを買っても、中身のタンパク質は1kgではありません。
手元の46製品だと、1食あたりの含有率は 60% 〜 90% の幅があります。

含有率60%の製品と90%の製品では、
同じ「1kg・同じ価格」でもタンパク質1gあたりの単価が1.5倍変わります。
```
