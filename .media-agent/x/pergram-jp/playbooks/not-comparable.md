# 型｜「1食」に共通の定義がない

**向ける読み手**: `price-shock`（主）/ `sale-hunter`

**狙い**: 「1食あたりたんぱく質20g」同士を並べても比較にならない、という**比較の落とし穴**。
「おすすめ記事の順位が信用できない」という話の、動かぬ根拠になる。

## 組み立て

1. 「1食あたり◯g」を見比べたことがある、という前提から入る
2. 46製品で1食の粉量が **13g〜100g、12通り**にばらけている事実を出す
3. だから「1食あたり」は製品をまたぐと比べられない、で閉じる

## 使う数字（投稿前に必ず再計算する）

- 1食の粉量: **13g 〜 100g、12通り**（46製品）

## やらないこと 🔒

- メーカーが恣意的にごまかしている、という書き方。**定義が無いだけで、不正ではない**
- 製品名・ブランド名を出す
