# 型｜中身の量（重量で見せる）

**向ける読み手**: `price-shock`（主）/ `sale-hunter`

**狙い**: 「1kg」という表示が、たんぱく質1kgを意味しないという**ラベルの読み方**を渡す。
単価より気づきが強く、保存されやすい。

## 組み立て

1. 事実を短く言い切る（「1kgって書いてあっても、たんぱく質が1kgあるわけじゃない」）
2. **重量で出す。率で書かない** — 「含有率33%」は読み流されるが「1kg中330g」は残る
3. 買うときにどこを見ればいいかで閉じる
4. 取得日を1行目か本文中に溶かす。末尾に括弧で足さない

## 使う数字（投稿前に必ず再計算する）

- 46製品で、1kgあたりのたんぱく質は **330g 〜 936g**（約2.8倍）
- 最少は1食15g中4.95g、最多は1食100g中93.6g

## やらないこと 🔒

- **少ない方を劣ると書く。** 残りに何が入っているかを pergram は持っていない（`nutrient_contents` は
  protein のみ）。知らないものを暗黙に劣ると決めつけるのは独自の品質スコアであり N-03 に触れる
- 「水増し」「スカスカ」「損してる」といった語
- 製品名・ブランド名を出す
