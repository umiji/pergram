# 読み手｜個人開発・エンジニア界隈

筋トレ層とは別の観客。**プロダクトの作り方と着眼点に反応する。**
拡散力が高く、フォローに繋がりやすいが、そのままでは購買層ではない。

## この人の状況

- 「何を作ったか」より「なぜそれを作ったか」を見ている
- 未完成であることに寛容。むしろ途中経過を好む
- データの出所と計算方法を気にする

## 効くもの

- 面倒だった具体的な作業（電卓を叩いていた）
- データの出所を明示すること（楽天 API、46製品）
- 入っていないものを正直に書き、募集すること

## 効かないもの

- 完成品として見せること
- 数字が1つも入っていない開発の苦労話
- 技術スタックの自慢

## 語り口

自分の手で作った人として話す。誇張しない。件数を隠さない。
