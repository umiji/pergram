# 読み手｜セールで買い時を計っている人

楽天スーパーセール / マイプロテインのゾロ目セール / Amazon タイムセール祭りのたびに
「結局どれが一番お得か」を探している人。**セール期間中は判断を急いでいる。**

## この人の状況

- 買う意思は既にある。決めかねているのは「どれを」だけ
- 割引率とポイント還元で判断しており、1gあたりでは見ていない
- 時間がない。セールが終わる前に決めたい

## 効くもの

- **今日時点の数字**であることが分かる書き方（取得日を先に出す）
- 順位そのもの。1位から3位までを並べる
- 種別で絞り込める、という情報

## 効かないもの

- 長い前置き。結論が3行目より後にあると読まれない
- 「あとで比較してみてください」という先送り
- 割引率の話（pergram は割引率を持っていない）

## 語り口

短く。1行目に数字。装飾を削る。
