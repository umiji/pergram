# X のランキングで何が効くか

出典: `docs/research/x-impression-2026.md`（2026-01 に xAI が公開した
`xai-org/x-algorithm` のコード読解）。**アルゴリズムが変わったときだけ更新する。**

## スコアの形

```
Final Score = Σ ( weight_i × P(action_i) )
```

`ranking_scorer.rs` が足し合わせている予測値は 26 個ある。**いいねはそのうちの 1 つ。**

**最重要:** 重みは**予測確率**に掛かるのであって、実際のエンゲージメント回数には
掛からない。つまり「リプライをもらう」ことではなく、**「リプライされそうな投稿だと
予測させる」ことがスコアを上げる。** 本文の仕事はここにある。

## 文面で狙える行動

| 狙い | 本文側で何をするか |
| --- | --- |
| `dwell` / `dwell_time` | 読み進める理由を冒頭に置く |
| **`not_dwelled`（負）** | **冒頭の仕事は「止める」だけでなく「マイナスを踏まない」** |
| `reply` | 相手の番を残す。断定しきらない |
| `share_via_dm` / `share_via_copy_link` | 誰かに個人的に送りたくなる形。独立項目なので単独で狙う価値がある |
| `profile_click` | 「この人は何者だ」と思わせる |
| `follow_author` | 最も強い正のシグナル（最も稀な行動だから） |
| `quote` | 言い換えて自分の意見を足したくなる余白 |

**1 投稿で全部を狙わない。** 狙いを 1〜3 個決めてから書く。

## 長さの上限（守れないと投稿できない）

上限は**重み付き 280**。数え方が文字数と違う。

- **日本語（漢字・かな）は 1 文字が 2** — つまり**日本語だけなら約 140 字が上限**
- 半角英数字・記号は 1
- **URL は文字数にかかわらず一律 23**
- Premium（有料）は 25,000 まで書けるが、**無料はこの 140 字が硬い天井**である

**観測した投稿が長いからといって真似できるとは限らない。** 300 字の投稿は Premium
アカウントのものである。**無料アカウントで運用しているなら、長文で伸びていた投稿の
型を写しても再現できない。** 骨格を作る段で、自分が出せる長さに収まる型だけを採る。

## 運用側の制約

- **Author Diversity** — 同一閲覧者のセッション内で、同じ著者の 2 件目以降に減衰が
  かかる。**短時間の連投は自分で自分を潰す。** 複数本は時間を空ける
- **New-Author Boost** — 表示回数が閾値未満の著者は押し上げられる。**立ち上げ期は
  追い風があるが有限。** 質の低い投稿の量産はこれを無駄遣いする
- **DedupConversationFilter** — 同じ会話の枝は畳まれる。「N 連投で N 回露出」は誤り
- **Out-of-Network Discount** — 未フォロー層への配信は元から不利
- **1,000 フォロワー未満のリプライは追加のスパム審査を通る** — 短文・絵文字だけの
  返信は低品質と判定される

## やってはいけないこと

可視性は別系統（`visibility-filtering`）で判定される。**スコアが高くても落とされる。**

- ハッシュタグの多用（もう効かない。使っても 2〜3 個）
- 「いいね返し」「相互フォロー」等の呼びかけ
- 中身のない問いかけだけの投稿

## 数値を運用ルールにしない

「リプライはいいねの 150 倍」「ブックマークは 3 倍」といった数値は、**2026 年の公開
コードから読み取れない**（重み係数は非公開）。序列（リプライ > リポスト > いいね）は
複数ソースが一致するので参考にしてよいが、**数値は使わない。**
