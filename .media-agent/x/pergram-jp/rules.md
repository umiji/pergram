# 投稿ルール

## 禁止事項

- 症状・不調・悩みを起点にした投稿をする（N-01）
- 成分の効能・効果に関する独自の文章を書く（N-02）。機能に触れてよいのは、栄養機能食品の規格基準の定型文、機能性表示食品の届出表示、厚生労働省「日本人の食事摂取基準」の数値をそのまま引くときだけ
- 独自の総合スコア・品質スコア・加重平均ランキングを作る（N-03）
- **含有率の高さを「良さ」として扱う。** たんぱく質の含有率が低い製品は、残りに別の栄養素を
  入れていることが多い。**pergram が持っているのは `protein` の量だけで、残りに何が入っているかを
  知らない。** 知らないものを暗黙に劣ると決めつけるのは、独自の品質スコアを作るのと同じである（N-03）。
  含有率は「たんぱく質1gあたりの単価がなぜそうなるか」の説明にだけ使い、製品の優劣に使わない
- **「たんぱく質1gあたり」を、製品の価値そのものとして語る。** それは pergram の比較軸であって、
  買い手が何を買っているかとは別である。味・溶けやすさ・他の栄養素・飲みやすさで選ぶのは合理的で、
  それを「間違った選び方」として書かない
- 健康状態・体調・服薬に関する情報を読み手から集める（N-05）
- 診断的な表現を書く（N-07）
- Amazon / iHerb のレビュー本文・星評価を転載する（N-08）
- AGA・育毛・薄毛の文脈で成分を扱う（N-09）
- 妊活・美容医療の文脈で成分を扱う（N-10）
- 特定ブランドの優劣を述べる。並べてよいのは単価と含有量だけ
- 特定の製品を「おすすめ」として名指しで推す。症状や目的から製品を推薦しないという位置づけ（requirements.md §1.2）に反する。pergram というサイト自体を勧めるのは可
- 出典と取得日の無い価格を出す
- 網羅を示す語を使う（全メーカー / 全製品 / 全ブランド / 全比較 / すべての / 網羅）。実データは楽天で取得した46製品にすぎず、景表法上の過大表示になる。件数と取得元を必ず添える
- 価格の変動（値上がり・値下がり・過去との比較）を書く。価格履歴を保持していないため裏付けられない
- 公的な参照値が無い成分について、独自の目安を出す
- アフィリエイトリンクを、広告である旨を書かずに貼る
- 行政処分・措置命令・回収のニュースに触れるとき、特定の企業名・商品名を挙げて論評する。制度と仕組みの話に留める

## ブランドルール

- `pergram` は全て小文字。`Pergram` / `PerGram` と書かない
- プロフィール・固定投稿・広告のように初回接触になりうる場所では、必ずタグライン「1gあたり、いくら払ってる?」とセットで出す
- 使う語: 含有量 / 元素量 / 単価 / 1gあたり / 認証 / 出典 / 更新日 / 比較 / 一覧
- 画像に使ってはいけないもの: 葉・植物・カプセル・錠剤・筋肉・ハート・体のシルエット・チェックマーク・人物写真
- **絵文字は1〜2個まで使ってよい**（2026-09-03 PO判断で解禁）。実測で伸びた上位2投稿が
  どちらも挨拶＋絵文字だったため。ただし装飾として並べない
- **読み手に直接向けた問いかけは敬語を残す**（「見てます？」ではなく「見てますか？」）。
  本文がラフでも、問いかけだけは丁寧形にする
- 本文は硬く書かない。実測で伸びたのは会話体の投稿である
- ハッシュタグは投稿末尾に最大2個
- 数値には単位と基準を添える
- 不備や誤りを告知するときは謝罪から始めない。何が起きて、どうすれば直るかだけを書く
